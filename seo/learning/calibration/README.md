# Calibration

Здесь хранится проверка соответствия заявленной уверенности фактической доле подтверждений:
из экспериментов с `confidence ≈ 0.8` подтвердиться должны примерно 80%.
Систематический перекос означает, что формулу уверенности надо править, а не результаты.

Пусто: завершённых экспериментов недостаточно.
