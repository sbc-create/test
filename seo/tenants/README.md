# Редакционные файлы по tenant

Один каталог на tenant: `seo/tenants/<tenant>/`. Обязательный набор:

- `EDITORIAL_STRATEGY.yaml` — аудитория, тематика, tone of voice, отличия от других сайтов портфеля, запрещённые темы
- `EDITORIAL_CALENDAR.yaml` — подтверждённые анонсы, ожидаемые релизы, даты проверки, owner/source
- `CONTENT_BACKLOG.yaml` — идеи со score, источниками, правами, статусом, ожидаемой пользой
- `HOMEPAGE_PLAN.yaml` — порядок и правила блоков, окна свежести, пины и сроки, эксперименты
- `EDITORIAL_SOURCE_REGISTRY.yaml` — разрешённые источники, provenance, confidence, частота обновления, ограничения
- `CONTENT_STYLE_GUIDE.md` — голос конкретного сайта, правила фактов и качества, примеры

Каталог `demo/` — единственный заполненный, он относится к фикстуре. Для реальных сайтов
эти файлы создаются после передачи инвентаря: скопировать одну стратегию на 15–20 сайтов
нельзя — межсайтовые дубли блокируются гейтом перед публикацией.
