# Baseline

**Статус: BASELINE_NOT_ESTABLISHED.**

Baseline по определению строится на измеренных данных. Ни один источник
(Search Console, Вебмастер, Метрика, серверные логи) не подключён, портфель
пуст — поэтому реальных baseline-значений здесь нет и не будет придумано.

## Что уже готово к моменту подключения источников

| Компонент | Состояние |
|---|---|
| Механика сопоставимых окон (7/28/90, выравнивание по дням недели) | реализовано, `analysis/kpi.py` |
| Отсечение неполных дней и учёт задержки источника | реализовано, `connectors/base.py` |
| Таксономия интентов и кластеризация | реализовано, `analysis/queries.py` |
| Позиционные корзины TOP-3/10/20, взвешенная позиция, CTR к ожиданию | реализовано |
| Покрытие показами и входы на 1000 индексируемых страниц | реализовано |
| Хранение наблюдений с freshness/completeness/timezone | реализовано, `state.py` |

## Что будет в baseline после подключения (на сайт и на портфель)

Первичные: небрендовые клики, качественные органические сессии, показы,
медианная и взвешенная позиция, CTR с поправкой на позицию/тип запроса/устройство,
доля запросов в TOP-3/10/20, доля индексируемых страниц с показами,
входы на 1000 индексируемых страниц, конверсия в разрешённое полезное действие,
возвращаемость, динамика на окнах 7/28/90.

Guardrail: ручные санкции = 0, конфликты canonical/robots/sitemap = 0,
межтенантные утечки = 0, индексируемые тонкие/пустые/дублирующие страницы = 0,
выдуманные оценки/комментарии = 0, рост ловушек обхода = 0,
4xx/5xx/soft-404 в пределах бюджета, CWV/доступность плеера в бюджете.

## Как baseline будет зафиксирован

1. Подключить источники (см. `seo/UNKNOWNS.md`, пп. 3–8).
2. `seo collect --all` за 90 дней; дни с `completeness < 0.9` в baseline не входят.
3. `seo baseline` — снимок с пометкой окна, таймзоны и полноты.
4. Только после этого разрешён первый эксперимент: без baseline эффект не с чем сравнить.
