## Lords

| lords-01 | `d853747e6413` | 2 |

Откат — переключение символьной ссылки `current` на предыдущий релиз. Оба релиза
лежат рядом; связанные копии на жёстких ссылках не мешают откату: удаление
нового релиза не трогает файлы старого.

## Откат изменений этой задачи

| Что откатывать | Как | Последствие |
| --- | --- | --- |
| быстрый путь | `LORDS_FAST_PATH=0` в окружении службы | конвейер возвращается к полной сборке |
| расширенный отпечаток | удалить `var/lords/render-state/*.fingerprint.json` | ворота посчитают вход изменившимся и отрендерят |
| снимок произведений | удалить `var/lords/render-state/*.titles.json` | быстрый путь ответит «нужен полный рендер» |
| CMS canary | остановить процесс | ничего: контур изолирован |
| API | снять `SITE_ENGINE_API_ENABLED` | маршруты отвечают 404 |

Ни один из этих откатов не требует выкладки: все они — переменная окружения либо
удаление файла состояния.

переключение ссылки во время его работы означало бы гонку. Механизм не менялся с
02B, где репетиция проводилась.
