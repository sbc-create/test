# Обратная совместимость

## Что могло сломаться и почему не сломалось

| Изменение | Риск | Что сделано |
| --- | --- | --- |
| `render_site(..., only_title_slugs=...)` | новый обязательный параметр сломал бы всех вызывающих | параметр необязательный; `None` — прежнее поведение, отрисовываются все страницы |
| Новые части отпечатка (`enrichment`, `playability`) | старое состояние ворот не содержит этих полей | поля со значением по умолчанию `""`; первый цикл после изменения решает «рендерить» — то есть ошибается в безопасную сторону |
| Быстрый путь в конвейере | отказ быстрого пути остановил бы обновление | коды возврата: всё, кроме 0 и 10, означает полный рендер; поломка самого сценария приводит к полной сборке, а не к пропуску |
| `ControlPlaneApi` рядом с `SiteEngineApi` | замена сломала бы читающих | старый API не тронут; новый добавлен рядом и экспортирован через публичный интерфейс пакета |
| Публичный интерфейс `api` пополнен | сужение сломало бы импорты | только добавление имён; `SiteEngineApi` и `create_api` на месте |
| Снимок произведений | отсутствие снимка при первом запуске | отсутствие снимка означает «нужен полный рендер», а не «изменений нет» |

## Правило умолчаний

Каждое новое поле и каждый новый параметр имеет значение по умолчанию,
воспроизводящее прежнее поведение. Проверяется тем, что 2822 прежних теста
продолжают проходить.

## Что несовместимо намеренно

Ничего. В этой задаче не удалён ни один публичный интерфейс и не изменена
семантика ни одного существующего поля.

## Миграция состояния

Файл снимка произведений появляется сам при первом успешном цикле. До его
появления быстрый путь отвечает «нужен полный рендер» — то есть система ведёт
себя ровно так, как вела до изменения.
