# CMS canary

## Что это

Интерфейс управления поверх Control Plane. Слушает **только loopback**
(`127.0.0.1:8710`), публичного домена не имеет и в production не выкладывался.

Запускается `automation/host/cms-canary.py`.

## Разделы

Все десять отвечают 200 под владельцем:

| Раздел | Что показывает |
| --- | --- |
| Обзор | сайты, задания, записи аудита, поданные команды |
| Сайты | профиль, тип, домены, число модулей |
| Контент | каталог из сохранённого снимка, поиск по подстроке |
| Редакция | форма черновика; публикация — отдельная команда |
| Полки | состав полок витрин |
| Расписание | только подтверждённое источником |
| Задания | команды, их состояния, форма запуска загрузки |
| Релизы | выкладки, ревизии, кнопка публикации |
| Доступ | лица, их роли и области; таблица прав ролей |
| Аудит | журнал с отпечатками записей |

## Данные настоящие

| Раздел | Источник | Измерено |
| --- | --- | --- |
| Сайты | `config/site-profiles` | 7 профилей |
| Контент | снимок каталога Lords | 50 записей на странице |
| Релизы | `/srv/lords/*/current` | 3 витрины |

Ни один источник не обращается к API поставщика. CMS не знает ни одного его
адреса.

## Права видны в самом интерфейсе

| Проверка | Владелец | Наблюдатель |
| --- | --- | --- |
| кнопка «Опубликовать» | есть | нет |
| форма черновика редакции | есть (у редактора) | нет |

Это не только оформление: попытка подать команду без права отклоняется на
стороне API, а не скрытием кнопки.

## Проверено на живом canary

| Действие | Результат |
| --- | --- |
| открыть без входа | 401 |
| вход с неверным ключом | 401 |
| оператор запускает загрузку | 202, состояние `DRAFT` |
| повтор с тем же ключом | 200, помечено «повтор» |
| наблюдатель публикует | 403, «нет права publish:production» |
| записей аудита после двух подач | 1 — повтор не порождает вторую |
| `/openapi.json` | 200, 35 путей |
| `/healthz` | `{"status": "ok"}` |

## Секреты

| Проверка | Результат |
| --- | --- |
| ключ сеанса в разметке любой из 5 страниц | 0 вхождений |
| слова `token`/`secret` в разметке | 0 |
| ключ сеанса в журнале сервера | 0 |

Журнал обращений выключен намеренно: путь `/login?key=…` содержит ключ, и запись
такого пути в журнал сделала бы ключ достоянием журнала.

## Заголовки ответов

`X-Robots-Tag: noindex, nofollow` и `Cache-Control: no-store` на каждом ответе.
Куки сеанса — `HttpOnly`, `SameSite=Strict`.

## Чего canary не делает

Не исполняет команды. Команда принимается, проверяется правом, записывается в
аудит и остаётся в состоянии `DRAFT`: исполнителя в этом контуре нет.

Это не недоделка, а граница задачи: выкладка CMS в production запрещена, а
исполнение команд без выкладки означало бы, что изолированный контур управляет
production.
