## Точечная инвалидация вместо ожидания TTL

Новый контент не ждёт истечения общего срока. При событии инвалидируются только
затронутые теги. Измерено на Lords: изменение одного произведения затрагивает
7 страниц — его собственную, карусель главной, две страницы листинга, страницу
раздела и страницу года.

Глобальной очистки при одном обновлении не происходит нигде: ни в кэше постеров
(ключ — путь файла), ни в каталожном индексе Yummy (одна запись на витрину), ни
в релизах Lords (связанная копия с точечной правкой).

## Свойства, проверенные измерением

| Свойство | Где | Измерено |
| --- | --- | --- |
| stale-while-revalidate | nginx, постеры | `proxy_cache_background_update on` |
| last-known-good | постеры и каталожный индекс | при 502 отдаётся сохранённая копия; ключи индекса без TTL |
| схлопывание одновременных промахов | постеры | 8 одновременных промахов → 1 запрос к источнику |
| предел диска | постеры | 700 МБ по правилу `min(2 ГБ, 10 % свободного)`; занято 11 МБ |
| безопасная очистка | постеры | вытеснение по давности силами nginx; ручная — по конкретному ключу |
| метрики | постеры | `X-Poster-Cache`: HIT / MISS / PLACEHOLDER; доля попаданий 96 % |
| битых изображений | шесть сайтов | 0 |
| внешний адрес в `og:image` | Lords | сохранён: подмена ограничена `src` и полем `poster` |

## Правило, которое легко нарушить

Полная очистка кэша постеров при отказе источника **запрещена**: она превращает
переживаемый сбой в одновременную поломку изображений на всех шести сайтах.

## Чего в этой задаче не менялось

Политика кэша Yummy и Lords осталась той, что установлена в 02F. Здесь она
только формализована и связана с тегами; ни один слой не переписан.
