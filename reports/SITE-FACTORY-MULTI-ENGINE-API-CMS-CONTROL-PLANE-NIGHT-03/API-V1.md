# Site Engine / Control Plane API v1

## Устройство

Чтение и запись разделены не по названию, а по существу. Чтение отвечает данными
и ничего не меняет. Запись не отвечает данными — она принимает **команду**,
проверяет право, пишет в аудит и возвращает идентификатор.

Смешение этих ролей и есть то, из-за чего «сохранить форму» однажды становится
«выложить в production».

| Маршрут | Команда | Право |
| --- | --- | --- |
| `POST /api/v1/jobs` | `ingestion.run` | `ingestion:run` |
| `POST /api/v1/publications` | `release.publish` | `publish:production` |

## Свойства, проверенные тестами

| Свойство | Как проверено |
| --- | --- |
| пагинация | страница 2 из 10 по 3 даёт `[3,4,5]`, `total_pages=4`, `has_next=true` |
| предел размера страницы | запрос `per_page=100000` даёт 200 |
| фильтр | по подстроке `q` и по точному полю |
| сортировка | по полю, в обе стороны |
| единый формат ошибки | `{"error": {"code", "message"}}` во всех отказах |
| идемпотентность | повтор с тем же ключом не создаёт вторую команду |
| версия объекта | правка с устаревшей версией отклоняется с объяснением |
| RBAC | наблюдатель читает, но не командует; редактор чужого сайта отклонён |
| область сайта | администратор одного сайта не управляет соседним |
| correlation id | присланный возвращается, отсутствующий вычисляется |
| секретов нет | API собирает ответ сам, из профилей и журналов |
| неопознанное лицо | 401, а не 403 — разница нужна при разборе |
| выключенный API | 404, а не 403: наличие маршрута — тоже сведения |
| неподключённый источник | 501, а не пустой список |

Последнее стоит отдельно. Пустой список неотличим от «данных нет», и поломка
источника выглядела бы как исправная работа.

## Чего API не делает

Не ходит к поставщику. Не отдаёт содержимое команды целиком — только имена полей:
в нём может оказаться что угодно. Не исполняет команды сам: в canary исполнителя
нет, команда принимается и остаётся в состоянии `DRAFT`.
