# Вторая канарейка: серверный поиск на боевой витрине

## Что выложено

Витрина `lordserial33.biz` (lords-02), релиз `ff4eeadb8c7b`, отпечаток шаблона
`385d6140087a44e807ecf2d2542754423187af82e1327dc59173a7813f7a5606`, ревизия
отрисовщика `9a5208e0929fe2010d1aa458fc26ba9aec1bfe28`. Указатель поиска собран
по 52 517 собранным страницам, 21 343 куска, 18 МБ.

## Три дефекта, найденные боевой выкладкой

Каждый из них не воспроизводился на стенде и был виден только на витрине.

**Указатель не находился при разложенном рядом файле.** Служба стартует раньше,
чем раскладывается релиз; Python успевает запомнить каталог `lib` как
отсутствующий в кэше импортёра и больше туда не заглядывает. Ответ 503 при
работающей библиотеке — проверено запуском в отдельном процессе. Кэш импортёра
теперь сбрасывается перед загрузкой.

**Исправление рантайма не доезжало до витрины.** Блок обновления `serve.py`
стоял после сборки, и ворота уводили выполнение мимо него словами «вход не
изменился». Витрина с неизменившимся каталогом не получала исправление вовсе.
Перенесён до ворот.

**Запрос разбирался как латиница.** WSGI отдаёт `QUERY_STRING` побайтовым
разбором latin-1: «матрица» приезжала как «Ð¼Ð°ÑÑÐ¸ÑÐ°», ответ 200, найдено
ноль. Перекодирование делается на самой строке запроса — до разбора.

Отдельно: копирование модулей поиска без проверки уронило обновление на
витринах со старым закреплённым шаблоном. Каталог перестал обновляться на двух
витринах из трёх, при этом снаружи всё отвечало двумястами. Копирование стало
условным, отсутствие модулей называется в журнале.

## Публичная приёмка

Ноль провалов. Поиск по точному названию «матрица» — девять записей, первая
«Матрица (1999)». Опечатка «матрца» и чужая раскладка «vfnhbwf» находят.
Пустой запрос каталог не отдаёт, мусор честно не найден. Страница и API
согласованы: первый результат совпадает. Разные запросы дают разные ответы —
именно это и отличает применённый запрос от обещания.

Фасеты: 241 жанр, 75 стран. `PTNoneM` — ноль. Плеер на месте. Разделы `/`,
`/catalog/`, `/catalog/page/2/`, `/genres/`, `/countries/` — 200.

## Откат и возврат

`ff4eeadb8c7b` → `0c28b82a5fc6`: витрина 200, шаблон прежний. Возврат
`0c28b82a5fc6` → `ff4eeadb8c7b`: поиск «ведьмак» — двадцать записей. Обе
операции записаны с витриной, релизами, причиной, исполнителем, PID и UID.

Соседи `lordfilm47.space` и `1lordserials1.online` — 200, шаблон
`0c905f9fe50a746b` у обоих. Таймер активен.

## Чего в этой выкладке нет

Переключателя тем: механизм едет вместе с шаблоном, но рисуется только при
объявленной второй палитре, а профили Lords её не объявляют. Палитра —
поставка TEMPLATES; приёмка проверяет отсутствие переключателя честно и
потребует его наличия, как только палитра появится.
