## Первопричина

Обновление каталога пересобирало витрину из развёрнутого checkout
`/srv/site-factory/repo` и переносило `bundle-manifest.json` прежнего релиза
копией. Манифест утверждал одно, содержимое было другим, и сверить их было
нечем: ни отпечатка шаблона, ни ссылки на артефакт в манифесте не существовало.

Канареечный релиз `c573222dcd23` был переключён 6 сентября в 09:22:25 —
происхождение `cdnvideohub-live`, отпечаток шаблона `ca3d395ade25fb29`, снимок
каталога `547d379fae4acbd4` на 53 232 записи, операция записана. Через сорок
восемь минут таймер заменил публичный `current` релизом `72c71f2806fe`,
собранным из checkout `568863d`. Изменения канарейки исчезли, а переключение
считалось успешным.

## Старая и новая схема

| | было | стало |
|---|---|---|
| источник шаблона | развёрнутый checkout | закреплённый артефакт из манифеста релиза |
| манифест нового релиза | копия прежнего | собран из прежнего: шаблонная часть перенесена, содержательная обновлена |
| переключение | `ln -sfn` без условий | замок на витрину + проверка ожидаемого предыдущего + атомарная замена |
| смена шаблона | молча, любым обновлением | только именем, под своей причиной, с записью прежних значений |
| быстрый путь при смене шаблона | применялся | отключён: иначе витрина наполовину новая |
| ворота рендера при смене шаблона | применялись | не применяются: отпечаток описывает вход, а не релиз |
| диагностика | `healthz` отдавал прочитанное | отдаёт выложенное: релиз, шаблон, ревизия, снимок, цель отката |
