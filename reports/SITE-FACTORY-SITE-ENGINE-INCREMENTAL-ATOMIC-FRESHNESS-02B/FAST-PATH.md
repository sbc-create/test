# Быстрый путь свежести

`factory/site_engine/freshness.py`. Тесты: 26.

## Разделение путей

| Путь | Частота | Что делает |
| --- | --- | --- |
| быстрый | каждые 5 минут | обрабатывает только изменения |
| полная сверка | раз в сутки | полнота, удаления, аномалии, пересчёт адресов |
| полная пересборка | по событию | смена схемы, шаблона, миграция, авария, команда |

Быстрый путь не ждёт окончания сверки. Пока они делят одну очередь и один замок,
«раз в сутки» превращается в «сутки задержки», и семичасовой цикл возвращается
через чёрный ход.

## Очередь

Хранится файлом, переписывается атомарно, переживает перезапуск. Очередь,
теряющаяся при перезапуске, теряет серию именно тогда, когда что-то пошло не
так, — то есть в единственный момент, когда она нужна.

Повтор того же изменения не создаёт второй записи: ключ идемпотентности не
содержит времени.

Изменение уходит из очереди **только после подтверждения на живом адресе**. Не
подтвердилось — значит, не сделано, и следующий цикл возьмётся снова. Число
попыток считается.

## Времена

| Отметка | Смысл |
| --- | --- |
| `provider_timestamp` | время по версии поставщика, может отсутствовать |
| `detected_at` | первое наблюдение нашим опросом — **начало SLA** |
| `event_created_at` | когда создано событие |
| `render_started_at` / `render_finished_at` | сборка затронутого |
| `published_at` | переключение релиза |
| `cache_invalidated_at` | сброс тегов |
| `live_verified_at` | подтверждение на публичном адресе — **конец SLA** |

Время поставщика **никогда не подменяет наблюдение**. У большинства записей его
нет, а у остальных оно не двигается при выходе серии: подмена выдала бы наше
наблюдение за факт выхода.

## Пороги

| Условие | Уровень |
| --- | --- |
| старейшее необработанное ждёт ≥ 10 мин | предупреждение |
| ≥ 15 мин | тревога |
| успешного цикла не было ≥ 10 мин | предупреждение |
| ≥ 15 мин | тревога |
| p95 задержки > 15 мин | тревога |

**Пустая очередь тревогой не считается.** Отсутствие изменений у поставщика — не
наша задержка, и записывается отдельно как `PROVIDER_GAP`.

## Замок

Брошенный замок перехватывается через пятнадцать минут. Без срока годности
оборванный процесс останавливает очередь навсегда — тихо, потому что снаружи это
выглядит как «цикл идёт».

## Состояние

Модуль написан и покрыт тестами. **К живым контурам не подключён**: подключение
требует, чтобы отпечаток входа уже работал в production и чтобы первый полный
цикл записал эталон. Это отмечено в `BLOCKERS.md` как незавершённое, а не выдано
за сделанное.
