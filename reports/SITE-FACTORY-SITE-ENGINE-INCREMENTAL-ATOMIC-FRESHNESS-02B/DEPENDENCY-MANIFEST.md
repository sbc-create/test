# Карта зависимостей: событие → затронутые ресурсы

`factory/site_engine/dependencies.py`. Тесты: 40.

Смысл этой карты — в отрицаниях. Выход одной серии меняет карточку тайтла, полку
новых серий и одну-две страницы листинга, а не 61 328 страниц. Пока карты нет,
единственный честный ответ на вопрос «что перестраивать» — «всё».

## Что задевает каждое событие

| Событие | Ресурсы |
| --- | --- |
| `EPISODE_ADDED` | карточка, главная, до двух страниц листинга, страница сезона, документ SEO |
| `SEASON_ADDED` | карточка, страница сезона, карта сайта, SEO |
| `TITLE_CREATED` | карточка, главная, до двух листингов, карта сайта, SEO |
| `TITLE_UPDATED` | карточка, SEO |
| `VOICEOVER_ADDED` | карточка, SEO |
| `RATING_UPDATED` | карточка, хранилище оценок, SEO |
| `PLAYBACK_AVAILABLE/UNAVAILABLE` | карточка, главная, SEO |
| `SCHEDULE_UPDATED` | страница расписания — **только там, где включено** |
| `ANNOUNCEMENT_UPDATED` | страница анонсов — **только там, где включены** |

Верхняя граница закреплена тестом: **ни одно событие не задевает больше десяти
страниц**.

## Чего карта намеренно не делает

Соблазн добавить ресурс «на всякий случай» велик, и каждое такое добавление
возвращает к полной пересборке маленькими шагами. Отрицания закреплены тестами:

* расписание не обновляется там, где выключено;
* анонсы не обновляются там, где выключены;
* полка новых серий не трогается там, где её нет;
* страница несуществующего сезона в план не попадает;
* карта сайта трогается только при появлении нового адреса, но не при выходе
  серии;
* обновление оценки не трогает главную;
* документ SEO идёт за карточкой и не идёт без неё.

## Причины

У каждого ресурса в плане записана причина, по которой он туда попал. Это не
украшение: по причине видно, если ресурс попал зря. Пример сухого прогона для
выхода серии:

```json
{
  "event_type": "EPISODE_ADDED",
  "pages": 4,
  "resources": [
    {"kind": "page", "path": "/title/film/", "reason": "карточка тайтла меняется при EPISODE_ADDED"},
    {"kind": "page", "path": "/", "reason": "полка новых серий показывает прибавку"},
    {"kind": "page", "path": "/catalog/page/3/", "reason": "карточка поднимается в списке обновлений"},
    {"kind": "page", "path": "/title/film/season-1/", "reason": "страница сезона показывает новую серию"},
    {"kind": "seo", "path": "/title/film/", "reason": "метаданные описывают изменившуюся карточку"}
  ],
  "cache_tags": ["title", "shelf:new-episodes", "catalog"],
  "dry_run": true
}
```

## Сухой прогон

`dry_run()` возвращает тот же план с пометкой и не делает ни одной записи.
Показывает: событие, список сайтов, страницы, теги кэша, ожидаемое число файлов
и причину каждого изменения.
