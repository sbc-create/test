# Реестр адресов

`factory/site_engine/routes.py`. Тесты: `tests/unit/test_site_engine_routes.py` (26).

## Что было сломано

Прежняя схема выдавала второму тайтлу с тем же именем адрес `X-2`, не проверяя,
что `X-2` — законный адрес другого тайтла, которого зовут «X 2». Один затирал
другого. Потеря — 207 записей из 53 116, ноль и четыре десятых процента
каталога, и заметить её по внешнему виду витрины невозможно.

Пример из живого каталога:

```
akuly-2   остаётся: «Акулы 2»          теряется: «Акулы»
avatar-korolya-2  остаётся: «Аватар короля»  теряется: «Аватар короля 2»
```

Кто именно теряется, зависело от порядка ответа API: тот же каталог в другом
порядке дал бы другие потери.

## Модель

| Поле | Смысл |
| --- | --- |
| `content_id` | устойчивая личность, `провайдер:идентификатор` |
| `canonical_path` | нынешний адрес |
| `legacy_paths` | прежние адреса, с них ставится перенаправление |
| `collision_group` | базовый слаг группы |
| `route_version` | растёт при намеренном переносе |
| `created_at` / `updated_at` | когда появился и когда менялся |

Слаг — человекочитаемое представление, не личность. Переименование тайтла
адрес **не двигает**: работающая ссылка важнее совпадения адреса с названием.
Для миграций есть отдельный вызов `move`, он пишет прежний адрес в историю.

## Почему новые адреса не могут столкнуться

Разделитель — два дефиса. `slugify` схлопывает любую их серию в один, поэтому
`X--a1b2c3` не получится ни из какого названия. Пространства имён не
пересекаются **по построению**, а не по договорённости, — именно этого не
хватало прежней схеме.

Различающая часть — шесть шестнадцатеричных знаков от `content_id`. Зависит
только от личности: порядок обхода на неё не влияет, повторный импорт даёт тот
же адрес.

## Ошибка, найденная до выкладки

Первая редакция назначения признавала владельцем только базовый адрес группы и
выселяла всех прочих на `--`-адреса. На живом каталоге это переставило бы
**5 435 работающих ссылок** — записи, законно занявшие `X-2` и ни с кем не
конфликтующие.

Поймано прогоном на настоящих данных, а не рассуждением. Порядок исправлен:
сперва за каждым закрепляется то, чем он уже владеет, и лишь потом раздаются
свободные адреса.
