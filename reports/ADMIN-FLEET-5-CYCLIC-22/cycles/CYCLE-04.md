# CYCLE-04 — Браузерная приёмка контура сайта

## Что проверяется

Один сценарий на любое семейство: `tests/tools/site_admin_fleet_e2e.js` плюс
стенд `tests/tools/fleet_stand.py`, заводящий две витрины и операторов на
каждой. Сорок одна проверка на движок: вход по адресу своего сайта, семь
разделов, правка с предпросмотром «было/станет», применение, откат, проверка
что соседний сайт не задет, подделанная форма, подмена параметра витрины, роль
читателя, четыре ширины с двукратным увеличением, клавиатура.

## Две настоящие утечки соседа

Обе одной природы: область видимости объявлена, но не передана.

**Перечень сессий не имел области вовсе.** В нём стоит адрес владельца
(добавлен в прошлом этапе, чтобы отзыв был осмысленным), поэтому список сессий
оказался перечнем людей соседнего сайта — другой дорогой. То же с перечнем
приглашений: приглашение соседа — это его адрес почты и его роль.

**Принадлежность терялась при обновлении прав.** Панель обновляет права сессии
на каждом запросе — чтобы новые ограничения действовали сразу, а не после
выхода. Пересборка принципала не переносила `site_id`, и местный администратор
молча превращался в видящего весь массив. Модульные тесты этого не ловили: они
обращаются к каталогу напрямую, минуя обновление прав.

Ни одна из двух не видна в ответе API по отдельному маршруту — обе видны только
на собранной странице.
