# CYCLE-06 — Содержимое семейств из их собственных пакетов

## Воспроизведённый пробел

Три семейства объявляют `content_source.kind: fixture` — набор записей в пакете
самой витрины. Движок такой источник читать не умел: каталог он брал только из
кэша поставщика. Отсюда результат цикла 5: контур админки работает, а очередь
разбора пуста, потому что каталога нет.

## Что сделано

`factory/site_engine/content_fixture.py` и `POST /api/v1/content-ingest`
(право `jobs:write`).

* **Отпечаток проверяется, если объявлен.** Чтение без сверки означало бы, что
  подменённый набор попадёт на витрину молча.
* **Отсутствующий набор — отказ, а не пустой каталог.**
* **Перенос ничего не выдумывает**: запись без идентификатора отвергается
  целиком.

## Найденный дефект в собственной работе

Объявленный отпечаток перестал бы проверяться, если YAML разберёт его как
число: строка из одних нулей становится нулём, ноль ложен, и `or ""` превращал
его в «не объявлен». Поймано собственным тестом на подменённый набор; проверка
переписана на `is not None`.

## Что это значит для приёмки

Подставлять этим витринам чужой каталог нельзя: зелёный прогон на выдуманных
данных доказывает только то, что данные выдуманы. Три семейства остаются на 6.

Запрос отправлен: `HANDOFF-2026-09-06-032-CORE-TO-TEMPLATES` — нужен набор
записей и его отпечаток, ничего больше. Номер 032, а не 029: пока писался
handoff, соседний поток занял 029, 030 и 031 (см. дефект FLEET-INV-003).
