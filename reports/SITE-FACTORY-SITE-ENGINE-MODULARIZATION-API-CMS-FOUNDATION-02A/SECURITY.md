# Безопасность в границах 02A

## Что сделано

**API выключен по умолчанию.** Без флага `SITE_ENGINE_API_ENABLED` маршрутов
нет. В production не включается даже с флагом: список разрешённых окружений —
`local`, `test`, `staging`, и production в нём отсутствует. Выключенный API
отвечает 404, а не 403: наличие маршрута тоже сведения. Невнятное значение
флага (`0`, `false`, `maybe`, пустая строка) считается выключенным — проверено
параметризованным тестом.

**Секретов в ответах нет.** Конфигурация сайта отдаётся без `credentials_ref`.
Проверено тестом, который ищет в сериализованном ответе слова `credentials_ref`
и `token`, а не осмотром глазами.

**Секретов в профилях нет.** Гейт архитектуры отдельным правилом допускает
только ссылки вида `*_ref`. Профили лежат в Git.

**Изменяющих маршрутов нет.** Ни одного. Write-контракты описаны и не
опубликованы.

**Право на запись выражено кодом.** Запись в нормализованное хранилище требует
токена, выданного конкретному прогону обхода, и токен проверяется на
принадлежность сайту. Витрина такого токена не получает нигде.

**Права привязаны к сайтам.** Область сайтов входит в личность, а не
проверяется отдельно; попытка опубликовать на чужом сайте отклоняется с
называнием сайта.

**Аудит только дописывается.** Ни изменения, ни удаления записей нет вовсе. У
каждой записи есть отпечаток содержимого.

## Что не делалось

Не выкладывалось ничего. Production не изменялся. Ни один секрет не читался, не
печатался и не попадал в отчёты. Маршруты в nginx не публиковались.

## Что остаётся открытым

Аутентификация и полноценный RBAC для изменяющих операций — предмет `02B`.
Пока их нет, изменяющих публичных маршрутов не будет.
