# Site Engine API v1

Только чтение. Выключен по умолчанию. В production не включается даже с флагом.

Описание порождается из кода: `factory/site_engine/api/openapi.py`, файл —
`schemas/site-engine/openapi-v1.json`. Тест сверяет, что каждый описанный
маршрут действительно отвечает.

## Включение

```
SITE_ENGINE_API_ENABLED=1
SITE_ENGINE_ENVIRONMENT=local|test|staging
```

Без флага маршрутов нет. Отсутствующий, пустой или невнятный флаг (`0`,
`false`, `maybe`) считается выключенным. Ответ выключенного API — 404, а не
403: наличие маршрута тоже сведения.

В nginx не публикуется. В production не открывается.

## Маршруты

| Маршрут | Что отдаёт |
| --- | --- |
| `GET /api/v1/health` | живость, версия, число сайтов, имена адаптеров |
| `GET /api/v1/sites` | список сайтов |
| `GET /api/v1/sites/{siteId}` | сайт, его модули и источник контента |
| `GET /api/v1/sites/{siteId}/config` | политика кэша, SEO, флаги — без ссылок на секреты |
| `GET /api/v1/sites/{siteId}/shelves` | полки, собранные из хранилища |
| `GET /api/v1/sites/{siteId}/titles` | каталог со страницами |
| `GET /api/v1/sites/{siteId}/titles/{titleId}` | карточка |
| `GET /api/v1/sites/{siteId}/titles/{titleId}/episodes` | сезоны и счётчики серий |
| `GET /api/v1/sites/{siteId}/titles/{titleId}/ratings` | оценки с происхождением |
| `GET /api/v1/sites/{siteId}/coverage` | полнота каталога |
| `GET /api/v1/ingestion/status` | состояние обхода по сайтам |

## Три ответа, которые стоит прочитать внимательно

**`limit` больше предела — это 400, а не молчаливое усечение.**

```json
{"error": {"code": "limit_too_large",
           "message": "limit больше предела 100; молча отдать меньше было бы хуже",
           "max_limit": 100}}
```

Отдать меньше запрошенного и не сказать об этом — ровно то, чем каталог себя
однажды обманывал, отвечая при этом HTTP 200.

**Список серий отсутствует, и ответ говорит это прямо.**

```json
{"episode_list_available": false, "seasons": [],
 "counts": {"available": 5, "planned": 5, "max_season": 1}}
```

Пустой `seasons` без этого признака читался бы как «серий нет».

**Полнота: `null` — это не «полно».**

```json
{"source_total": null, "local_total": 6774, "missing": null, "complete": null}
```

Источник промолчал о своём числе — ответ сообщает молчание, а не догадку.

## Ошибки

Одна форма у всех: `{"error": {"code": "...", "message": "..."}}`. Коды:
`not_found`, `site_not_found`, `title_not_found`, `bad_request`,
`limit_too_large`. Проверено тестом, что тело ошибки не содержит ничего, кроме
ключа `error`.

## Проверено на живых данных

| Профиль | Источник | Записей |
| --- | --- | --- |
| `yummyani-site` | снимок наблюдателя | 6 774 |
| `lords-01` | кэш живого каталога | 53 116 |
| `demo-books` | общий Site Engine API | своего загрузчика нет |

Вертикальный путь пройден для всех трёх: профиль → адаптер → нормализованная
модель → ответ. API не обращается ни к API поставщика, ни к базе витрины.

## Безопасность

Секретов в ответах нет: `credentials_ref` вырезается из конфигурации, и это
проверяется тестом, а не осмотром. Пагинация обязательна, предел назван.
Изменяющих маршрутов нет.
