# Кэш как отдельный модуль

`factory/site_engine/cache.py`. Тесты: `tests/unit/test_site_engine_cache.py` (18).

Production-кэш в рамках 02A **не менялся**. Правка, сделанная в родительской
задаче, остаётся на месте; здесь описан общий контракт и приведена эталонная
реализация, чтобы второй сайт не изобрёл несовместимое поведение.

## Составляющие контракта

`CacheProvider`, `CacheKey`, `CachePolicy`, `CacheResult`, `CacheOutcome`,
`InvalidationRequest`, `LastKnownGoodStore`, `RequestCoalescer`,
`FileVersionCache`, `UncacheableResponse`.

## Свойства и почему они такие

| Свойство | Причина |
| --- | --- |
| TTL | базовое |
| окно фонового обновления | посетитель получает прежнее значение, а не ожидание |
| последнее хорошее значение | отказ источника не должен опустошать витрину |
| схлопывание промахов | сброс тега на популярной странице иначе даёт лавину |
| ключи со скоупом сайта | три тенанта из одного образа не видят кэш друг друга |
| наблюдаемость исходов | иначе диагностика несвежести — гадание |
| сухой прогон инвалидации | показать, что будет сброшено, не сбрасывая |

## Запреты

* **5xx не кэшируется** — иначе одна плохая минута источника становится
  пятнадцатью минутами плохой витрины.
* **Пустой ответ не становится новым last-known-good** — каталог однажды
  «похудел» именно так.
* **Бессрочного кэша HTML не бывает** — `CachePolicy` с нулевым TTL не
  создаётся вовсе.

Что считать пустым, решает загрузчик, а не кэш: для полки пустота нормальна,
для каталога она бедствие. Поэтому загрузчик сам поднимает
`UncacheableResponse`.

## Свежесть новых серий не зависит от TTL общей страницы

`FileVersionCache` ключуется состоянием файла, а не часами. Наблюдатель
переписал снимок — следующий же запрос видит новое. TTL здесь либо задержал бы
серию, либо не дал бы экономии; версия файла не делает ни того, ни другого.
Закреплено тестом: значение, положенное под версией `v1`, при версии `v2`
берётся заново.

## Связь с событиями

Каждый тип события отображается в набор тегов (`tags_for_event`). Событие, не
сбрасывающее ни одного тега, до страницы не доедет — и это проверяется тестом
для всех типов, кроме `SOURCE_ANOMALY`, который намеренно ничего не сбрасывает.
