# Владение данными по модулям

Порождено из `config/site-engine/module-registry.json`. Полное описание каждого
модуля — `MODULE-REGISTRY.md`.

| Модуль | Владеет | Пишет | Читают |
| --- | --- | --- | --- |
| `core-contracts` | определениями | никто | все |
| `site-configuration` | профилями и флагами | человек через Git | все |
| `provider-adapters` | сырыми ответами | внешний источник | `content-ingestion` |
| `content-ingestion` | состоянием обхода и полнотой | сам | `monitoring` |
| `normalized-content` | тайтлами и каноническими идентификаторами | только `content-ingestion`, по токену прогона | все читающие |
| `catalog` | правилами выборки | никто | `shelves`, `seo-bridge` |
| `episodes-seasons` | счётчиками и выводом о прибавке | `content-ingestion` | `shelves` |
| `playback` | признаком «смотрибельно» | `content-ingestion` | `shelves` |
| `shelves` | составом и порядком полок | сам | рендерер |
| `ratings` | оценками | `content-ingestion` | `shelves`, `seo-bridge` |
| `schedule` | календарём | внешний источник (не назначен) | рендерер |
| `announcements` | анонсами | `editorial` | рендерер |
| `cache-invalidation` | тегами и их сбросом | все через события | все |
| `seo-bridge` | документом SEO | предмет стыковки | рендерер |
| `editorial` | правками, черновиками, ревизиями | редактор через сценарии | показ |
| `audit` | журналом | все, только дописывание | человек |
| `monitoring` | метриками и тревогами | все | человек |
| `renderer-adapters` | страницами | сам | посетитель |

## Три правила, проверяемые кодом

**Никто не пишет в чужое хранилище.** Запись в `normalized-content` требует
`WriteToken`, выданного прогону обхода и привязанного к сайту. Попытка без
токена или с чужим токеном отклоняется.

**Данные поставщика не изменяются никем.** `editorial` не имеет права писать в
`normalized-content` вовсе; правка живёт отдельно и накладывается при показе.

**Рендерер не создаёт событий и не владеет данными.** Оба свойства объявлены в
описании каждого рендерера и проверяются тестом для всех зарегистрированных.
