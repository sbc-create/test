## Улучшения, которые реализованы (5)

1. **Одна игра — один сайт:** реестр `games-ownership/1`, валидатор отклоняет гайд по игре другого сайта (тест).
2. **Маршрут — только участки источника** (тест сравнивает со страницей источника); если участков нет — честное «не выделены».
3. **Прогресс по главе** сохраняется и сводится на странице игры («Прогресс: 2 из 4»).
4. **Видео без лишних запросов:** до нажатия — ни одного стороннего запроса (проверено в браузере), затем youtube-nocookie.
5. **Без спойлеров в гайде:** сюжет не пересказывается; только механики, маршрут, предметы.
