# Варианты games-story: A (chapter-guides) и B (progress-tracker)

Один сайт, два способа подачи; публикуется один. Данные — один проверенный снимок в каждой ветке.

| | A — chapter-guides | B — progress-tracker |
| --- | --- | --- |
| ветка / порт | `claude/template-games-story` / 8857 | `claude/template-games-story-b` / 8858 |
| главная | карточки глав игры | панель прогресса: клубники и стороны |
| страница игры | сетка карточек глав + видео | таблица-трекер: число клубник (с ограничением источником) и стороны A/B/C |
| гайд | одна колонка: факты, маршрут-«таблетки», механики, предметы, чек-лист | две колонки: вертикальный маршрут, трекер главы, предметы |
| предметы | одна сводная таблица | страницы по видам: красные, золотые, стороны |
| визуальная система | ночная гора: синий и малиновый | графит, бирюзовый, моноширинные цифры |
