# Решения games-story

| ID | Решение | Почему |
| --- | --- | --- |
| GST-01 | ТЗ — задание владельца на ночь 12–13.10.2026 (игра, главы и задания, маршруты, коллекционные предметы, поиск, реальные видео). | Прямое указание. |
| GST-02 | Игра — Celeste: единственная сюжетная игра, чья вики (celeste.ink) доступна без обхода защиты. wiki.gg, Fandom, StrategyWiki, Zelda Wiki — 403, не обходились, удалены из allowlist. | Не обходить ограничения источника. |
| GST-03 | Реестр владения `config/ownership.yaml` (games-ownership/1): celeste → games-story, baldurs-gate-3 → games-rpg, minecraft → games-survival. Одинаковая копия в каждом игровом шаблоне; валидатор отклоняет чужие игры. | «Один гайд не размножать между сайтами». |
| GST-04 | Клубники разбираются по иконкам инфобокса (вид → число), а не по позиции числа. | Иначе 3 золотые клубники Reflection выглядели бы как 3 красные. |
| GST-05 | Видео: идентификаторы взяты из сносок статьи Википедии о Celeste; проверены через YouTube oEmbed (существует, название, канал, встраивание). Это интервью разработчиков, а не прохождение глав — так и подписано. Таймкоды не указываются. | «Не выдумывать ролики и таймкоды». |
| GST-06 | Плеер — фасад: ссылка на YouTube, плеер youtube-nocookie загружается только по нажатию; CSP разрешает только этот frame-src. | Приватность и производительность; без наложения своей рекламы. |
| GST-07 | Названия участков и персонажей — как в источнике (английские), официальную русскую локализацию не подставляем. | Названия не выдумываются. |
| GST-08 | Тексты — сессия Claude (`manual_standin`, `ai_draft`), не Qwen. | Канала к Qwen нет. |
| GST-09 | Вариант A — `chapter-guides`, порт 8857, хранилище `gst-chapters:`. | Изоляция вариантов. |
| GS-C1 | Вариант C `atlas` — ветка `claude/template-games-story-c` от A (a45135b), порт 8870, свои `atlas.css`/`atlas.js`, ключи `gst-atlas:*`, светлая тема. | Изоляция вариантов. |
| GS-C2 | Атлас: персонажи — только по полю characters инфобоксов глав (без описаний персонажей); механики — указатель «механика → глава» (у каждой одна глава, отдельные страницы были бы пустыми); «Где я?» — все чекпоинты по порядку со следующим чекпоинтом или следующей главой (тест). | Сущности из источника, без придуманных биографий. |
| GS-C3 | При переходе со тёмной темы A на светлую найдены белые на белом заголовки карточек глав и логотип — axe их не поймал; исправлено, проверено скриншотом. | Автопроверка не заменяет взгляд. |
