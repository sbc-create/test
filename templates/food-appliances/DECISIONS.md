# Решения food-appliances

| ID | Решение | Почему |
| --- | --- | --- |
| FA-01 | Приборы в этом выпуске: мультиварка (6 рецептов) и аэрогриль (6). Гриль описан в коде, но страница отвечает 404: полных фактов 0. | Минимум задания — ≥2 прибора и ≥12 рецептов; пустой раздел прибора был бы заглушкой. |
| FA-02 | Режим — только название в кавычках из шага источника, рядом со словом «режим»/«программа». Температура — только число с °/градусов. Время в приборе — только из шага, где упомянут прибор или режим. | Режимы различаются у моделей; выдуманный режим опаснее, чем пропущенный. |
| FA-03 | Модель прибора, мощность и объём чаши не указываются. | В источнике их нет; закрытый мир запрещает их подставлять. |
| FA-04 | В git — только факты (ингредиенты, числа, режимы, хэш); текст шагов источника — в `var/food-appliances/private` (0700). | Права на текст источника не подтверждены; опубликованные шаги — свой текст черновиков. |
| FA-05 | Черновики написаны сессией Claude (`producer.mode=manual_standin`, `review_status=ai_draft`), не Qwen. | Канала к Qwen нет; результат Qwen не подменяется. |
| FA-06 | SharkNinja — только измерение хабов. Отдельные рецепты загружаются по пути, закрытому robots.txt, поэтому не загружались. | RFC 9309 соблюдается, обход не делается. |
| FA-07 | Аудит и импорт: www.sharkninja.com, 1000.menu, eda.rambler.ru (allowlist + тест матрицы). Импорт — только eda.rambler.ru (JSON-LD). | Хосты — из задания; другие не добавлялись. |
| FA-08 | Рецепты без изображений и видео: в Recipe нет `image`. | Своих фото нет, чужие не используются. |
| FA-B1 | Вариант B `step-console` — ветка `claude/template-food-appliances-b` от A (979df30), порт 8866, свои `console.css`/`console.js`, ключи `fab.*`. У A JavaScript нет. | Изоляция вариантов. |
| FA-B2 | Табло прибора сверху рецепта заменено настройками в самих шагах: режим, температура и время стоят в том шаге, где их называет источник (тест для всех рецептов); таймер — в шаге со временем. | Не прыгать между табло и шагами у плиты. |
| FA-B3 | Главная и страницы приборов — таблица сравнения: прибор, режимы, °C (без повторов), время в приборе по шагам, порции; «—» — источник не называет. | Сравнение без открытия рецептов. |
| FA-B4 | Отметки шагов сохраняются (`fab.steps.<slug>`), сброс одной кнопкой; без JS отметки и таймеры скрыты, шаги и настройки видны. | Прогрессивное улучшение. |
