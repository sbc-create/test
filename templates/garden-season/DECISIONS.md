# Решения garden-season

| ID | Решение | Почему |
| --- | --- | --- |
| GS-01 | ТЗ — задание владельца на ночь 12–13.10.2026 (очередь, п. 5: календарь с регионом и условиями, культура, сезонная задача, инструкция, подборка, поиск). | Прямое указание задания. |
| GS-02 | Источники сроков: OSU Extension (12 месячных календарей, Орегон) и RHS (цитаты, Великобритания). Хосты внесены в allowlist с provenance; UMN (403) не обходился и удалён. | Задание: «профильные садовые проекты, ботанические организации, университетские справочники». |
| GS-03 | У каждого пункта OSU сохраняется регион: явная пометка района → `or-west` / `or-east` / `or-local` (с исходной подписью); без пометки → `or-all` с оговоркой OSU о применимости. Префиксы времени («Early October») сохраняются отдельно. | «Не выдавай региональные сроки за универсальные». |
| GS-04 | Валидатор: месяц и регион срока = месяц и регион пункта; месяцы в тексте — только подтверждённые; числа — из пунктов или расчёта; запрещены «везде», «в любом регионе», «по всей России». | Те же правила проверяемы автоматически. |
| GS-05 | Сроков для регионов России в выбранных источниках нет; они не придумываются. Это прямо сказано на странице «Как читать сроки». | CLOSED_WORLD. |
| GS-06 | Тексты работ — сессия Claude (`manual_standin`, `ai_draft`), не Qwen. | Канала к Qwen нет. |
| GS-07 | Месяц без работ (декабрь) — 200 с пустым состоянием и ссылкой на календарь OSU, noindex, вне sitemap. | Честный сценарий вместо пустой страницы или 404 на рабочую ссылку из ленты месяцев. |
| GS-08 | Вариант A — `variant_id: month-calendar`, порт 8853, хранилище `gs-calendar:`. | Изоляция вариантов. |
| GS-C1 | Вариант C `my-plot` — ветка `claude/template-garden-season-c` от A (18e1723), порт 8868, свои `plot.css`/`plot.js`, ключи `gs-plot:*`. | Изоляция вариантов. |
| GS-C2 | «Мой участок»: регион (только регионы источников) + культуры + общие работы → календарь на год. Для районов Орегона добавляются сроки «весь штат» с подписью у каждой строки; Великобритания с Орегоном не смешивается (тест). Других регионов нет — сказано на форме. | Региональные сроки не выдаются за универсальные. |
| GS-C3 | Строка без месяца в источнике (например, окучивание картофеля у RHS) в календарь не попадает: месяц не придумывается. Пустой результат — честное «работ нет». Неизвестный регион или пустой выбор — 400 с сообщением. | Честность сроков. |
