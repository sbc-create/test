# Варианты garden-season: A (month-calendar) и B (region-timeline)

Один сайт, два способа подачи; публикуется один. Данные — один проверенный снимок в каждой ветке.

| | A — month-calendar | B — region-timeline |
| --- | --- | --- |
| ветка / порт | `claude/template-garden-season` / 8853 | `claude/template-garden-season-b` / 8854 |
| вход | лента 12 месяцев в шапке, год плитками | выбор региона источника; регион запоминается («Мой регион») |
| главная | год по месяцам → регионы → культуры → подборки | 4 карточки регионов → культуры |
| основной список | календарь: 12 карточек месяцев с фильтром по региону/типу | лента года одного региона с фильтрами-чипами по типу и культуре |
| работа | таблица «когда — регион — источник», одна колонка | шкала года «регион × месяц», две колонки (шаги / условия) |
| культура | таблица «регион × месяц» | карточки по регионам со списком месяцев |
| визуальная система | кремовая бумага, мох, солнечно-жёлтый, sans | хвойный верх, светлая бумага, терракота, serif-заголовки |
