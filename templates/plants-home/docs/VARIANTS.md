# Варианты plants-home: A (plant-catalog) и B (pick-and-diagnose)

Один сайт, два способа подачи; публикуется один. Данные — один проверенный снимок в каждой ветке.

| | A — plant-catalog | B — pick-and-diagnose |
| --- | --- | --- |
| ветка / порт | `claude/template-plants-home` / 8855 | `claude/template-plants-home-b` / 8856 |
| вход | «Сколько света у вас?» плитками, подборки, все карточки | мастер подбора из трёх вопросов + блок «что-то не так?» |
| список | карточки видов с фильтрами | таблица сравнения видов по свету, уходу, ядовитости, с сортировкой |
| карточка | паспорт условий сверху, уход разделами, проблемы | две колонки: уход списком и «если … то»; условия таблицей сбоку |
| особая страница | — | «Что случилось»: симптом → виды → что пишет источник |
| визуальная система | гербарий: слоновая кость, тёмная зелень, терракота, serif | мята, графит, коралл, крупные варианты ответа, sans |
