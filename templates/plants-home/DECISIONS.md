# Решения plants-home

| ID | Решение | Почему |
| --- | --- | --- |
| PH-01 | ТЗ — задание владельца на ночь 12–13.10.2026 (очередь: каталог, карточка растения, освещение и условия, уход, проблема/решение, подборки, поиск; учитывать вид и условия). | Прямое указание. |
| PH-02 | Источник фактов — NC State Extension Plant Toolbox (университет). MBG Plant Finder закрыт robots.txt — не обходился, хост удалён. RHS и botanichka — только референсы. | CLOSED_WORLD, robots. |
| PH-03 | Карточка = один вид = одна страница источника. Проблемы — только названные источником этого вида (проверка регулярным выражением по тексту источника). | «Учитывай конкретный вид». |
| PH-04 | Свет, почва, сложность ухода, размножение, ядовитость переводятся по фиксированному словарю (`flora/content.py`), без пересказа. | Перевод контролируемой лексики не добавляет фактов. |
| PH-05 | Hoya carnosa и Dracaena fragrans импортированы, но не опубликованы: на их страницах нет текста об уходе. | Карточка без ухода была бы пустой. |
| PH-06 | Ядовитость: показываем только то, что сказал источник; молчание источника ≠ безопасность (так и написано). | Безопасность детей и животных. |
| PH-07 | «around 50 degrees» без единицы у сансевиерии не используется — единицу не приписываем. | Не выдумывать шкалу. |
| PH-08 | Научное название — из источника (в т. ч. новое: Dracaena trifasciata, Streptocarpus ionanthus); русское — редакционное, помечено. | Прозрачность. |
| PH-09 | Тексты — сессия Claude (`manual_standin`, `ai_draft`), не Qwen. | Канала к Qwen нет. |
| PH-10 | Вариант A — `plant-catalog`, порт 8855, хранилище `ph-catalog:`. | Изоляция вариантов. |
| PH-B1 | Вариант B (`pick-and-diagnose`) начат с commit f0f5251 варианта A и переработан: свои шаблоны, `pick.css`, `pick.js`, порт 8856, хранилище `ph-pick:`. | Задание разрешает старт B с зафиксированного A. |
| PH-B2 | Главная — мастер подбора из трёх вопросов (свет, уход, дети/животные), работает GET-формой без JS; результаты с параметрами — noindex без canonical. | Другой способ навигации: от условий пользователя. |
| PH-B3 | При «есть дети или животные» результат делится на три группы по тому, что сказал источник: «не ядовито», «не указывает» (с предупреждением), «ядовито». Молчание источника не превращается в «безопасно» (тест). | Безопасность. |
| PH-B4 | Каталог — таблица сравнения видов (категории света, уход, ядовитость) с сортировкой; карточка — две колонки и «если … то»; диагностика «что случилось» — симптом → виды. | Отличие композиции трёх основных страниц. |
| PH-10 | Добавлено 5 видов (13.10, из ветки A c32e8c2: факты NC State, карточки, распознавание «mealy bugs»); страницы — из закрытого хранилища A, без сети. | Тот же каталог во всех вариантах. |
