# Решения games-rpg

| ID | Решение | Почему |
| --- | --- | --- |
| GR-01 | ТЗ — задание владельца на ночь 12–13.10.2026: игра, квест, персонаж, билд, предмет и механика; версия/патч там, где сведения от них зависят. | Прямое указание. |
| GR-02 | Игра — Baldur's Gate 3 по реестру games-ownership/1; источник — bg3.wiki (CC BY-NC-SA): только факты, свой текст, ссылка и дата. | Права на текст; «не копировать чужие статьи». |

| GR-04 | Билд — прогрессия класса из таблицы источника. Таблицы с ячейками заклинаний (Wizard, Cleric) не прошли проверку правдоподобия и не публикуются. | Не показывать неверные данные. |

| GR-07 | Вариант A — `codex-sections`, порт 8859, хранилище `grpg-codex:`. | Изоляция вариантов. |

| GR-C1 | Вариант C `index-compare` — ветка `claude/template-games-rpg-c` от A с предметами (0e68f8a), порт 8871, свои `index.css`/`index.js`, ключи `grpg-index:*`. | Изоляция вариантов. |

Сравнение предметов — таблица из инфобоксов (редкость, вид, урон, КД, вес, место), без цены. | Быстрый поиск по имени и сравнение по фактам. |
