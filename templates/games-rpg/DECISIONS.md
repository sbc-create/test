# Решения games-rpg

| ID | Решение | Почему |
| --- | --- | --- |
| GR-01 | ТЗ — задание владельца на ночь 12–13.10.2026: игра, квест, персонаж, билд, предмет и механика; версия/патч там, где сведения от них зависят. | Прямое указание. |
| GR-02 | Игра — Baldur's Gate 3 по реестру games-ownership/1; источник — bg3.wiki (CC BY-NC-SA): только факты, свой текст, ссылка и дата. | Права на текст; «не копировать чужие статьи». |
| GR-03 | Версия: Patch 8 (финальный крупный патч, 15 апреля 2025 года по вики); пометки о патчах на страницах источника показываются. | Сведения о механиках зависят от патча. |
| GR-04 | Билд — прогрессия класса из таблицы источника. Таблицы с ячейками заклинаний (Wizard, Cleric) не прошли проверку правдоподобия и не публикуются. | Не показывать неверные данные. |
| GR-05 | Предметы в этом выпуске не опубликованы: проверенные страницы предметов ещё не собраны — раздел появится, когда будут факты. | Пустой раздел был бы заглушкой. |
| GR-06 | Тексты — сессия Claude (`manual_standin`, `ai_draft`), не Qwen. | Канала к Qwen нет. |
| GR-07 | Вариант A — `codex-sections`, порт 8859, хранилище `grpg-codex:`. | Изоляция вариантов. |
| GR-B1 | Вариант B (`party-planner`) начат с 13b0901 (A) и переработан: свои шаблоны, `party.css`, `party.js`, порт 8860, хранилище `grpg-party:`. | Задание разрешает старт B с зафиксированного A. |
| GR-B2 | Вход — планировщик отряда: GET-форма (до 4 спутников, лишние отбрасываются с предупреждением), сводка считается на сервере и работает без JS. «Лучшая характеристика» при равенстве показывает всех обладателей (тест). | Не выдавать одного персонажа за единственного лидера. |
| GR-B3 | Персонажи — таблица сравнения характеристик с сортировкой по заголовку (состояние с параметром — noindex без canonical); материал — «лист персонажа» в две колонки. | Отличие композиции трёх основных страниц. |
| GR-B4 | Раздел «Предметы» перенесён из A (GR-08): тот же разбор инфобокса и 4 материала; страницы — из закрытого хранилища A, без сети. В планировщике отряда предметы не участвуют. | Тот же контент в обоих вариантах. |
| GR-09 | +4 предмета из ветки A (c71fd63, без сети): 8 предметов. | Тот же каталог во всех вариантах. |
