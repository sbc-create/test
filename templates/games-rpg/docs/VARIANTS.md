# Варианты games-rpg: A (codex-sections) и B (party-planner)

Один сайт, два способа подачи; публикуется один. Данные — один проверенный снимок в каждой ветке.

| | A — codex-sections | B — party-planner |
| --- | --- | --- |
| ветка / порт | `claude/template-games-rpg` / 8859 | `claude/template-games-rpg-b` / 8860 |
| главная | разделы справочника с карточками | планировщик отряда (до 4 спутников) + последний отряд |
| персонажи | карточки | таблица сравнения характеристик с сортировкой |
| материал | одна колонка «кодекса» | «лист персонажа» в две колонки |
| особая страница | — | сводка отряда: классы и лучшие характеристики (с равенствами) |
| визуальная система | пергамент, бордо, золото, serif | сланец, янтарь, плотные таблицы, sans |
