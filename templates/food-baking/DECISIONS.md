# Решения food-baking

| ID | Решение | Почему |
| --- | --- | --- |
| FB-01 | Сеть только к 3 хостам задания; тексты английских референсов не сохраняются, только измерения. | Задание называет King Arthur и Sally's; eda.rambler.ru — русский референс и источник фактов из исходного аудита. CLOSED_WORLD-конфликт тот же, что в food-daily FD-01; в замороженный `knowledge/DECISIONS.md` не пишем. |
| FB-02 | Публично — факты источника и собственный текст со ссылкой; исходные шаги — только в `var/food-baking/private`. | Те же права, что FD-02 food-daily: production — BLOCKED_RIGHTS до оценки. |
| FB-03 | Нет пересчёта порций и форм. | Задание прямо запрещает пересчёт формы или времени без проверенного алгоритма; пересчёт количеств без пересчёта формы для выпечки вводит в заблуждение. |
| FB-04 | Температура, время, форма и таймеры — только из шагов источника, с номером шага. | Нельзя придумывать режимы; таймер ведёт на шаг, откуда взято время. |
| FB-05 | Вид теста — по прозрачным правилам состава, страница вида — от 2 рецептов. | Без ручных ярлыков и пустых страниц. |
| FB-06 | Разбор ошибок — только предупреждения из конкретных шагов источника. | Общие советы без источника были бы выдумкой. |
| FB-07 | Черновики написаны сессией Claude (`manual_standin`), не Qwen. | Канала к Qwen нет (см. food-daily docs/INTEGRATIONS.md); контракт приёма тот же: факты неизменны, текст проверяется. |
| FB-08 | Файловый снимок вместо БД, редактор только для чтения. | Для 13 рецептов БД — лишняя инфраструктура; история версий — `data/history.jsonl`. |
| FB-B1 | Вариант B `oven-bench` — ветка `claude/template-food-baking-b` от A (8a5cb1e), порт 8864, свои `bench.css`/`bench.js`, ключи `fbb.*`, свой путь секрета редактора. | Изоляция вариантов. |
| FB-B2 | Главная — рецепты по первой (наибольшей) температуре духовки; без духовки — в конце. | Вход «разогрел духовку — что испечь». |
| FB-B3 | Пекарский процент = масса продукта / масса всей муки × 100, только для продуктов в г/кг; без муки в граммах колонки нет. Не масштабирование: значения источника не меняются. | Производное число только из чисел источника. |
| FB-B4 | Каталог — таблица сравнения (тесто, °C, время в духовке, мука, всего) с сортировкой; сортировка = noindex. Форма на главной не выводится: текст источника в косвенном падеже. | Компактное сравнение; без кривой грамматики. |
| FB-B5 | Отметки «отвешено» и шагов сохраняются (`fbb.weigh.<slug>`, `fbb.steps.<slug>`), сброс одной кнопкой; таймеры стоят в шаге, где источник называет время. Тест JSON-LD перенесён на строки таблицы «Отвесить» с тем же инвариантом. | Рабочий лист вместо разворота книги. |
| FB-B6 | Подсказка поиска «Например: слива, заварное» обрезалась на 320–390 px — сокращена до «Слива, заварное». В A тот же текст: проверить ширины страницы поиска там. | Найдено проверкой ширин B. |
