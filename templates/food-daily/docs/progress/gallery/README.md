# Галерея вариантов

`index.html` — открыть файлом или `python3 -m http.server 8877 --bind 127.0.0.1` в этой папке.
`gallery.json` — данные (доказательства веток + повторный опрос превью, флаг `primary` — решение владельца 13.10.2026),
`recommendations.json` — обоснование выбора, `check-result.json` — проверка самой страницы в Chromium
(320/390/768/1440 × светлая/тёмная тема, axe 0), `click-result.json` — переходы из 30 карточек и 10 строк таблицы
основных вариантов (код, свой variant-id, noindex открывшейся страницы). Запуск всего локально — `RUN-LOCAL.md`.

Генератор и проверка читают рабочие деревья всех 30 вариантов, поэтому в шаблон food-daily не входят:
тест изоляции шаблона (`tests/test_isolation.py`) запрещает исходникам ссылаться на другие сайты.
