## Распределение тем между кулинарными сайтами

Источник — `data/topic-map.csv` (153 темы, у каждой одно основное место).

| сайт | тем | что забирает | примеры |
| --- | ---: | --- | --- |
| food-daily | 134 | завтраки, супы, вторые блюда, гарниры, салаты, закуски на каждый день | сырники, борщ, плов с курицей, гречка по-купечески |
| food-baking | 12 | выпечка, тесто, десерты, хлеб, пицца как тесто | шарлотка, пироги, чизкейк, домашний хлеб |
| food-appliances | 5 | блюда, где прибор — главный интент | мультиварка, аэрогриль, гриль, микроволновка, на пару |
| food-weekly | 2 | меню и планы: **ссылки на рецепты сети**, без копий страниц | меню на неделю, что приготовить на ужин |

Правила на границах: рецепт с прибором в названии («солянка в мультиварке»)
относится к food-appliances, даже если блюдо повседневное; food-daily
ссылается на него, а не дублирует. food-weekly собирает планы из
опубликованных URL других сайтов и своих рецептов не создаёт. Одинаковые
тексты на разные домены автоматически не размножаются.

## Общие правила для всех шаблонов

* своя ветка `claude/template-<site_id>`, свой worktree `/home/claude/wt-template-<site_id>`
  (каталог сначала проверить; существующий чужой не переиспользовать);
* область записи — только `templates/<site_id>/**`; общий lockfile, ядро,
  CI, соседние шаблоны и действующие сайты не меняются;
* собственные страницы, компоненты, стили, ресурсы, сборка; общие стили,
  layout и UI-компоненты между шаблонами запрещены; смена цвета одного шаблона
  отдельным дизайном не считается;
* runtime: свой порт на петле, своя БД, медиа, кэш, очередь, секреты;
* сетевые хосты — только перечисленные владельцем, через allowlist;
* контент: факты источника + собственный текст + ссылка; без выдуманных
  оценок, авторов и дат; ИИ-текст раскрывается;
* приёмка: SSR, SEO-матрица и тесты как в `templates/food-daily/tests`, закрытый
  preview, скриншоты двух размеров, отчёт с командами и exit code.

## ТЗ TEMPLATE-FOOD-APPLIANCES-01 — «Готовим в технике»

* ветка `claude/template-food-appliances`; worktree `/home/claude/wt-template-food-appliances`; write scope `templates/food-appliances/**`.
* Интент: блюда и режимы конкретных приборов (аэрогриль, мультиварка, гриль). Главная сущность — **прибор и режим**, а не блюдо.
* Страницы: прибор → режимы → рецепты; рецепт показывает режим, температуру и время **по данным источника**, без пересчёта времени при смене порций; таблица «чем различаются модели» — только из документации производителя (новый хост — только с разрешения владельца).
* Визуальная система: технический, «приборная панель», тёмный акцент, иконки режимов; ничего из food-daily.
* Темы на старт: 5 из `topic-map.csv` + разведка слагов `v-multivarke`, `v-aerogrile` в реестре (`data/inventory/*.jsonl.gz`).
* Приёмка: ≥20 рецептов в preview по ≥3 приборам, режимы в JSON-LD не выдумываются.

## ТЗ TEMPLATE-FOOD-BAKING-01 — «Тесто и десерты»

* ветка `claude/template-food-baking`; worktree `/home/claude/wt-template-food-baking`; write scope `templates/food-baking/**`.
* Интент: виды теста, пересчёт ингредиентов **по массе и форме** (диаметр формы), причины ошибок выпечки.
* Функции: калькулятор формы (круглая ↔ прямоугольная) только для количеств; температура и время не пересчитываются; раздел «почему не получилось» — только с источником.
* Визуальная система: кондитерская, пастель + шоколад, крупная фотографичная сетка (до появления своих фото — свои иллюстрации).
* Темы: 12 из `topic-map.csv` + выпечка из реестра (pirog, tort, keks, pechene, bulochki).
* Приёмка: ≥20 рецептов, ≥3 вида теста, калькулятор формы покрыт тестами.

## ТЗ TEMPLATE-FOOD-WEEKLY-01 — «Меню на неделю»

* ветка `claude/template-food-weekly`; worktree `/home/claude/wt-template-food-weekly`; write scope `templates/food-weekly/**`.
* Интент: готовые планы питания и список покупок. **Рецепты не копируются**: план ссылается на опубликованные URL сайтов сети (по их sitemap/снимку).
* Функции: план на 7 дней, сводный список покупок с суммированием одинаковых продуктов и единиц, замена блюда в плане.
* Зависимость: опубликованные рецепты food-daily/food-baking (до production — preview-снимки как фикстуры, честно помеченные).
* Референс: menunedeli.ru (меню, видео в рецептах) — см. `docs/audit/competitor-audit.md`.
* Приёмка: ≥4 плана, список покупок без дублей, ни одной копии страницы рецепта.
