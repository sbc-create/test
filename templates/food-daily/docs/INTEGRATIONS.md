### Handoff в общий контур (не делалось в этой ветке)

1. **seo-engine**: выдать food-daily собственную scoped-учётку только на чтение и
   tenant `food-daily`; добавить в `openapi-v1.json` `securitySchemes`; после
   этого адаптер `SeoEngineProvider` сможет наполнять снимок. До этого
   multi-tenant разграничение для food-daily не подтверждено.
2. **Qwen**: инструмент моста `food_daily_jobs` (только чтение outbox) и
   `food_daily_submit` (запись ответа в inbox с той же схемой) — тогда Qwen
   пишет черновики сам, а импорт и все проверки остаются прежними.
3. **ChangeSet**: если появится общий контракт, food-daily переводит `versions`/
   `audit` на него адаптером; формат журнала уже содержит actor, версию, причину.

## YouTube для игровых сайтов — контракт (без реализации)

Реализация — в ветке игрового шаблона. Пример данных — `data/youtube-contract.example.json`.

* поиск: официальный YouTube Data API `search.list` с `type=video` и
  `videoEmbeddable=true`; затем `videos.list` (`status.embeddable`,
  `status.privacyStatus=public`, `contentDetails.duration`, `snippet.channelId`);
* отдельно хранятся: `video_id`, `channel_id`, `checked_at`, `embeddable`,
  `availability`, `relevance` (смысловое соответствие гайду проверяется
  человеком или моделью по описанию/субтитрам — не по заголовку);
* таймкоды — только подтверждённые (`timestamps_source`), не по заголовку;
* показ — официальный embed `youtube-nocookie.com/embed/<id>` или ссылка;
  ролик не скачивается; поверх плеера своя реклама и pre-roll не ставятся;
  просмотры YouTube не считаются нашими рекламными показами;
* одна игра закреплена за одним игровым сайтом сети.

## Реклама: режимы

| режим | что это | наша реклама |
| --- | --- | --- |
| собственный ролик (in-stream) | наш файл в нашем плеере | возможен pre/mid-roll по правилам поставщика, после проверки ролика |
| out-stream | рекламный блок вне плеера | места с заранее заданной высотой, не перекрывают ингредиенты, шаги и управление видео |
| YouTube embed | чужой плеер | запрещено накладывать и ставить перед ним |
| лицензированное видео | по условиям лицензии | только если лицензия разрешает |

Семантика события `event 3` из существующего рекламного контракта фабрики
в food-daily не используется: рекламного контракта для этого сайта нет.
Sticky-форматы — только в разрешённом поставщиком режиме.
