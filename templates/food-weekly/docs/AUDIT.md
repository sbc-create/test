## Структура (до кода)

| страница | адрес | что делает |
| --- | --- | --- |
| главная | `/` | планы недели, как планировать, подборки |
| каталог меню | `/menyu/` | все планы с короткой сеткой |
| неделя | `/menyu/<план>/` | таблица 7 дней × завтрак/обед/ужин, замена блюда (форма, работает без JS), итог по времени |
| день | `/menyu/<план>/den-<N>/` | три блюда дня, ссылки на рецепты |
| список покупок | `/menyu/<план>/pokupki/` | сумма продуктов по всем рецептам недели с учётом замен и числа порций, единицы не смешиваются |
| инструкция | `/kak-planirovat/` | как пользоваться планом, заменой и списком |
| подборка | `/podborki/<id>/` | тематический отбор блюд из каталога сети (например, быстрые ужины) |
| поиск | — | в этой версии не нужен: 3 плана; каталог сети ищется на сайте рецептов |

## Улучшения

1. **Неделя видна сеткой**, а не спрятана в тексте статьи.
2. **Список покупок считается** из количеств реальных рецептов соседнего сайта и пересчитывается при замене блюда и смене числа порций; одинаковые продукты с разными единицами не складываются.
3. **Замена блюда без регистрации и без JS**: выбор сохраняется в адресе (`?zamena=…`), такая страница не индексируется.
4. **Рецепты не копируются**: план ссылается на материал сайта «Будни на кухне» по `content_id` из ленты `recipe-catalog/1`.
5. **Честный статус связи**: сосед пока в закрытом preview — ссылки ведут туда, это видно в подвале и в отчёте.
