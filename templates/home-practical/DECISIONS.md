# Решения home-practical

| ID | Решение | Почему |
| --- | --- | --- |
| HP-01 | ТЗ сайта — задание владельца на ночь 12–13.10.2026 (п. 2); отдельного документа на сервере нет и он больше не требуется. | Прямое указание задания. |
| HP-02 | Источники выбраны самостоятельно: IKEA (документация производителя), CPSC Anchor It! (организация), ivd.ru (референс). Каждый хост внесён в allowlist с provenance; хосты с 401/403 (Лемана ПРО, The Spruce, Apartment Therapy) удалены, защита не обходилась. | Задание разрешает выбор; CLOSED_WORLD: только открытые и прочитанные страницы. |
| HP-03 | В git — только факты источника (URL, дата, sha256 страницы, размеры, нагрузки, предупреждения, уход, короткие цитаты); сами страницы — в `var/home-practical/private` (0700). Ручные цитаты сверяются с текстом страницы дословно при импорте. | Происхождение проверяемо, чужой текст не публикуется. |
| HP-04 | Тексты инструкций написаны сессией Claude (`producer.mode=manual_standin`, `review_status=ai_draft`). | Это не результат Qwen и не проверено редакцией — так и показано на страницах. |
| HP-05 | Число в тексте допустимо, только если оно есть в фактах источников этого материала или получено расчётом `calc`, который пересчитывается при сборке. | Нельзя выдумывать размеры и нагрузки. |
| HP-06 | Требование производителя и рекомендация организации ссылаются на источник своего вида; совет редакции помечен и на источник как на требование не ссылается. | Требование задания: редакционные рекомендации отличать от требований производителя. |
| HP-07 | Нет цены, рейтинга, отзывов и времени выполнения (валидатор их отклоняет). | Не проверялись; запрещено заданием. |
| HP-08 | Изображений товаров нет. Карточки и разделы используют собственные SVG-пиктограммы помещений (декоративные, `alt=""`). | Чужие фото не копируются; одинаковая фотография для разных материалов не используется. |
| HP-09 | Сохранённое и отметки чек-листа — localStorage с пространством имён варианта (`hp-rooms:`), отметки привязаны к версии текста. | Регистрации нет; варианты A и B не делят состояние. |
| HP-10 | Вариант A — `variant_id: rooms-cards` (мета `site-factory-variant-id`, по образцу фабрики), порт 8851; вариант B — `problem-checklists`, своя ветка, порт 8852. | Варианты для выбора, изолированы. |
| HP-11 | Набор SKÅDIS исключён из материалов. | Из карточки подтверждается слишком мало для полной инструкции. |
| HP-C1 | Вариант C `home-audit` — ветка `claude/template-home-practical-c` от A (19fb887), порт 8867, свои `audit.css`/`audit.js`, ключи `hp-audit:*`. | Изоляция вариантов. |
| HP-C2 | Обход квартиры: шесть помещений по очереди, в каждом — ситуации из поля «где применимо» инструкций; выбор переносится в адресе (`?m=`), работает без JS, с JS ещё и запоминается. Страницы обхода и плана с выбором — noindex без canonical; без выбора — индексируемые. | Вход «пройди дом», а не «найди статью». |
| HP-C3 | План: инструкции по комнатам и общий список «Что понадобится», собранный из разделов инструкций; одинаковые пункты объединяются только при совпадении текста. Никаких сроков, цен и оценок сложности. | Не придумывать длительность и стоимость. |
| HP-C4 | Найдено проверкой: переход по номеру комнаты терял свежие отметки текущей страницы — ссылки обхода собирают адрес из текущего выбора в момент клика (действие `plan_has_both_choices`). | Не терять выбор пользователя. |
