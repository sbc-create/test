# Варианты home-practical: A (rooms-cards) и B (problem-checklists)

Один сайт, два способа подачи для выбора. Публиковать оба на разных доменах нельзя: материалы одинаковые.

| | A — rooms-cards | B — problem-checklists |
| --- | --- | --- |
| ветка / порт | `claude/template-home-practical` / 8851 | `claude/template-home-practical-b` / 8852 |
| вход | плитки 6 помещений с пиктограммами, затем задачи и подборки | список 6 проблем с симптомами («Что мешает дома?») |
| главная | герой с поиском → помещения → задачи → подборки → карточки | проблемы (нумерованный список) → поиск «опишите словами» → вся таблица инструкций |
| каталог | карточки + фильтр двумя списками | компактная таблица + переключатели помещения/задачи + сортировка (помещение, задача, название) |
| инструкция | одна колонка: паспорт-плашка → «где подходит» → что потребуется → шаги (нумерованные карточки) → ограничения блоками → чек-лист | две колонки: шаги-чек-лист с прогрессом и «Следующий шаг» → итоговая проверка → ограничения таблицей; сбоку паспорт, материалы, «где подходит» |
| дополнительная страница | — | страница проблемы: решения по порядку и прогресс по каждому |
| визуальная система | льняной фон, тёмно-зелёный и глина, serif-заголовки, скруглённые карточки | белая бумага, графит, жёлтый маркер, плотные списки и таблицы, без пиктограмм |
| состояние в браузере | `hp-rooms:` — сохранённое, отметки итогового чек-листа | `hp-problems:` — сохранённое, отметки шагов, отметки итоговой проверки |
| общие данные | один и тот же проверенный снимок `data/` (13 инструкций, 15 источников) в каждой ветке | |
