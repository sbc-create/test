## Улучшения, которые реализованы (5)

1. **Связи в обе стороны:** «Из чего делается» и «Что можно сделать» строятся из ингредиентов рецептов источника, а не вручную (тест графа).
2. **Цепочка старта на главной:** Бревно → Доски → Палка → Верстак → Факел, каждая ступень — ссылка.
3. **Количества только из сетки:** валидатор отклоняет число, которого нет в фактах источника (тест).
4. **Чужие строки отсекаются:** ингредиенты с цифрами/процентами/скобками (лут, вместимость) и дубли не попадают в рецепты (тест).
5. **Одна игра — один сайт:** реестр games-ownership/1; Celeste и Baldur's Gate 3 здесь отдают 404 (тест).
