## Улучшения, которые реализованы (5)

1. **Связи в обе стороны:** «Из чего делается» и «Что можно сделать» строятся из ингредиентов рецептов источника, а не вручную (тест графа).
2. **Цепочка старта на главной:** Бревно → Доски → Палка → Верстак → Факел, каждая ступень — ссылка.
3. **Количества только из сетки:** валидатор отклоняет число, которого нет в фактах источника (тест).
4. **Чужие строки отсекаются:** ингредиенты с цифрами/процентами/скобками (лут, вместимость) и дубли не попадают в рецепты (тест).
5. **Одна игра — один сайт:** реестр games-ownership/1; Celeste и Baldur's Gate 3 здесь отдают 404 (тест).

## Вариант B: что меняется относительно A (craft-tree)

| страница | A (craft-tree) | B (craft-planner) | почему |
| --- | --- | --- | --- |
| главная | цепочка старта и карточки по разделам | форма «что и сколько», плитки быстрого выбора, ресурсы и биомы чипами | задача игрока — «сколько нужно на N», а не «что бывает» |
| раздел | сетка карточек с описанием | компактная таблица: название, имя в вики, куда идёт, «Посчитать» | быстрый просмотр десятка строк на телефоне |
| предмет | карточки рецептов со схемой 3×3, связи списками | таблица рецептов, «на один крафт» по слотам, таблица «Куда идёт» с выходом | количества нужны для расчёта, схема — нет |
| планировщик | нет | шаги по порядку с отметками (сохраняются), базовые ресурсы, излишек, печать | новый сценарий |

Улучшения B (4): количество ингредиента по занятым слотам сетки источника (тест: сумма = число слотов);
суммирование спроса по веткам с округлением вверх и показом излишка; ввод проверяется (1–64; иначе 400 и сообщение);
расчёт делается на сервере — без JS план полный.
