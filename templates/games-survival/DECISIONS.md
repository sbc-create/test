# Решения games-survival

| ID | Решение | Почему |
| --- | --- | --- |
| GV-01 | ТЗ — задание владельца на ночь 12–13.10.2026: игра, ресурс, крафт, постройка, биом, проверяемые связи между материалами и поиск. | Прямое указание. |
| GV-02 | Игра — Minecraft по реестру games-ownership/1; источник — minecraft.wiki: только факты (рецепты, вводные сведения), свой текст, ссылка и дата. | Права на текст. |
| GV-03 | Версия: Java Edition 26.3 — так главная вики называет текущую на день чтения. Bedrock не рассматривается. | Рецепты зависят от версии. |
| GV-04 | Связи «из чего → во что» вычисляются из ингредиентов рецептов источника; переплавка (печь) в связи не входит и описана словами. | Не придумывать связи. |
| GV-05 | Рецепты кирки не опубликованы: таблица Pickaxe на вики в другом формате, разбор ненадёжен. Страницы инструментов появятся вместе с надёжным разбором. | Не показывать неверные данные. |
| GV-06 | «Постройки» как отдельный раздел не выпущены: проверяемых фактов о постройках не собрано. Верстак, печь и сундук — блоки, они в «Предметах и блоках». | Пустой раздел был бы заглушкой. |
| GV-07 | Схема 3×3 условная: показывается число занятых клеток, не расположение (оно в источнике бывает анимированным). Об этом сказано под рецептами. | Честность изображения. |
| GV-08 | Тексты — сессия Claude (`manual_standin`), не Qwen. | Канала к Qwen нет. |
| GV-09 | Вариант A — `craft-tree`, порт 8861, хранилище `gsv-tree:` (сейчас не используется: только печать). | Изоляция вариантов. |
| GV-10 | Ремонт («Damaged Shield» → Shield) не считается рецептом: результат совпадает с ингредиентом. Найдено при работе над B. | Ремонт ≠ крафт. |
