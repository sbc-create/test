# Решения games-survival

| ID | Решение | Почему |
| --- | --- | --- |
| GV-01 | ТЗ — задание владельца на ночь 12–13.10.2026: игра, ресурс, крафт, постройка, биом, проверяемые связи между материалами и поиск. | Прямое указание. |
| GV-02 | Игра — Minecraft по реестру games-ownership/1; источник — minecraft.wiki: только факты (рецепты, вводные сведения), свой текст, ссылка и дата. | Права на текст. |
| GV-03 | Версия: Java Edition 26.3 — так главная вики называет текущую на день чтения. Bedrock не рассматривается. | Рецепты зависят от версии. |
| GV-04 | Связи «из чего → во что» вычисляются из ингредиентов рецептов источника; переплавка (печь) в связи не входит и описана словами. | Не придумывать связи. |
| GV-05 | Рецепты кирки не опубликованы: таблица Pickaxe на вики в другом формате, разбор ненадёжен. Страницы инструментов появятся вместе с надёжным разбором. | Не показывать неверные данные. |
| GV-06 | «Постройки» как отдельный раздел не выпущены: проверяемых фактов о постройках не собрано. Верстак, печь и сундук — блоки, они в «Предметах и блоках». | Пустой раздел был бы заглушкой. |
| GV-07 | Схема 3×3 условная: показывается число занятых клеток, не расположение (оно в источнике бывает анимированным). Об этом сказано под рецептами. | Честность изображения. |
| GV-08 | Тексты — сессия Claude (`manual_standin`), не Qwen. | Канала к Qwen нет. |
| GV-09 | Вариант A — `craft-tree`, порт 8861, хранилище `gsv-tree:`. | Изоляция вариантов. |
| GV-10 | Вариант B — `craft-planner`, порт 8862, хранилище `gsv-plan:` (отметки шагов плана); ветка от A db40378. | Изоляция вариантов. |
| GV-11 | Парсер 1.1 сохраняет первое название в каждом занятом слоте (`slot_items`); количество ингредиента = число его слотов. Страницы перечитаны из `var/…/private`, без сети. | Количества нужны для расчёта; не угадывать. |
| GV-12 | Планировщик берёт первый рецепт предмета, все слоты которого — материалы сайта; иначе предмет базовый. Железный слиток — базовый: на верстаке он делается только из блока железа или самородков, которых на сайте нет; переплавка не считается. | Не изобретать путь крафта. |
| GV-13 | Ремонт («Damaged Shield» → Shield) не считается рецептом: результат совпадает с ингредиентом. Исправлено и в A отдельным коммитом. | Ремонт ≠ крафт. |
| GV-14 | Количество в планировщике — 1–64; страницы с параметрами — noindex и без canonical, сама страница выбора индексируема. | Бесконечные URL не индексируются. |
| GV-15 | Раздел «Постройки» из A (GV-11): страницы источника скопированы из закрытого хранилища A и разобраны парсером B 1.1.1 без сети. Забор и ступеньки — цели планировщика (все слоты — материалы сайта); кровать — нет (шерсти на сайте нет); дверь — без рецепта. | Тот же контент, что в A; расчёт только по полным рецептам. |
| GV-C1 | Вариант C `inventory-first` — ветка `claude/template-games-survival-c` от B (978d803: нужен разбор slot_items), порт 8872, свои `inv.css`/`inv.js`, ключи `gsv-inv:*`; планировщик B сохранён на `/planirovshchik/`. | Изоляция вариантов. |
| GV-C2 | «Из того, что есть»: ингредиенты — предметы в занятых слотах сетки источника, количество — число слотов (тест на всех рецептах). «Можно сейчас» — все ингредиенты отмечены; «не хватает одного» — ровно один нет (рецепты из одного ингредиента сюда не попадают). Ингредиент, которого нет на сайте, называется как в источнике с пометкой «на сайте нет». Переплавка не учитывается. | Не придумывать рецепты и замены. |
| GV-16 | Кирка из A (GV-12): парсер 1.1.2 разбирает слот результата с атрибутами и хранит все варианты результата. Планировщик не берёт рецепты с анимированной сеткой (шаг «Кирка» по первому кадру скрыто означал бы деревянную); в инвентаре C результат показан как есть («Wooden Pickaxe × 1»). | Не выдавать вариант за общий предмет. |
| GV-17 | Топор, лопата, меч из A (GV-13), страницы — из закрытого хранилища A, без сети; запрет цен не срабатывает на «рубит». Планировщик их не считает (перебор уровней, GV-16). | Тот же каталог во всех вариантах. |
