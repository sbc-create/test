# Audit Ledger — изменения

## R2 (FLEET-CORE-002-AUDIT-LEDGER.R2)

Исходный код журнала и контрактов перенесён в канонический репозиторий.
До этого он существовал только в рабочем каталоге, и работающую службу нельзя
было связать ни с одним коммитом: релиз `52fd0665` содержал правки `app.py` и
`server.py`, которых нет в его собственном дереве.

* `factory/site_engine/audit/` — хранилище, личность, HTTP-обработчик, мост,
  публикация, резервное копирование, карантин, операционная проекция;
* Control API подключает журнал обычным импортом пакета: подмена `sys.path`
  на внешний каталог убрана;
* `tests/audit/` и изолированный прогон `run_tests.py`;
* `contracts/control-plane/` — бандл и сборщик;
* `automation/host/units/site-factory-audit-bridge.service` — мост как
  постоянная служба с замком единственного экземпляра;
* роли читателей и отзыв токенов по отпечатку;
* разделение сырой ленты и рабочей проекции.

В Git не входят: база журнала, лента, курсоры, DLQ, резервные копии,
манифесты карантина, токены.

## R1

Первая рабочая версия: append-only на уровне API и триггеров БД, выведение
личности сервером, матрица владения, идемпотентность, цепь хешей, checkpoint,
сверка с реестром, локальная копия и восстановление в изоляции.
