# Тесты

- Тест доказывает поведение, а не существование файла. Проверка «файл создан» без
  проверки эффекта не считается тестом.
- Каждое нормативное требование имеет ID `REQ-*` и связано с тестом
  (`tests/test_traceability.py` падает, если связь потеряна).
- Негативные fixtures обязательны: на каждый блокирующий статус есть пакет, который
  его вызывает.
- Тесты не выходят в сеть, кроме `127.0.0.1` пилотного окружения.
- Тесты не пишут за пределы `var/` и `artifacts/`.
- Отчёт содержит фактический exit code и путь к артефакту. Утверждение о проверке,
  которая не запускалась, — ошибка, а не стилистика.
