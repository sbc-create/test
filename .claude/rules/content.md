# Контент, права и VK

- Контент никогда не генерируется фабрикой. Источник — только site package.
- Отсутствующий обязательный факт (в т.ч. `alt` изображения) блокирует публикацию
  конкретного материала. Значение по умолчанию не подставляется.
- VK: только переданные content/video ID из разрешённого каталога с rights manifest.
  Общий поиск по VK, случайные публичные ролики, скачивание и перезалив запрещены.
- Недоступный/удалённый ролик → состояние `content_unavailable` и техническое событие.
  Подстановка другого ролика запрещена.
- Реклама — только через переданный contract VK/Adman/AdTech с placement/product IDs и
  разрешёнными событиями. SDK-методы, targeting-поля, пиксели и fallback не выдумываются.
- Секретные токены VK/рекламного API остаются server-side.
- Мимикрия под VK, правообладателя, телеканал или бренд запрещена в домене, логотипе,
  title и интерфейсе.
- placeholder, lorem ipsum, demo-аккаунты и заглушки не публикуются.
