# Конфигурация веб-сервера

Шаблон `automation/ansible/roles/dle_site/templates/nginx-site.conf.j2` — базовый.
Он **не содержит** предположений о внутренней структуре DLE: перечень закрываемых
путей (`public_deny_paths`), точки входа установщика и правила SEO-URL приходят из
`blueprints/dle20/profiles/paths.yaml`, который заполняется из официальной документации.

Пока профиль не заполнен, `factory deploy` на SSH-цель возвращает `BLOCKED_INPUT`.
Конфигурация Apache добавляется тем же способом после получения официальных рекомендаций.
