# Инструменты приёмки

Собирается из самих сценариев: `python3 tests/tools/tools_index.py --write`.
Правка этого файла руками бессмысленна — описание берётся из первой
содержательной строки инструмента, и проверка сверяет их.

| инструмент | что делает |
|---|---|
| `admin_journey_e2e.js` | Полный редакционный путь: одиннадцать разделов, две роли, три ширины и 200 % |
| `admin_journey_e2e.sh` | Полный редакционный путь по каждому движку |
| `admin_overview_content_e2e.js` | Браузерная приёмка разделов «Сводка» и «Каталог» |
| `admin_review_e2e.js` | Браузерная приёмка редакторского пути очереди разбора |
| `admin_settings_e2e.js` | Браузерная приёмка разделов «Настройки» и «Люди» |
| `admin_settings_e2e.sh` | Прогон приёмки настроек по каждому движку |
| `admin_smoke.py` | Проверка, что админка действительно поднимается и отвечает |
| `base_url.py` | Печатает базовый URL текущей цели пилота |
| `browser_multisite.py` | Браузерная приёмка трёх сайтов: наполняет стенд, поднимает сервер, гоняет Playwright |
| `check_browser_audit.py` | Проверяет артефакт браузерной приёмки последнего задания |
| `check_yaml.py` | Статическая проверка YAML репозитория (исключая var/ и node_modules) |
| `collect_evidence.py` | Собирает курируемый набор доказательств последнего чистого прогона |
| `control_center_e2e.js` | Браузерная приёмка центра управления: роли, ширины, клавиатура |
| `control_center_e2e.sh` | Браузерная приёмка центра управления по каждому движку |
| `control_vertical_e2e.js` | Вертикальный путь центра управления в браузере, одним прогоном |
| `control_vertical_e2e.sh` | Браузерная приёмка центра управления по каждому движку |
| `cross_site_uniqueness.py` | Прогон ворот cross_site_uniqueness по фактически отданным страницам трёх сайтов |
| `dns_check.py` | Проверка делегации и A-записей доменов Lords |
| `domain_docs.py` | Локальные инструкции по доменам — собираются из реестра, а не пишутся рядом |
| `fixture_catalog.py` | Набор записей стенда для витрин, чей пакет объявляет источник `fixture` |
| `fleet_e2e.sh` | Приёмка контура сайта по каждому движку |
| `fleet_pilot_watch.sh` | Наблюдение за пилотом флота: снимок каждую минуту |
| `fleet_stand.py` | Стенд флота: две витрины семейства и операторы на каждой |
| `frontend_http.py` | HTTP-проверка трёх сайтов на одном приложении |
| `lords_public_acceptance.sh` | Публичная приёмка канареечного релиза lords-02 |
| `lords_public_browser.js` | Браузерная приёмка боевой витрины Lords: два движка, реальный домен |
| `lords_public_browser.sh` | Браузерная приёмка боевой витрины Lords в двух движках |
| `lords_release_diff.py` | Сверка состояния витрины до и после операции |
| `lords_staging_stand.py` | Локальный запуск трёх публичных стендов Lords из настоящих пакетов |
| `lords_stand.py` | Локальный стенд направления Lords: четыре сайта на четырёх портах |
| `measure_reference.js` | Измерение референсного интерфейса. Скрипт СЧИТАЕТ, а не копирует: наружу |
| `module_map.py` | Карта модулей: кто кого импортирует, где циклы, кто пишет в общие файлы |
| `mutation_isolation.py` | Мутационная проверка критических ворот: изоляция сайтов и SEO |
| `new_site_e2e.js` | Браузерная приёмка мастера заведения витрины |
| `new_site_e2e.sh` | Мастер заведения витрины по каждому движку |
| `operator_identity_e2e.js` | Браузерная приёмка операторского контура |
| `operator_identity_e2e.sh` | Прогон операторского E2E по каждому движку с чистого состояния |
| `player_first_frame.js` | Проверка ФАКТИЧЕСКОГО начала воспроизведения |
| `public_account_e2e.js` | Браузерная приёмка публичного контура учётной записи |
| `public_account_e2e.sh` | Публичный контур учётной записи: прогон по каждому движку с чистого состояния |
| `rating_coverage.py` | Покрытие оценок на одном зафиксированном снимке каталога |
| `rating_source_probe.py` | Ответ на HANDOFF-043 §6: исчерпан ли источник оценок или теряет проекция |
| `rating_votes_probe.py` | Ответ на HANDOFF-043 §6, вопрос второй: отдаёт ли поставщик число голосов |
| `restore_proof.py` | Доказательство восстановления из бэкапа, а не наличия файла бэкапа |
| `review_workflow_e2e.js` | Браузерная приёмка рабочего потока разбора |
| `screenshot_manifest.py` | Манифест скриншотов приёмки: имя, размер и SHA-256 каждого снимка |
| `search_candidate_threshold.py` | Опыт: меняет ли выдачу более строгий отбор кандидатов |
| `search_divergence_probe.py` | Какая выдача расходится с перебором и почему |
| `search_index_cost.py` | Стоимость самого указателя, без сети и без отрисовки страницы |
| `search_latency_probe.py` | Замер подсказки с переиспользованием соединения |
| `secret_scan.py` | Поиск секретов в том, что попадает в git и в артефакты |
| `site_admin_fleet_e2e.js` | Браузерная приёмка контура сайта: один сайт семейства, полный путь |
| `site_registry.py` | Реестр реальных витрин: что действительно развёрнуто, а не что объявлено |
| `state_owners.py` | Какая подсистема какие области состояния трогает |
| `summarize_run.py` | Сводная таблица полного прогона |
| `template_stand.py` | Стенд шаблонов: каждый шаблон направления на своём порту, без пакета сайта |
| `tools_index.py` | Указатель инструментов приёмки: собирается из них самих |
| `with_app_env.py` | Запускает команду приложения с секретами в окружении, но не в логе |
| `with_test_server.sh` | Поднять тестовый сервер, выполнить команду, гарантированно убрать за собой |
