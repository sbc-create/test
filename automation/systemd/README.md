# Юниты перепроверки доступности

Файлы подготовлены, но **не установлены и не включены**. Установка и включение —
отдельное решение владельца вместе с включением `availability_gate` в профилях
витрин: до этого момента карантин ничего не меняет, а юниты только собирали бы
статистику.

Два прохода различаются не частотой ради частоты, а ценой:

* `nova-availability-quarantined` — каждые пять минут, но только по записям,
  которые уже в карантине, и по тем, которых в реестре ещё нет. Это десятки
  запросов, и именно этот проход возвращает карточку, как только у поставщика
  появляется видео.
* `nova-availability-full` — раз в сутки по всему каталогу. Полный проход — это
  десятки тысяч запросов, и гонять его каждые пять минут значило бы устроить
  поставщику нагрузочное тестирование.

Установка (когда владелец примет решение):

```
install -m 0644 automation/systemd/nova-availability-*.service /etc/systemd/system/
install -m 0644 automation/systemd/nova-availability-*.timer   /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now nova-availability-quarantined.timer nova-availability-full.timer
```
