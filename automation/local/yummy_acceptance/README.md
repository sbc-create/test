# Приёмка карт Yummy по собственному каталогу домена

Только GET к самому домену, UA `sf-seo-audit/1.0`. Эталон — опубликованный каталог ЭТОГО домена; карта другого домена эталоном не служит.

Рабочий каталог — `var/seo-audit/yummy-sitemap-20261021/` (не в git): туда скопировать скрипты и запускать оттуда.

- `yummy_recheck.py <домен> [параллельность]` — всё одной командой: снимок частей карты, обход листалки, догон тайтлов из titles.xml, новый baseline, приёмка против `baseline-1457Z/` (исходные наборы 21.10 14:57Z).
- `yummy_accept.py` — что появилось и что осталось отсутствующим; потерянные прежние адреса с проверкой, живы ли они; дубли и чужие хосты; выборка появившихся страниц (200, index, canonical, h1, номер серии); хвост каталога 330–351.
- Признак D4 — `d4_reach` в итоге recheck: сколько тайтлов эталона достижимо из листалки.

Отчёт и выводы: `docs/seo-operator/YUMMY_SITEMAP_COMPLETENESS_20261021.md`.
