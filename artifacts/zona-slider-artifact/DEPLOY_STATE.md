## Почему активации нет

Живой процесс `pid 3737964` запущен от `User=lords`, сессия работает от
`claude`. Сигнал отклонён ядром:

```
os.kill(3737964, SIGKILL) → PermissionError: [Errno 1] Operation not permitted
```

`systemctl` профилем запрещён. Перезапустить витрину сессия не может — это
единственный оставшийся шаг.

Процесс держит прежний код в памяти, поэтому `zonafilm.space` пока отдаёт
старую разметку: в живом ответе присутствует `max-width:7.5rem` (обрез даты) и
отсутствуют `height:clamp(340px,26vw,390px)`, `object-position:50% 28%`,
`--z-card-max:none`. Это проверено на живом ответе, а не предположено.

## Что изменилось к лучшему помимо установки

До этой сессии перезапуск витрины был **опасен**: `sites/zona-01/current` вёл
на `releases/legacy-b32438c91aaa` — сборку без `.zhero` и `.zadded`, то есть
без слайдера и ленты дат. Любой рестарт откатил бы витрину на неё.

Теперь ссылка ведёт на проверенный релиз с починкой, и рестарт отдаёт именно
его. Ловушка снята независимо от того, кто и когда перезапустит витрину.

Прежняя цель сохранена в `sites/zona-01/PREVIOUS_TARGET.txt`.

## Активация — одна команда

```
sudo systemctl restart nova-zona-01.service
```

После неё витрина поднимется через загрузчик → `sites/zona-01/current` →
`zona-slider-2650fad6`. Этот путь проверен запуском релиза с тем же env, что в
юните; права для пользователя `lords` на каталог и файлы релиза проверены
(каталог 0775, все файлы читаемы).

## Откат, если после рестарта что-то не так

```
# 1. вернуть прежние байты
cp /srv/lords/.frontend/.rollback/20260921T162850Z-zona-01-frontend-611a55911a0c.py \
   /srv/lords/.frontend/zona-01-frontend.py
# 2. вернуть прежнюю цель ссылки
ln -sfn ../../releases/legacy-b32438c91aaa /srv/lords/.frontend/sites/zona-01/current
# 3. перезапустить
sudo systemctl restart nova-zona-01.service
```

Прежние байты `611a5591…` сохранены и сверены побайтово при снятии.
