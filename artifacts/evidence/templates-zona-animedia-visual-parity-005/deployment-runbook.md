# Подготовка к будущей canary-выкладке

## Команды выкладки в этой задаче нет — и это не упущение

Задание просит подготовить точную команду будущей canary-выкладки. Такой команды
здесь не приводится, потому что приводить её было бы неправдой: **кандидата не
существует**. Шаблоны Zona и Animedia не изменялись, новая сборка не собиралась,
`artifact_sha256` нового кандидата не существует.

Команда установщика обязательна требует `--expect-sha256`, `--design-version`,
`--commit` и `--build-id`. Заполнить их сейчас можно только выдуманными
значениями, а выдуманный отпечаток в runbook'е опаснее его отсутствия: он
выглядит исполнимым.

Production остаётся на текущих версиях: Lords 1.1.0, Zona 1.1.0, Animedia 1.0.2.

## Единственное требуемое действие владельца

Разблокировать измерение референсов. Обе записи уже есть в
`inventory/reference-sources.yaml` как `ui_reference`/`read_only`, но
отсутствуют в `inventory/network-allowlist.yaml` — именно этот файл проверяет
guard. Агенту вносить их туда прямо запрещено заголовком самого файла.

От владельца нужно внести в `inventory/network-allowlist.yaml` две записи —
только `GET`, только чтение интерфейса:

```yaml
  - ref: zona-w140-ui-reference
    host: w140.zona.plus
    purpose: "ui_reference: измерение каркаса, сетки и типографики эталона Zona"
    methods: [GET]
  - ref: amd-online-ui-reference
    host: amd.online
    purpose: "ui_reference: измерение каркаса, сетки и типографики эталона Animedia"
    methods: [GET]
```

Если приёмка должна покрыть не только главную, владельцу нужно расширить
`allowed_paths` обеих записей в `inventory/reference-sources.yaml`: сейчас там
разрешён ровно один путь `/`, и остальные страницы останутся
`BLOCKED_REFERENCE` даже при открытой сети.

## Что произойдёт после разблокировки

Инструмент измерения готов и правки кода не требует:

```bash
node tests/tools/measure_reference.js https://w140.zona.plus/ artifacts/reference/zona-w140 390,768,1024,1440,1920
node tests/tools/measure_reference.js https://amd.online/      artifacts/reference/amd-online 390,768,1024,1440,1920
```

Дальше задача продолжается с этапа 1: reference pack → расхождения →
исправления шаблонов → браузерная проверка → парные скриншоты и diff →
регрессии → коммит → отдельная команда выкладки.

## Границы, которые сохранятся и тогда

Измеряются каркас, сетка, плотность, типографика и поведение. Тексты,
изображения, каталог, счётчики, рекламные и publisher ID оригиналов не
сохраняются и в наши витрины не переносятся — это прямое требование
`inventory/reference-sources.yaml` и оно не смягчается заданием на паритет.
