## Что доделано

1. `_блок_поиска` — форма на самой странице: поле с `aria-label`, кнопка
   отправки, ссылка сброса `data-b12-clear="1"` (появляется только когда есть
   что сбрасывать). Подсказка — одна строка, чтобы блок оставался в
   130–160px вместе со ссылкой сброса.
2. Состояния по `display_policy_by_state` паспорта:
   - пустой запрос → `data-b12-state="empty"`, «Запрос пуст»;
   - ноль совпадений → `data-b12-state="zero"`, `data-b12-count="0"`;
   - недоступный Search API → `data-b12-state="error"`, «Поиск временно
     недоступен». Недоступный источник не показывается как ноль совпадений;
   - есть результаты → `data-b12-state="populated"` + счётчик.
3. Листалка `/search/` по 24 на страницу; несуществующая и нечисловая
   страница отдают настоящий 404, а не молча зажимаются к первой.
4. Canonical: порядок параметров `q`, затем `page`; на первой странице
   `page` отсутствует.
5. Дедупликация по `canonical_title_id` — одна запись не занимает две
   карточки.
6. Порядок выдачи берётся у Search API и не переупорядочивается шаблоном
   (`search_ranking = Search_API_only_no_template_mutation`).
7. Полоса готовности каталога сохранена и на поиске.

`&` между параметрами в `href` экранируется (`&amp;`) — в остальном шаблоне
это не так; расхождение записано наблюдением P2 в `BLOCKERS.json`, менять
соглашение по всему шаблону в рамках B12 нельзя.
