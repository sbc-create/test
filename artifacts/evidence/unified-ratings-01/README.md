# Evidence: UNIFIED_RATINGS

Этап единого модуля оценок 1–10 и безопасного сбора внешних рейтингов.
Ветка `claude/unified-ratings-1-10-sources-01`.

| Путь | Что доказывает |
| --- | --- |
| `00-preflight/PREFLIGHT.json` | состояние до работы: ветка, HEAD, чужие незакоммиченные файлы исходного worktree, production backend, схема, флаги подготовленного 1% canary |
| `01-discovery/STAGE_A_DISCOVERY.json` | Этап A: способ доступа, лимит, контракт шкалы и health каждого источника; живая read-only проверка |
| `02-db/BACKUP_RESTORE.json` | бэкап production-БД и проверенное восстановление (`integrity_check`, побайтовое сравнение) |
| `02-db/MIGRATION_DRY_RUN.json` | миграция и откат на копии боевой базы: что добавлено, что не изменилось |
| `02-db/MIGRATION_APPLIED.json` | применение к production: таблицы до/после, количество строк в таблицах работающего виджета |
| `03-pilot/PILOT_<source>.json` | Этап B: пилот ≤20 тайтлов на источник, исходные и нормализованные значения, provenance |
| `03-pilot/PILOT_RERUN_idempotency.json` | повторный пилот: 0 вставок, 0 обновлений, всё unchanged |
| `04-sample100/SAMPLE_<source>.json` | Этап C: выборка ≤100 тайтлов, конфликты названий, сезонов и годов |
| `05-tests/TEST_RUNS.json` | два последовательных прогона тестов и их сравнение |
| `06-ingest/` | Этап D: инкрементальный сбор и расписание |
| `FINAL_REPORT.json` | машинный блок и полный отчёт модуля |
| `FINAL_REPORT.md` | тот же отчёт для чтения |

## Чего в этом этапе нет

Публичной раскатки виджета, изменений шаблонов сайтов, изменений DNS,
TLS, nginx, robots, sitemap и индексации, расширения подготовленного 1%
canary. Сбор внешних оценок и публичный rollout интерфейса — разные
этапы, и прохождение одного не является доказательством готовности
другого.
