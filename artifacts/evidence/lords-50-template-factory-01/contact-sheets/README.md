# Контактные листы

Пятьдесят отдельных PNG из прошлого этапа удалены: они показывали главные
страницы ДО ночной доработки. Два набора материалов рядом — верный способ
принять одно, а посмотреть на другое.

Контактные листы теперь собираются каталогом приёмки и всегда соответствуют
последнему прогону:

* `../review/all.html` — все пятьдесят на одном листе, снимок открывается в
  полный размер;
* `../review/family-*.html` — десять листов по семьям, пять шаблонов рядом в
  одном масштабе;
* `../review/routes-Txxx.html` — лист маршрутов одного шаблона: главная,
  каталог, тайтл, сезон, серия, поиск, 404 и краевые случаи;
* `../review/shortlist.html` — десять кандидатов на шести ширинах.

Полноразмерные кадры лежат в `../templates/Txxx/screenshots/`.
