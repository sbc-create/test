Витрина отдаёт прежний статический релиз, в котором 19 страниц произведений

`zona-01` объявляет `design_version: "1.3.0"`, а установленный артефакт знает
только `1.1.0`, `1.2.0`, `1.2.1`, и незнакомую версию он не отвергал, а молча
выключал новое оформление. Перезапуск 2026-09-22 04:11:55 (не этой сессией)
проявил расхождение, которое лежало на диске с 17:37 накануне.

**Одна команда владельца, возвращающая витрину со слайдером** (без
`daemon-reload` — см. предупреждение ниже):

```
sudo -u lords python3 -c "import json,pathlib; p=pathlib.Path('/srv/lords/.frontend/template-manifest-zona-01.json'); m=json.loads(p.read_text()); m['design_version']='1.2.0'; p.write_text(json.dumps(m, ensure_ascii=False, indent=2))" && sudo systemctl restart nova-zona-01.service
```

Доказательство, что это сработает, снято на самих установленных байтах
(`sha256 bbd6467f…`): с манифестом `1.2.0` тот же файл отдаёт главную с одним
H1, восемью слайдами и 36 карточками, а страницу произведения — 200.
