# ROLLBACK — как вернуть Zona назад

Откат нужен на двух разных уровнях, и путать их нельзя: один возвращает
объявление, другой — байты.

## Уровень 1: откат объявления (манифест)

Самый дешёвый и самый вероятный. Меняется одно поле, байты рантайма не
трогаются.

```
sudo -u lords python3 -c "import json,pathlib; p=pathlib.Path('/srv/lords/.frontend/template-manifest-zona-01.json'); m=json.loads(p.read_text()); m['design_version']='1.3.0'; p.write_text(json.dumps(m, ensure_ascii=False, indent=2))" && sudo systemctl restart nova-zona-01.service
```

Значение `1.3.0` — то, что объявлено сейчас. Если владелец пойдёт путём A из
`DEPLOY_STATE.md` и поставит `1.2.0`, то этой командой состояние возвращается
ровно к текущему.

Проверка после отката: `/` отдаёт ту же разметку, что и до правки.

## Уровень 2: откат байтов рантайма

Цель отката зафиксирована и сверена:

```
ROLLBACK_TARGET_SHA256=7ccf094a1d7f2b5e648a38f51f6a63de9627576637d96f6c966fe1759ad8fa1e
ROLLBACK_TARGET_FILE=/srv/lords/.frontend/.rollback/20260921T173722Z-zona-01-frontend-7ccf094a1d7f.py
```

```
sudo -u lords cp /srv/lords/.frontend/.rollback/20260921T173722Z-zona-01-frontend-7ccf094a1d7f.py \
                 /srv/lords/.frontend/zona-01-frontend.py && \
sudo systemctl restart nova-zona-01.service
```

Важно: `7ccf094a…` — это код **без настоящего слайдера**. Откат на него
возвращает витрину к состоянию до 2026-09-21 17:37, а не чинит текущую
деградацию. Как лекарство от сегодняшнего 404 он не годится: смотри
`DEPLOY_STATE.md`, путь A.

## Чего делать нельзя

* **Не выполнять `systemctl daemon-reload` перед перезапуском.** Файл юнита на
  диске указывает на диспетчер, а тот ведёт на релиз `zona-slider-2650fad6`
  с теми же байтами `7ccf094a…`. Загруженный в память юнит указывает прямо на
  `zona-01-frontend.py`. Перезагрузка юнитов молча сменит путь исполнения.
* Не переставлять символическую ссылку `sites/zona-01/current` заодно с
  откатом манифеста: это два разных пути активации, и смешивать их — способ
  получить третье, никем не проверенное состояние.

## Что откат НЕ затронет

Каталог (`zona-01-catalog.json`), подробности (`zona-01-details.json`),
недельный снимок и конфигурация плеера принадлежат данным, а не релизу:
ни один из перечисленных шагов их не меняет. Индексация (`noindex, nofollow`),
DNS и TLS не участвуют ни в одном из шагов.
