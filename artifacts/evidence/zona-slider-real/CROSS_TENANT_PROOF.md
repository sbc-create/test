# CROSS_TENANT_PROOF — соседи не тронуты

Изоляция доказывается двумя независимыми способами: составом изменений и
побайтовым сравнением отдачи. Обещания в тексте коммита доказательством не
считаются.

## 2. Побайтовое сравнение отдачи соседей

Общий файл рантайма один на шесть витрин, поэтому «не трогал каталог соседа» —
недостаточная проверка. Нужен результат: отдают ли соседи ТЕ ЖЕ байты.

`automation/host/zona-cross-tenant-diff.py` поднимает один и тот же набор
данных дважды: рантаймом стартового HEAD `738e07d` и рантаймом текущего
дерева, — и сверяет SHA256 тела ответа на четырнадцати маршрутах.

| Семейство | Версия оформления | Совпало маршрутов | Расхождения |
| --- | --- | --- | --- |
| lords | 1.1.0 | 14 / 14 | нет |
| animedia | 1.2.1 | 14 / 14 | нет |
| animedia | 1.2.0 | 14 / 14 | нет |

Итог: **42 из 42 маршрутов байт в байт**. Машинный результат —
`cross-tenant-bytes.json`, поле `all_identical: true`.

Маршруты сравнения: `/`, `/catalog/`, `/new/`, `/movies/`, `/series/`,
`/animation/`, поиск с результатом, пустой поиск, `/collections/`, страница
фильма, страница сериала, сезон, эпизод, несуществующий адрес.

## 3. Почему правки не могли задеть соседа

| Правка | Почему Zona-only |
| --- | --- |
| `1.3.0` в наборе версий | добавлена в `ПЕРЕРАБОТАНО_С["zona"]`; набор Animedia не изменён, Lords объявляет 1.1.0 |
| отказ при незнакомой версии | ограничен `СТРОГАЯ_ВЕРСИЯ_ОФОРМЛЕНИЯ = {"zona"}`; соседи получают только строку на stderr |
| оценки на карточке | правка `ВидЗона.плитка`; `ВидАнимедиа` переопределяет `плитка` целиком, `ВидЗона.строка` не тронута |
| сжатие полосы точек | правила `.zhero__dots` / `.zhero__dot` живут в `ЗОНА_СТИЛЬ`; у Animedia свой `АНИМЕДИА_СТИЛЬ` |

Последнее закреплено тестами: `test_карточка_соседнего_семейства_не_тронута`
и `test_известные_версии_не_ломают_соседей` падают, если правка протечёт.

## 4. Общий модуль оценок не менялся

Zona показывает оценки из СВОЕГО бокового файла подробностей
(`zona-01-details.json`, `ratings_by_source`): imdb у 33% записей выборки,
shikimori у 8%, `kinopoisk_rating` у 38%. Это данные витрины, а не чужой
сервис.

Общий модуль сообщества (`/srv/lords/.frontend/community_ratings_overlay.py`)
**не изменён и не вызывается из Zona**. Его контракт знает только
`space="animedia"` и `space="yummy"`; флаг `RATINGS_PUBLIC_READ_ZONA` и
allowlist для Zona в нём отсутствуют. Интеграция потребовала бы правки чужого
модуля — она не сделана намеренно; недостающий контракт описан в
`RATINGS_CONTRACT_GAP.md`.
