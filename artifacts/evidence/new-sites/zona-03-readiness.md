## Ровно два входа, которых не хватает

1. **Снимок каталога.** Издатель строит только для site_id из жёсткого словаря
   `ВИТРИНЫ` в `/srv/site-factory/repo/automation/host/nova-catalog-publish.py`
   и на чужой отвечает `PublishError: витрина zona-03 не входит в профиль
   публикации`. Нужна одна запись:

       "zona-03": {"unit": "nova-zonafilm12-site.service", "host": "zonafilm12.site",
                   "port": 9124},

   Доставку добавлять не нужно: `доставить_ячейкам` берёт адреса из реестра
   ячеек, где у zona-03 уже `managed_by: cell`, `data_owner: pipeline`,
   `data_dir: /srv/zonafilm12-site/data`.

   Права не мешают: `/srv/lords/.frontend` принадлежит `claude`. Формат не
   мешает: семейство то же. Доставка не мешает: адреса верны. Мешает только
   получение.

2. **Доступ токена исполнителя.** Проверено ЕГО токеном через очередь, трижды,
   последний раз 15:01:01:

       zona-03: GitHub не ответил про прогон 36261531037 в
       sbc-create/site-zonafilm12-site: failed to get run: HTTP 404: Not Found

   Из интерактивной сессии тот же прогон читается без ошибок — то есть дело не
   в прогоне и не в CI, а в правах токена `/etc/site-factory/gh-token`.

## Почему снимок не подкладывается руками

Издатель его потом не обновит — сайта нет в `ВИТРИНЫ`, — и домен замрёт на
снимке 25.09. Это тот же капкан, который стоил zona-02 четырёх суток застывшего
каталога при зелёных проверках.
