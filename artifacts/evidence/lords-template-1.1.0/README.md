# Материалы приёмки шаблона Lords 1.1.0

Всё здесь получено на НОВОМ экземпляре, созданном из шаблона штатным способом
(`python3 -m factory cell newsite`), а не на доработанных сайтах.

## Как воспроизвести

```bash
# 1. каталог проверки (синтетические данные, живых снимков не читает)
python3 seed.py <каталог-данных> rev-1

# 2. экземпляр из шаблона + настройка места и канонический модуль
bash rebuild.sh [профиль]         # по умолчанию lords-general

# 3. запуск
cd <проект> && LORDS_90_COMMUNITY_MODERATOR_KEY=<ключ> \
    python3 run.py --port 9190 --data-dir <каталог-данных>

# 4. приёмка
./checks/run.sh                   # проверки самого проекта
python3 verify.py                 # поверхности по адресу
python3 verify_community.py       # звёзды, комментарии, модерация
python3 verify_redelivery.py      # три поколения каталога
python3 verify_provenance.py      # коммит → артефакт → исполняемый код
node browser.js                   # Chromium: темы, лента, плеер
```

## Чего в этих материалах нет

Секретов и содержимого настройки плеера: `publisher_id` в отчёты не выводится,
и проверка `verify.py` отдельно требует, чтобы его не было в ответе `/healthz`.

Тестовые голоса и комментарии созданы в ИЗОЛИРОВАННОМ хранилище внутри каталога
проверки. Ни один живой файл сообщества не открывался. Оставшийся на
lordserial33.biz тестовый голос в шаблон не переносился и прямой правкой не
удалялся.
