# Host attestation — контур измерения живого флота

Проверки, которые имеют смысл только на работающем control host. В обычную
коллекцию `pytest tests/` не попадают и попасть не могут: здесь нет ни одного
файла `test_*.py`, а `pytest.ini` собирает только `testpaths = tests`.

## Запуск

```bash
HOST_ATTESTATION_CONTROL_HOST=1 bin/host-attest --candidate-sha <40 hex>
```

Без `--candidate-sha` берётся HEAD рабочего дерева. Без объявления control host
или без доступного корня флота команда **не притворяется успехом**: выпускает
свидетельство с вердиктом `BLOCKED` и завершается кодом 2.

| Код | Значение |
| --- | --- |
| 0 | PASS — все обязательные проверки прошли |
| 1 | FAIL — измерили, что-то не так с флотом |
| 2 | BLOCKED — не измеряли или не смогли измерить |
| 3 | неверный вызов |

Свидетельство ложится в `artifacts/host-attestation/<candidate_sha>.json`
(каталог переопределяется `HOST_ATTESTATION_DIR` или `--output-dir`).
Корень боевых данных — `FLEET_ROOT`, умолчание в `fleet-baseline.json`.

## Состав измерения

Перечень обязательных проверок объявлен в
`factory/site_engine/attestation/contract.py::ПРОВЕРКИ` и выполняется
`checks.py::ВСЕ`. Совпадение этих двух списков проверяется герметичным тестом:
объявленная, но не выполняемая проверка делала бы каждое свидетельство неполным.

| check_id | Что измеряет |
| --- | --- |
| `fleet.census` | число сайтов и production ACTIVE в реестре |
| `registry.version` | версия живого реестра |
| `registry.synthetic_records` | синтетические записи не изменялись |
| `fleet.public_domains` | публичные домены отвечают, обращение только на чтение |
| `ledger.backup` | копия журнала создаётся и восстанавливается |
| `ledger.secrets_not_exposed` | в ленте, манифестах и журнале секретов нет |
| `systemd.listeners` | Control API слушает ровно один раз |
| `systemd.no_orphan_processes` | осиротевших экземпляров нет |
| `templates.credential_boundary` | граница учётных данных `templates-cp-consumer` |

## Правила контура

**Недоступность — это BLOCKED.** Не PASS, не пропуск, не «0 нарушений». Файла
нет, базы нет, права не те, служба не отвечает — о флоте ничего не узнали, и так
и записывается. `BLOCKED` перекрывает `FAIL` при вычислении вердикта: о
неизмеренном известно меньше, чем о сломанном.

**Контур только читает.** Все подключения к базам — `mode=ro`. Единственное
исключение — `ledger.backup`, который создаёт копию штатным механизмом
резервного копирования и восстанавливает её в изоляции.

**Секреты в свидетельство не попадают.** Проверки отчитываются числами, именами
и вердиктами; там, где ищется утечка, в отчёт идёт факт совпадения и его место,
а не то, что совпало.

**Базовая линия — данные, а не код.** `fleet-baseline.json` содержит значения,
которые до разделения контуров стояли прямо в утверждениях тестов. Там они
делали герметичный прогон зависимым от машины; здесь они — объявленное
состояние боевого контура, с которым измерение сверяется.
