# SEO-оператор и главный редактор

Автономный SEO/редакционный контур для портфеля из 15–20 сайтов. Работает во втором
worktree рядом с development-контуром.

> **Текст в этом файле не является защитой.** Реальные ограничения обеспечивают
> `.claude/settings*.json` (permission rules), `.claude/hooks/pretooluse_guard.py`
> (обязательный PreToolUse enforcement) и `src/seo_operator/guardrails.py`
> (business-scope). Все три покрыты тестами.

## Текущее состояние

Портфель **не заполнен**: репозиторий пуст, источники данных не подключены.
Работает `demo-fixture` — синтетический сайт для dry-run и тестов. Фикстурные
данные недоступны любому сайту без префикса `demo-`.

Что нужно для перехода к реальной работе — `seo/UNKNOWNS.md` (одним пакетом).

## Быстрый старт

```bash
export PYTHONPATH=$PWD/src
python3 -m seo_operator.cli permissions test     # матрица разрешений
python3 -m seo_operator.cli guardrails baseline  # зафиксировать защищённое ядро
python3 -m seo_operator.cli daily-run --site demo-fixture
python3 -m pytest tests/ -q
```

## Правила работы

1. **Каждое изменение принадлежит эксперименту**, кроме исправления доказанного дефекта.
2. **Нет rollback — нет мутации.** Snapshot и исполняемый rollback payload создаются
   до применения, не после.
3. **Оценка только после зрелости данных**: 21 день, 1000 показов, 40 кликов,
   3 сопоставимые пары дней недели, минус 3 дня задержки Search Console.
4. **Никакой имитации пользователей.** Фиктивные комментарии, отзывы, голоса и оценки
   запрещены абсолютно. Редакционный ответ — отдельная сущность с раскрытым авторством.
5. **Неподтверждённый факт опускается, а не угадывается.** «Дата не объявлена» —
   валидная публикация; выдуманная дата — нарушение.
6. **Инцидент замораживает только затронутый сайт.** Несвязанные сайты не откатываются.
7. **Блокировка не останавливает цикл.** `BLOCKED_AUTHORIZATION` → независимые задачи
   продолжаются, вопрос уходит в один агрегированный отчёт. Один и тот же неизменившийся
   блокер повторно не запрашивается.
8. **Каждый сайт уникален.** Одинаковый текст, подборка или раскладка главной на
   нескольких tenant блокируются гейтом перед публикацией.

## Защищённое ядро

`seo/PROTECTED_GUARDRAILS.yaml`, `.claude/settings*.json`, `.claude/hooks/`,
`automation/approved-commands/`, `inventory/authorization/`, `guardrails.py`, `audit.py`.

SEO-контур и созданные им модули **не изменяют** эти файлы. Дрейф детектируется
по хэшам при каждом прогоне и останавливает мутирующие шаги.

## Структура

```
.claude/          permission rules + PreToolUse hook (fail-closed)
automation/       утверждённые обёртки: единственный путь к Tier 2/3
inventory/        authorization manifests (несекретные, business scope)
seo/              политики, реестры, обучение, редакция по tenant, отчёты
src/seo_operator/ код оператора
tests/            372 теста, включая permission corpus и mutation-тесты ядра
```

## Автономность по уровням

| Tier | Что | Условие |
|---|---|---|
| 0 | Чтение, аудиты, отчёты | всегда |
| 1 | Мелкие безопасные правки | `seo_autonomy_tier >= 1`, snapshot, rollback, experiment ID |
| 2 | Canonical, indexability, новые страницы, редиректы | подписанная production policy + канарейка + manifest |
| 3 | DNS, удаление сайта, массовая миграция, деньги | всегда отдельная явная авторизация владельца |

Разрешение инструмента и manifest — **два независимых слоя**. Операция выполняется
без владельца, только если проходят оба.
