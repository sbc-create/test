# Опубликованные изменения и измеренный результат по трафику

Ведёт SEO-сессия. Строка появляется, когда изменение **проверено на живом сайте**. Результат вписывается только по замеру.

**Источник базы** — Метрика, штатный сборщик (`var/analytics/cabinet-latest.json`, выгрузка 16.10 05:09Z):
- неделя 09–15.10, визиты из поиска (`daily_search`) раздельно по Яндексу и Google;
- реальные визиты — без автоматических браузеров (`seo_operator/goal_review.py`): визиты с `ym:s:isRobot = no` минус визиты с браузером HeadlessChrome. До 16.10 из них вычитались и HeadlessChrome-визиты, уже помеченные роботом, — занижение не больше числа роботов за сутки (yummyani.site 09–15.10: ≤ 73 визитов/сут, то есть 2 682…2 755). С 16.10 выгрузка содержит `ym:s:isRobot` в профиле трафика, двойного вычитания нет.

**Правила:**
- нет данных — «не измерено», а не ноль;
- рост не приписывается правке автоматически;
- всплески проверяются отдельно (разбор недели — `docs/seo-operator/goal-review/`).
