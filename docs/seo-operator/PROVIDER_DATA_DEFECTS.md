Здесь записываются ошибки в общем снимке поставщика: жанры, внешние ID, пропавшие записи. Исправлять их витрине или SEO-стороне нельзя. Снимок — постоянные данные поставщика, правится только у него.

Каждая запись — это пример, доказательство, последствие и условие пересмотра. Правила витрин из-за таких дефектов не меняются (решение владельца витрины 26.10, по animedia.icu).

Отфильтровать кандидатов редактора по допуску animedia.icu «по результату в снимке» нельзя: в снимке такого поля нет (проверено 26.10, ключи записи: `external_ids, genres, id, name, original_name, playable, poster_source, poster_url, ratings_by_source, seasons, sources, type, year`). Витрина вычисляет допуск при отрисовке. Наблюдаемый результат — `noindex` на живой странице. Его редактор и так видит на шаге 3 (открывает страницу).

Возврат пропавших записей проверяется после каждой доставки каталога: `python3 automation/local/provider-defect-watch.py` (список — `config/provider-defect-watch.json`). Причина «Чужой жизни» установлена 26.10 Архитектором: данные поставщика — ни названия, ни слага нет в 38 снимках; фильтрация и сопоставление ID исключены.
