# План главной страницы

Общая схема блоков. Конкретный состав и порядок — в стратегии каждого сайта:
одинаковая главная на всех сайтах портфеля не допускается.

## Блоки

| Блок | Что показывает | Правило устаревания |
| --- | --- | --- |
| «Новинки» | вышло за последние 14 дней | автоматически выпадает по дате |
| «Скоро» | подтверждённые анонсы с будущей датой | снимается в день выхода или переноса |
| «Онгоинги» | выходящее сейчас, с датой следующей серии | снимается по завершении показа |
| «Популярное» | по измеренным данным, не по мнению | пересчитывается ежедневно |
| Подборки | редакционные, по подтверждённым связям | пересматриваются раз в неделю |

## Жёсткие правила

- **«Скоро» не содержит просроченных обещаний.** Ежедневный прогон ищет анонсы
  с прошедшей датой в состоянии `announced` и требует их обработки.
- **Закрепление имеет срок.** Пин без `pinned_until` не ставится; истёкшие пины
  снимаются автоматически.
- **«Популярное» опирается на измерение.** Если данных нет, блок не
  выдумывается: он либо скрывается, либо заполняется редакционной подборкой с
  честной подписью.
- **Каждый блок ведёт вглубь.** Задача главной — переход к просмотру и
  следующий шаг, а не удержание на себе.

## Проверка после изменения

Изменение главной затрагивает внутреннюю перелинковку всего сайта, поэтому
после него прогоняются проверки orphan-страниц и каннибализации: снятый блок
может оставить страницы без входящих ссылок.
