## Регулярное выполнение

Через существующий цикл редактора (`editor-run.timer`, шлюз раз в 5 минут,
с 2026-10-10 — пауза 20 минут после завершения партии, flock — без
пересечений; `docs/editor/BACKGROUND_EDITOR.md`, «Режим запусков»). Отдельной
автоматизации нет. После каждых 10 задач — оценка качества по журналу запусков;
ежедневно в 10:00 МСК — пересмотр по свежему снимку. Страница, изменённая по
спросу, повторно не правится до оценки +7 дней.
