# Редакционная стратегия по сайтам

Каждый сайт портфеля получает собственную стратегию. Это не формальность:
общая стратегия неизбежно приводит к одинаковым подборкам, одинаковым
заголовкам и одинаковой главной на всех доменах — то есть ровно к тому, что
запрещено.

## Обязательные поля стратегии

| Поле | Назначение |
| --- | --- |
| Аудитория | кому адресован сайт и чем отличается от соседнего в портфеле |
| Tone of voice | как сайт разговаривает; проверяемые формулировки |
| Структура рубрик | какие разделы существуют и что в них попадает |
| Приоритетные классы запросов | из таксономии |
| Собственные эксперименты | что проверяется именно здесь |
| Редакционный аккаунт | «Редакция сайта» / «AI-ассистент редакции» / нет |
| Модерация комментариев | разрешена или нет |

## Правило разграничения

Два сайта портфеля не могут иметь одинаковый набор «приоритетные классы
запросов + рубрики + tone of voice». Если такое совпадение возникает, это
означает, что сайты конкурируют между собой за одну выдачу, и стратегию нужно
разводить или сайты объединять.

Проверка плана на дубли между сайтами выполняется функцией
`detect_cross_site_duplication` до постановки материала в календарь.

---

## Стратегии реальных сайтов

**Не заполнены.** Ни один из 15–20 сайтов не передан оператору: нет доменов,
CMS, подтверждения прав и данных об аудитории. Стратегия, написанная без этого,
была бы выдумкой, а не планом.

Для заполнения по каждому сайту нужны: домен, доступ к CMS, тематика, текущая
структура рубрик, аудитория и решение владельца по редакционному аккаунту.

## Демонстрационные стратегии (синтетические тенанты)

Показывают требуемую степень различия между сайтами одного портфеля.

### `fixture-anime`

| Поле | Значение |
| --- | --- |
| Аудитория | зрители, следящие за текущими сезонами, приходят регулярно |
| Tone of voice | сдержанный, фактологичный; без превосходных степеней |
| Рубрики | Новинки, Онгоинги, Скоро, Подборки, Сезоны |
| Приоритетные классы | `title_season`, `watch_intent` |
| Эксперименты | указание номера сезона в `title`; блок «следующая серия» |
| Редакционный аккаунт | «AI-ассистент редакции» |
| Модерация | разрешена |

### `fixture-serials`

| Поле | Значение |
| --- | --- |
| Аудитория | смотрят сезонами, возвращаются к премьерам |
| Tone of voice | разговорный, без фамильярности; акцент на расписании |
| Рубрики | Премьеры, Скоро, Популярное, Watch order |
| Приоритетные классы | `discovery`, `title_exact` |
| Эксперименты | watch order как отдельная посадочная страница |
| Редакционный аккаунт | «Редакция сайта» |
| Модерация | запрещена |

Пересечение по приоритетным классам отсутствует: первый сайт работает с
сезонными и «смотреть»-запросами, второй — с discovery и точными названиями.
