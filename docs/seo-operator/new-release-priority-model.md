# Модель приоритета новинок

Реализация — `seo_operator/priority.py::score_release`.

## Жёсткие условия допуска

Проверяются до любого подсчёта. Не веса, а фильтр:

1. **Подтверждённый источник.** Нет — материал не планируется, оценка 0.
2. **Подтверждённые права.** Нет — материал не планируется, оценка 0.

Ни высокий спрос, ни близкая дата не отменяют эти два условия.

## Факторы оценки

| Фактор | Вес | Обоснование |
| --- | --- | --- |
| Окно релиза (0–14 дней) | +3.0 | спрос концентрируется здесь |
| Только что вышло (−7…0 дней) | +2.5 | пик запросов «смотреть» |
| Анонс заранее (15–60 дней) | +1.5 | успеть занять позицию до пика |
| Далёкий анонс (>60 дней) | +0.5 | рано, но стоит застолбить |
| Архив | +0.2 | остаточный интерес |
| Дата неизвестна | +0.3 | нельзя планировать окно |
| Новый сезон | +2.0 | сезонные запросы дают отдельный спрос |
| Онгоинг | +1.5 | повторные визиты между сериями |
| Нет посадочной страницы | +2.0 | спрос есть, отвечать нечем |
| Высокий спрос (>5000 показов) | +2.0 | подтверждено данными |
| Средний спрос (>500 показов) | +1.0 | подтверждено данными |

## Отсутствие данных — не ноль

Если показов нет в данных, фактор спроса **не добавляется вовсе**; он не
считается нулевым спросом. Разница существенна: неизмеренный спрос не должен
опускать новинку ниже измеренно непопулярной. Проверено тестом
`test_unknown_impressions_do_not_score_as_zero_demand`.

## Объяснимость

Каждая оценка возвращает разбор по факторам и текстовое объяснение. В
ежедневный отчёт попадает объяснение, а не только число: приоритет, который
нельзя перепроверить, невозможно оспорить.
