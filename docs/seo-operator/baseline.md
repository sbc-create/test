# Baseline

## Статус: не измерен

Baseline на 2026-08-22 **не может быть построен**. Это не сбой конвейера, а
следствие отсутствия входных данных.

| Требуется для baseline | Состояние |
| --- | --- |
| Список сайтов | portfolio registry пуст (0 сайтов) |
| Показы, клики, CTR, позиции | нет доступа к Google Search Console |
| Позиции и индексация в Яндексе | нет токена + домен заблокирован сетью |
| Поведение: глубина, возвращаемость | нет доступа к Яндекс Метрике |
| Переходы к просмотру | нет доступа ни к Метрике, ни к CMS |
| Технические ошибки | нет доменов для обхода |
| Обход роботов, crawl budget | нет доступа к серверным журналам |
| Доступность плеера | нет доступа к мониторингу |

Gate качества данных возвращает `FAIL`, и конвейер по этому сигналу
**отказывается публиковать метрики**. В отчёте выводится «не измерено» с
причиной, а не нули.

## Почему не заполнено нулями

Ноль показов и «показы измерить нечем» выглядят в таблице одинаково, но
означают противоположное: первое — плохой результат, второе — отсутствие
результата. Подстановка нулей превратила бы отсутствие доступа в ложный факт о
сайтах и сделала бы бессмысленным всякое последующее сравнение.

Поведение закреплено тестом `test_safe_metric_marks_unmeasured_rather_than_zero`.

## Что baseline будет содержать после подключения

Для каждого сайта и каждого источника: показы, клики, CTR, средняя позиция,
доли TOP-3/10/20, индексация, технические ошибки по категориям, переходы к
просмотру, глубина, возвращаемость — с датой снятия и указанием источника
каждого числа.

Первый заполненный baseline снимается за 28 дней до старта любых изменений:
без предшествующего периода вердикт эксперимента не с чем сравнивать.

## Что уже проверено без данных

Технический контур проверен на синтетическом тенанте: обход 4 страниц, 4
находки, 2 предложенных изменения, применение в canary, откат по ухудшению
метрики. См. [`demo-canary-rollback.md`](demo-canary-rollback.md).
