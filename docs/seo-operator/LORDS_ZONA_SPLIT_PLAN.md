## Проблема (измерено 15.10)

Семь доменов отдают один каталог: 64,7 тыс. записей, а в карте у каждого около 65 тыс. адресов. У одних и тех же страниц тайтлов совпадают meta description, H1 и синопсис. Тело страницы lordfilm47.space совпадает с lordserials22.info на 100 %. Технически все семь открыты одинаково.

Поиск выбирает одну копию из набора дублей: растёт только lordserials22.info, у соседей единицы визитов.

## Варианты (выбор — после данных об индексе, п. 1 плана)

- **А. Тематическое разнесение.** У каждого домена своя основная тема и свой каталог-выборка:
  - сериалы — домены «serial» (lordserials22.info уже ведёт по ним, lordserial33.biz, 1lordserials1.online);
  - фильмы — lordfilm47.space;
  - Zona — свои жанровые или страновые темы.

  Пересекающиеся записи одного произведения на нескольких доменах получают canonical на «домашний» домен темы. Риск: перенос canonical снимет текущие входы у доменов, где запись уже растёт. Поэтому решение принимается только по данным «исключено как дубль» из Вебмастера и по входам Метрики.
- **Б. Уникализация без переноса.** Свой редакционный слой на главных и разделах каждого домена, без выдуманных фактов, под одни и те же тайтлы. Страницы тайтлов остаются дублями — эффект ограничен главными и разделами.
- **В. Оставить один домен «серийным» и вывести остальные из пересечения.** noindex для страниц тайтлов, дублирующих домашний домен. Быстро, но обнуляет поиск у остальных и противоречит цели «5 000 на каждом» — **не рекомендуется**.

## Что нужно, чтобы выбрать

1. Вебмастер (B023): по каждому из семи доменов — проиндексировано, исключено (особенно «дубль»), запросы с показами. Для lordserials22.info — какие страницы в индексе.
2. Для каждой темы — 20 страниц-образцов с поисковыми входами Метрики (уже есть по lordserials22.info и zonafilm12.site), чтобы проверить, что «домашний» домен действительно получает показы.
