## Как построен эталон

Для каждого домена только GET к нему самому, UA `sf-seo-audit/1.0`.

1. **Тайтлы.** Все страницы `/catalog?page=N` и `/catalog/announcement`, плюс тайтлы из `titles.xml`, до которых каталог не доводит (см. дефект D4). Каждая страница тайтла проверена: 200, `index`, canonical на себя.
2. **Сезоны.** Ссылки `season/N` со страницы тайтла.
3. **Серии.** Ссылки `episode/N`: со страницы тайтла для показанного сезона, для остальных сезонов — со страницы сезона. Проверено на Конане (1 217 серий), Ван-Писе (1 180) и Синтяне (750): списки не обрезаны.
4. **Исключения из эталона.** Сезон с `noindex` в эталон не входит. Таких 149 на каждом домене, все пустые; ни один из них не в карте, и это верно.

Время обхода: 13:15–14:57Z. Со всеми частями карты сравнивается снимок, снятый сразу после обхода (14:57Z). Снимок 13:03Z лежит рядом.

Артефакты: `var/seo-audit/yummy-sitemap-20261021/` — `<домен>-catalog.json`, `<домен>-extra.json`, `fresh/<домен>-compare.json`, `summary-20261021.json`. Скрипты — в scratchpad сессии: `yummy_catalog_crawl.py`, `yummy_compare.py`.

**D2. yummyani7.info и yummyani7.site: части с сериями не пересобирались с 20.10.**
