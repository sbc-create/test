# Политика экспериментов

## Гипотеза

Эксперимент без гипотезы и первичной метрики не создаётся — конструктор
`Experiment` выбрасывает исключение. Гипотеза формулируется так, чтобы её можно
было опровергнуть: «сокращение title до 60 символов повысит CTR карточек»,
а не «улучшим заголовки».

## Границы canary

| Ограничение | Значение | Причина |
| --- | --- | --- |
| Максимум сайтов | 1 | массовое изменение по всему портфелю необратимо дорого |
| Максимум страниц сайта | 10% | остальное — контрольная группа |
| Минимум наблюдения | 14 дней | недельные колебания спроса не должны определять вердикт |
| Минимум показов | 1000 | ниже этого эффект неотличим от шума |

Попытка выйти за границы — не предупреждение, а `CanaryScopeError`.

## Пороги решения

| Изменение первичной метрики | Вердикт |
| --- | --- |
| нарушен guardrail | `rollback` немедленно |
| ≤ −3% | `rollback` немедленно |
| наблюдение < 14 дней | `continue` |
| показов < 1000 | `insufficient_data` → откат |
| ≥ +5% | `keep` |
| между −3% и +5% | `rollback` |

## Расширение

Расширение за пределы canary — отдельное решение, а не автоматическое
продолжение. Основание: вердикт `keep` на завершённом наблюдении, зафиксированный
в реестре экспериментов. Расширение проводится ступенями, каждая — снова
эксперимент.

## Что не является экспериментом

Исправление фактической ошибки (битый плеер, 500-я ошибка, обещание с прошедшей
датой) экспериментом не оформляется и порогов не ждёт: это устранение дефекта.
