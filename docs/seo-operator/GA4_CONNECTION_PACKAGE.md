## 3. Условия показа тега (код, c6eb21e)

* Тег GA4 — независимый счётчик: ни ID Метрики, ни загрузка `mc.yandex.ru` условием
  не являются (тест `test_ga4_independent_of_metrika`).
* ID — только формы `G-[A-Z0-9]{4,16}`; хост запроса — только из
  `LORDS_GA4_ALLOWED_HOSTS` (домен + живые aliases этого сайта); иначе тега нет.
* Один `config`, без явного `page_view`; повторная вставка гасится.
* Смешение: проба отказывает, если один ID ожидается у двух доменов, и даёт нарушение,
  если один ID виден на двух живых доменах.
* Согласие пользователя: **механизма согласия на витринах нет** (Метрика грузится без
  него). GA4 не вводит его сам; режим согласия (Consent Mode) — решение владельца.
