## 3. Условия показа тега (код, c6eb21e)

* Тег GA4 — независимый счётчик: ни ID Метрики, ни загрузка `mc.yandex.ru` условием
  не являются (тест `test_ga4_independent_of_metrika`).
* ID — только формы `G-[A-Z0-9]{4,16}`; хост запроса — только из
  `LORDS_GA4_ALLOWED_HOSTS` (домен + живые aliases этого сайта); иначе тега нет.
* Один `config`, без явного `page_view`; повторная вставка гасится.
* Смешение: проба отказывает, если один ID ожидается у двух доменов, и даёт нарушение,
  если один ID виден на двух живых доменах.
* Согласие пользователя: **механизма согласия на витринах нет** (Метрика грузится без
  него). GA4 не вводит его сам; режим согласия (Consent Mode) — решение владельца.

## 4. Сервисный аккаунт и сборщик

Аккаунта нет — email назвать нельзя, пока владелец его не создаст. Имя предлагается
фиксированное: `site-factory-ga4-reader`; email будет
`site-factory-ga4-reader@<ID проекта Google Cloud владельца>.iam.gserviceaccount.com`
(вторая часть — ID проекта, его знает только владелец).

Права разделены:
* **настройка ресурсов** (создание ресурсов/потоков, роль «Редактор» в GA) — НЕ запрашивается:
  ресурсы создаёт владелец, право менять учёт фабрике не нужно (согласовано с Архитектором);
* **чтение статистики** (Data API) — роль «Читатель» на аккаунте GA или на каждом из 17 ресурсов.

Сборщик (Архитектор): по образцу `analytics-cabinet` — `LoadCredential=` на файл ключа,
значение живёт только в `/run/credentials/%n`; путь файла назначается, когда файл появится.
