# Три пары подборок Zona: назначение, правило отбора, состав (MOD-95/98/100)

Замер SEO-сессии 20.10 на zonafilm.space и zonafilm12.site (обе витрины дают одинаковые размеры). Правила — `src/collection_contract.py` (РЕЕСТР["zona"]). Артефакт: `var/seo-audit/collections-pairs-deep-20261020.json`. Пересечение — число общих карточек из 60 на странице N обеих подборок. Остальные подборки (жанровые и др.) не трогаются: с прочими они пересекаются на 3–17 % (MOD-100).

## Предложение (к согласованию с Архитектором)

1. **`video_available` — объединить.** 301 `/collection/video_available/` → `/catalog/` (тот же «весь каталог», своя страница с canonical на себя), с сохранением `?page=` где применимо; убрать подборку из раздела `/collections/` и из блока главной, число в описании раздела «12 подборок» → «11». Отбор по playable не переносить никуда.
2. **`recently_added` — выбрать один из двух вариантов** (решение за Архитектором, данных для выбора хватает):
   - а) оставить только видовые `recently_added_movies` и `new_episodes`, а общую `recently_added` перевести 301 на одну из них — **не рекомендую**: зритель, ищущий «всё новое», попадёт только на фильмы или только на сериалы;
   - б) **рекомендую**: оставить `recently_added` как общую, а `recently_added_movies` и `new_episodes` сделать её видовыми срезами — `/collection/recently_added/?kind=Фильм|Сериал` с canonical на себя (или сохранить их адреса, но вывести в разметке как фильтры общей подборки), чтобы на первой странице общей подборки не повторялись 48 из 60 карточек отдельной индексируемой страницы. Минимальная правка без смены адресов: у общей подборки порядок «поровну по видам» (чередование фильм/сериал по published_at) — первая страница перестаёт совпадать с фильмовой на 80 %.
3. **`current_season` ↔ `new_movie_releases` — не объединять**: задачи разные; при желании развести начало выдачи на zonafilm12 — исключить из первой страницы `current_season` записи, которые уже стоят в первой странице `new_movie_releases` (только порядок, без смены отбора).

## Эксперименты и порядок

- Канарейка — **zonafilm.space** (≈4 визита в сутки живой аудитории, на страницы подборок поисковых входов 0); перенос на zonafilm12.site и zonafilm.cc — после сверки.
- Действующие оценки: «ссылки стран» 01.11 (метрики — входы на разделы стран и доля входов вне крупнейшего тайтла) подборок не касаются; на страницы подборок во всей сети 3 поисковых визита из 16 802 (0,02 %), поэтому эффект на трафик не заявляется и не измеряется — основание правки: дубли индексируемых страниц и ложное обещание «С видео».
- Проверки к задачам: пересечение пар ≤ 30 % на страницах 1–2, 301 с сохранением пути, раздел `/collections/` — число и перечень ссылок совпадают, остальные подборки без изменений (отрицательный контроль).
