## 1. Цели Метрики: создать отсутствующие и подтвердить ПРИЁМ событий

Почему это нужно именно сейчас. Отправка событий выложена в код линии Zona
(коммиты `e298c76` и `33ea8bb`), а 27.10 — и в код `animedia.icu` (своими
точками плеера: у этой линии нет ни `requested`, ни `nextOrFail`). Подтвердить
ПРИЁМ сессия не может: токен читает служба, и `factory analytics` отвечает
`BLOCKED_SECRET`. Отдельно измерено: у `zonafilm.space` в кабинете создано
**0 целей из 9**, у `zonafilm12.site` — 9 из 9, у `animedia.icu` (счётчик
`113288667`) все девять целей за 20–26.10 равны нулю при 4417 визитах — то
есть событие не отправлялось, а не зритель так себя вёл.

Поэтому шаг запускается для ТРЁХ доменов, а не одного: команда ниже повторяется
с `animedia.icu` и `zonafilm12.site` на месте домена. Домены независимы: отказ
на одном не отменяет остальные.

Сервер: управляющий узел (этот), через `sudo`. Юнит уже установлен.

```bash
# ДО: что сейчас в кабинете
python3 -m factory analytics status --domain zonafilm.space | grep -E 'zonafilm'

# Создать отсутствующие цели ОДНОГО домена (дубля не создаёт: счётчик ищется
# по домену и переиспользуется; при двух счётчиках прогон останавливается)
sudo systemctl start 'analytics-connect@zonafilm.space.service'
systemctl status 'analytics-connect@zonafilm.space.service' --no-pager | tail -5
cat /home/claude/wt-portable-site-cell-01/var/analytics/connect-zonafilm.space.json
```

Ожидаемый результат: в отчёте перечислены созданные цели, и
`analytics status` показывает `целей 9/9` у `zonafilm.space`.

Подтверждение ПРИЁМА событий (после выпуска кода и живого прохода по сайту):

```bash
sudo systemctl start analytics-cabinet.service
python3 -m factory analytics report --domain zonafilm12.site \
    --date1 2026-10-27 --date2 2026-10-27
```

**Оговорка к сравнению доменов.** Цель `player_start` у линии Zona уходит по
сообщению поставщика `requestPlay` («площадка запросила показ»), а у
`animedia.icu` такого сообщения в контракте нет, и выдумывать его нельзя:
там цель уходит на первом продвижении медиа. Условие строже запроса, поэтому
`player_start` на `animedia.icu` может показать меньше просмотров, чем было,
но не больше. Складывать эти числа между доменами как одну величину нельзя.

**Чем результат НЕ считается.** Наличие счётчика на странице — не отправка
события; отправка — не приём. Пока в отчёте нет достижений цели, нули означают
«событие не дошло», а не поведение зрителей: считать их поведением нельзя.

Откат: `systemctl stop` для обоих юнитов. Цели в кабинете создаются
необратимо — но это и есть запрошенная операция; данных витрин она не касается.
