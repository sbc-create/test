**Что открывается после.** Моя работа без вас: снимок накладки, пробная

### Шаг 8 — исходящее соединение до API Вебмастера. Зависимостей нет

только `--runtime` — до перезагрузки, чтобы решение можно было отменить, ничего
не правя в файлах.

### Шаг 7 — не команда, а решение

Публичный `/healthz` у девяти витрин отдаёт 22–24 раскрывающих поля: пути,
хеши, git-коммиты. Решения D150/D166/D187 закрывают `/healthz` от
**индексации**, а не от доступа, поэтому состав ответа может быть сознательным.
Безопасная форма (`{"ok": true}`) уже работает у восьми витрин. Сузить состав —
правка шаблона, её делает SEO-сессия, а не команда владельца. Откат здесь —
это решение о выпуске, а не операция.
