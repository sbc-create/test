# Передача владельцу рантайма: домены вне канонического Registry

Templates ничего в production не менял и не предлагает менять. Это перечень
наблюдений с доказательством, чтобы владелец домена и рантайма мог принять
решение.

## Что проверялось

Только чтение, один запрос на домен, `artifacts/live-title-journey/off-registry-domains.json`.

В каноническом Registry (версия 32) девять витрин: три Lords, две Animedia,
три Yummy и одна Zona. Трёх доменов ниже в нём **нет** — ими Templates не
управляет.

## `lordfilm1.online`

Заявлено в задании: 502 Bad Gateway / upstream connection refused.

Наблюдение отсюда: **имя не разрешается**.

```
URLError: <urlopen error [Errno -2] Name or service not known>
```

То есть до апстрима дело не доходит: DNS-записи для этого имени с этого узла
нет. Возможные объяснения — запись удалена после наблюдения, либо 502 был
виден с другой точки. Утверждать, какое из них верно, отсюда нельзя.

Что нужно от владельца: подтвердить, должен ли домен существовать. Если да —
DNS и апстрим находятся вне периметра Templates, и восстанавливать их отсюда
нельзя. Если нет — исключить домен из перечня проверок, чтобы он не выглядел
как незакрытый дефект.

## `lorserial66.lol` и `newlordfilm.lol`

| Домен | Ответ | Шаблон |
| --- | --- | --- |
| `lorserial66.lol` | HTTP 200, 154 470 байт | старый DLE: 10 признаков движка, 148 упоминаний CDNVideoHub, `data-template-version` отсутствует |
| `newlordfilm.lol` | HTTP 200, 154 398 байт | тот же старый DLE |

Новый шаблон туда не выложен. Оба домена вне канонического Registry, поэтому
Templates не может ни выложить туда кандидата, ни объявить их исправленными.
Классификация — `BLOCKED_OTHER_OWNER`.

Что нужно от владельца: решить, входят ли эти домены в периметр фабрики. Если
входят — внести их в Registry как витрины с указанием окружения и владельца;
только после этого выкладка на них становится осмысленной и проверяемой.

## Граница

Ни DNS, ни TLS, ни systemd, ни обратный прокси в этой работе не менялись.
Ни один live-сайт не объявляется исправленным.
