# Передача Release Ops: кандидат Zona

Описание кандидата и условий канарейки. Разрешением на выкладку не является:
production deploy и канарейка в это задание не входят и не выполнялись.

## Почему это срочно

Замер живой витрины read-only: из **190 проверенных карточек 190 ведут в
404**. Ни одна карточка на `zonafilm.space` не открывает страницу
произведения. Доказательство:
`artifacts/live-title-journey/live-inventory.json`.

Причина разобрана в Zone R2: витрина ссылалась на страницы, которых не
собирала. Кандидат её закрывает; на живой витрине работает сборка
`1.0.2 / 20260910T124530Z-a1691c56-nova`, то есть кандидат не выложен.

## Доказательство маршрутов

`automation/host/candidate-route-gate.py` поднимает кандидата на локальном
стенде и открывает **каждую** видимую ссылку на произведение из всего
собранного дерева, сверяя не только код ответа:

- заголовок страницы против текста карточки — `ENTITY_MISMATCH`;
- `canonical` против запрошенного пути — `CANONICAL_MISMATCH`;
- текст «не найдено» при коде 200 — `SOFT_404`.

Результат — `artifacts/candidate-route-gate/zona.json`.

## Условие канарейки: переезды

В артефакте один переезд:

```
/title/kakoy-skandal-2/  →  /title/kakoy-skandal--2025/
```

Рантайм витрины обязан читать `redirects.json` из каталога релиза, загружать
карту целиком до начала обслуживания, отказывать при нечитаемом файле и
отвечать 308 только если цель собрана. Подробности и дымовая проверка —
`ZONE-R2-RELEASE-OPS-HANDOFF.md`.

Без поддержки переездов адрес `/title/kakoy-skandal-2/` станет 404. Сейчас на
живой витрине 404 отдают все адреса произведений, так что хуже не станет, —
но выкладывать кандидата и оставлять один известный 404 незачем.

## План канарейки

1. Выложить артефакт на одну витрину, не переключая остальные.
2. Дымовая проверка до переключения: корень, каталог, три раздела, десять
   адресов произведений из `route-map.json`, адрес-источник переезда.
3. **Обязательно после канарейки — проверка всех карточек**, а не выборки:
   тот же `candidate-route-gate` против выложенного домена. Выборка из
   тридцати ссылок не отличила бы нынешнее состояние витрины (190 из 190 в
   404) от исправного, если бы в выборку попали только разделы.
4. Критерий отката: любая карточка, ведущая не в 200, либо любой
   `ENTITY_MISMATCH`.

## Откат

Возврат прежнего артефакта целиком вместе с его `redirects.json`. Откат и
возврат вперёд проверены на кандидате Lords тем же способом
(`artifacts/lords-visual-parity/rollback-proof.json`): различающий файл
отдавался от нужного артефакта на каждом шаге.

## Граница

Templates не выкладывает, не переключает ссылки, не трогает DNS, TLS, systemd
и обратный прокси. Ни один live-сайт этой работой не объявляется исправленным.
