Кому: линии, владеющей `var/site-repos/zonafilm-cc` (моя сессия изолирована в

Задание владельца 19.10 требует переработать наполнение главных и довести до

## 1. Что не так (измерено)

Живой код: `src/home.py:339` (выпуск `8c01c474e1d4`, установлен 19.10 13:29:04Z).

```python
def свежесть(з: dict) -> str:
    return з.get("published_at") or ""
```

Этим ключом сортируются слайдер и полки «Новые фильмы» и «Новые сериалы».
`published_at` — дата появления записи В КАТАЛОГЕ, а не дата произведения.
Что получилось на живой странице (инструмент
`automation/local/homepage-cards-audit.py`, 19.10 17:1xZ):

| полка | карточек | медиана года | старейшая | старше 10 лет | добавлены за 7 суток | без видео |
| --- | --- | --- | --- | --- | --- | --- |
| Фильмы в каталоге | 24 | **1979** | **1927** | **23** | 24 | 0 |

Снимок первого экрана это подтверждает: «Новые фильмы» — это «Вражьи тропы»,
«Лунный камень», «Песнь о счастьи», «Внимание, цунами!». Полка обещает новые
фильмы и показывает советское кино 1930–1980-х.

Технических дефектов на карточках нет: постеры у всех, видео доступно у всех,
повторов между полками нет (единый набор занятых слагов работает правильно).
Это дефект ОТБОРА.

## 2. Правка (минимальная: меняется только ключ порядка)

В `src/home.py`, рядом с существующей `свежесть` (строка 339):

```python
    def свежесть(з: dict) -> str:
        """Дата появления записи в каталоге. Это НЕ новизна произведения."""
        return з.get("published_at") or ""

    def _год(з: dict) -> int:
        г = str(з.get("year") or "")
        return int(г) if г.isdigit() else 0

    def новизна(з: dict) -> tuple:
        """Новизна ПРОИЗВЕДЕНИЯ: сначала год, потом дата появления в каталоге.

        Прежде все «новые» полки сортировались по `published_at`, и на главную
        выходили фильмы 1927–1983 годов, добавленные накануне: измерено 19.10,
        медиана года первых 24 карточек 1979, старше десяти лет 23 из 24. Год —
        свойство произведения, дата каталога — свойство файла, и слово «новое»
        относится к первому. Дата каталога остаётся вторым ключом: внутри
        одного года свежее добавленное выходит раньше.
        """
        return (_год(з), з.get("published_at") or "")
```

Дальше три замены ключа — и больше ничего:

```diff
     # 1) Компактный слайдер — игровые фильмы с обложкой и оценкой.
     лента = выбрать(lambda з: фильм(з) and есть_постер(з) and играбельно(з)
                     and оценка(з) is not None,
-                    свежесть, В_СЛАЙДЕРЕ)
+                    новизна, В_СЛАЙДЕРЕ)

     # 2) Новые фильмы
     новые_фильмы = выбрать(lambda з: фильм(з) and есть_постер(з) and играбельно(з),
-                           свежесть, В_БЛОКЕ)
+                           новизна, В_БЛОКЕ)

     # 3) Новые сериалы
     новые_сериалы = выбрать(lambda з: сериал(з) and есть_постер(з) and играбельно(з),
-                            свежесть, В_БЛОКЕ)
+                            новизна, В_БЛОКЕ)
```

**Чего правка намеренно НЕ делает:**

* не трогает «Обновления серий» — там ключом остаётся `свежесть`. Правильным
  ключом была бы дата выхода серии, но её в данных ячейки нет вовсе (`seasons`
  несут только `avail` и `eps`), а подставлять вместо неё другую дату значит
  повторить ту же ошибку;
* не меняет отбор — только порядок. Поэтому ни одна полка не может сократиться:
  под отбор слайдера подходят 45 360 записей каталога из 66 865;
* не меняет заголовки, адреса, canonical и ссылки «Весь раздел»
  (`/movies/`, `/series/`) — внутренняя перелинковка остаётся прежней;
* не трогает подборки и навигацию.

## 5. Приёмка после активации (команды и ожидаемые числа)

```bash
# 1. состав первых карточек
python3 automation/local/homepage-cards-audit.py --domain zonafilm.cc
#    ожидается: полка «Фильмы в каталоге» — медиана года ≥ 2025,
#    «старше 10» = 0, без видео 0, повторов 0, пустых полок нет

# 2. снимки «после» тем же инструментом и теми же окнами
python3 automation/local/page-screenshots.py --url https://zonafilm.cc/ \
    --label zonafilm-cc-after --fold --out <каталог>

# 3. адреса и канонические ссылки не изменились
curl -sS https://zonafilm.cc/ | grep -c 'href="/movies/"'   # было 1
curl -sS https://zonafilm.cc/ | grep -o 'rel="canonical"[^>]*'
```

**Отрицательный контроль обязателен:** число карточек в полках должно остаться
прежним (24 / 12 / 12 / 9). Если какая-то полка сократилась — правка задела
отбор, а не порядок, и её надо откатывать.

## 6. Границы, которые эта правка не нарушает

* **канареек на zona-02 нет** — проверено по `config/experiments.json` живой
  линии: заняты animego-02/03/04, lords-05 и yummy-07;
* адреса наблюдения канареек не затрагиваются, потому что правка не меняет
  ни одного URL;
* восьмёрка K2 и четыре замороженных домена не трогаются;
* эффект на поиск заранее не обещается: база «до» снята, дату проверки эффекта
  назначим после активации, и новый порядок полок доказанным ростом SEO
  объявляться не будет.
