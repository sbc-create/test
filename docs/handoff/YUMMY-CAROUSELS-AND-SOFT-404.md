# Handoff: карусели главной, мёртвая кнопка и мягкий 404 жанровых адресов

**Кому:** владельцу приложения витрины (`yummyani/web`).
**От кого:** слой шаблонов Site Factory (семейство `yummy`).
**Статус:** измерено в браузере на боевом каталоге; ни один пункт не лечится
со стороны посредника — все живут в разметке и поведении приложения.

Проверено через предпросмотр слоя шаблонов (`tools/yummy/preview.py`), который
переносит ответ приложения байт в байт; те же числа получаются и прямым
запросом к приложению. Посредник в этих находках не участвует.

---

## 1. Кнопка «назад» нажимается в начале ленты и ничего не делает

Четвёртая карусель главной (`.portal-carousel-wrapper` с кнопками
«Предыдущие тайтлы сезона» / «Следующие тайтлы сезона»):

| момент | `scrollLeft` дорожки | `disabled` у «назад» | `aria-disabled` |
| --- | --- | --- | --- |
| при загрузке | 0 | `false` | нет |
| после клика «назад» | 0 | `false` | нет |
| после клика «вперёд» | 184 | `false` | нет |

Кнопка в начале ленты доступна, нажимается и не меняет ничего. Для
посетителя это неотличимо от сломанной кнопки, а для клавиатуры и экранного
диктора — от рабочей.

**Нужно:** на границах выставлять `disabled` (или `aria-disabled="true"` с
отменой обработчика). Признак — `scrollLeft <= 0` для «назад» и
`scrollLeft + clientWidth >= scrollWidth` для «вперёд».

## 2. Три карусели из четырёх не имеют кнопок вовсе

| карусель | ширина содержимого | ширина окна | кнопки |
| --- | --- | --- | --- |
| 1 | 2318 | 1288 | нет |
| 2 | 3482 | 1288 | нет |
| 3 | 2318 | 1288 | нет |
| 4 | 4416 | 1288 | есть |

Содержимое шире окна почти вдвое, и добраться до него можно только
горизонтальной прокруткой — жестом, которого на настольном компьютере с
обычной мышью нет. Часть карточек недостижима.

**Нужно:** те же кнопки, что у четвёртой карусели, либо видимая полоса
прокрутки.

## 3. Дорожки карусели недостижимы с клавиатуры

Все четыре дорожки: `overflow-x: auto`, `scrollWidth > clientWidth`,
`tabindex = -1`. Прокручиваемая область без фокуса — нарушение WCAG 2.1.1
(Keyboard); axe называет его `scrollable-region-focusable` и находит 18 узлов
на странице.

**Нужно:** `tabindex="0"` на элементе с прокруткой (плюс доступное имя —
см. пункт 4).

## 4. Три области носят одно и то же имя «Актуальное»

```
.portal-season-track[role="list"][aria-label="Актуальное"]   ×3
.portal-season-track (без role и без aria-label)             ×1
```

Ленты показывают разное: «Новые серии», «Актуальное», «Сейчас выходят»,
«Аниме летнего сезона». Экранный диктор объявляет три из них одинаково, а
четвёртую — никак.

**Нужно:** `aria-label` по заголовку своего раздела; четвёртой — тоже
`role="list"` и имя.

## 5. Мягкий 404 на жанровых адресах

```
GET /catalog/genre/school      → HTTP 200, 28 348 байт, 0 ссылок на тайтлы
GET /catalog/genre/komediya    → HTTP 200, 28 360 байт, 0 ссылок на тайтлы
```

В браузере на этих адресах отрисовывается **«СТРАНИЦА НЕ НАЙДЕНА … Код 404»**
— при коде ответа 200. Соседние нереализованные адреса ведут себя правильно:

```
GET /catalog/year/2024         → HTTP 404
GET /catalog/type/tv           → HTTP 404
```

Карта страниц (`docs/templates/PAGE-MAP-yummy.md`) объявляет жанровый лендинг
как «not routed until allowlist» — то есть ожидается 404, как у года и типа.

**Нужно:** отдавать 404 кодом, а не только текстом. Страница, которая
говорит «не найдено» и отвечает 200, остаётся в индексе и расходует обход.

## 6. `/catalog/random` переходит на клиенте, а не ответом

```
GET /catalog/random → HTTP 200, 0 ссылок на тайтлы, нет <h1>
```

В браузере через несколько секунд адрес меняется на страницу тайтла — переход
делает клиент. Карта страниц объявляет `307/308 to title or 404`.

Для посетителя это работает; расхождение с объявленным контрактом остаётся.
Раздел объявлен `noindex` и вне карты сайта, поэтому вреда поиску нет — пункт
приведён для полноты и правится по решению владельца.

## Как перепроверить

```bash
python3 tools/yummy/preview.py up --run <кат> --data <снимок> --profiles site
NODE_PATH=/home/claude/node_modules node tools/yummy/audit.mjs \
  --base http://127.0.0.1:9310 --routes <маршруты> --out <кат> --label check
```

В матрице смотреть `axe.violations` (`scrollable-region-focusable`,
`target-size`, `aria-*`) и `status` для `/catalog/genre/*`.

Кнопки карусели проверяются кликом с чтением `scrollLeft` до и после — так
получены числа в пункте 1.
