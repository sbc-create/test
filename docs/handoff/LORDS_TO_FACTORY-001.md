## 3. Проверенная команда

Выполнялась на всех трёх профилях; ниже — с подстановкой для первого домена.

```bash
python3 -m factory cell reserve --site lords-05 --order <id-заказа> \
        --domain lordserials22.site

python3 -m factory cell newsite \
        --site lords-05 --domain lordserials22.site \
        --template lords-dorama --port <свободный порт> \
        --site-name "<имя витрины>" \
        --remote https://github.com/sbc-create/site-lordserials22-site \
        --destination var/new-sites/lords-05
```

### Обязательные параметры

`--site`, `--domain`, `--template`, `--port`, `--remote`, `--destination`.
`--site-name` не обязателен, но без него в шапку встанет домен.

**`--remote` обязателен.** Без адреса собственного репозитория сайта доставка
содержимого в ячейку отказывает: «в реестре нет адреса репозитория». Сайт
поднимется, покажет засеянный каталог и больше никогда не обновится.

`newsite` откажется собирать из грязного дерева — это требование, а не помеха:
иначе закрепление назвало бы коммит, которому файлы не соответствуют.

### Что приезжает отдельно

| Что | Откуда | Без него |
| --- | --- | --- |
| `config/player.json` | Secret Hub, `secret://cdnvideohub/lords/publisher-id` | `run.py` не стартует |
| `src/community.py` | выпуск `20260923T190000Z-community-2-2-12` | раздел оценок и комментариев выключен с причиной — рабочее состояние |
| ключ модератора | вне Git, `LORDS_0X_COMMUNITY_MODERATOR_KEY` | сообщения остаются «ожидает проверки» |
| снимок каталога | производитель, через `factory.cell.delivery` | `run.py` отказывает: «нет снимка каталога» |

Имена переменных печатает сам `newsite` (`cell.storage_env`,
`cell.moderator_key_env`) — выдумывать не нужно.

## 6. Что остаётся за фабрикой

1. Зарезервировать три профиля по таблице §2, по одному заказу на домен.
2. Создать три проекта командой §3 из коммита §1.
3. Завести три репозитория сайтов и отправить проекты.
4. Выдать `player.json`, доставить `community.py`, задать ключи модератора.
5. Первая доставка каталога и первый выпуск — штатной очередью:
   `factory cell trigger --site <id> --confirm-activation`.
6. Приёмка на домене: `./checks/run.sh`, затем
   `artifacts/evidence/lords-template-1.1.0/verify.py` по адресу.
