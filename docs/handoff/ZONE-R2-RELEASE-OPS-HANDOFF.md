
Единственная запись:

```
/title/kakoy-skandal-2/  →  /title/kakoy-skandal--2025/
```

## Что обязан делать рантайм

1. **Читать `redirects.json` из того же каталога релиза**, что и страницы.
   Файл — часть артефакта, его отпечаток входит в отпечаток артефакта.
2. **Загружать карту атомарно**: целиком до начала обслуживания. Частично
   прочитанная карта хуже отсутствующей — часть адресов отвечает 404
   непредсказуемо.
3. **Отказывать при несовпадении отпечатка** или нечитаемом файле: не
   стартовать с пустой картой. Пустая карта неотличима от «переездов нет», а
   это разные вещи.
4. **Отвечать 308** на адрес-источник, **только если цель собрана**. Переход
   на несобранную страницу — это 404 через лишний шаг.
5. **Не выдавать переезд, если цель сама является источником переезда**:
   цепочки длиннее одного шага запрещены.

| Петель | 0 |
| Источник переезда среди собранных страниц | 0 |
| Любой другой прежний адрес витрины | 200 без перехода |

Последняя строка существенна: из 53 138 действующих публичных адресов
переезжает **один**. Если дымовая проверка показывает переезды где-то ещё,
выложен не тот артефакт.

## Откат

Откат — возврат прежнего артефакта целиком, вместе с его `redirects.json`.
Отдельно откатывать карту переездов нельзя: она описывает адреса именно того
релиза, рядом с которым лежит.

## Граница

Templates не меняет рантайм витрин, systemd, nginx и порядок выкладки. Если
рантайм не умеет читать карту переездов, правильный исход — не выкладывать, а
вернуть задание владельцу рантайма.
