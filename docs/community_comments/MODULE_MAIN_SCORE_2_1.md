## Формула

```
main_score = (ВЕС_БАЗЫ * B + сумма_наших) / (ВЕС_БАЗЫ + число_наших)
```

| Состояние | Значение |
| --- | --- |
| база и голоса | `(5*B + native_sum) / (5 + native_count)` |
| только база | `B` |
| только голоса | среднее наших |
| ничего | пусто, `значение is None` — **без выдуманного нуля** |

**Вес — настройка, а не число в формуле.** `ВЕС_БАЗЫ = 5` и
`ВЕРСИЯ_РАСЧЁТА = "main-score/1.0"` меняются вместе: величина, посчитанная по
другой методике, несравнима с прежней, и это должно быть видно в данных.

**Пяти фиктивных голосов не заводится.** Вес живёт в формуле; `native_count` —
только реальные записи посетителей. Проверено тестом, который читает файл
хранилища и считает записи.

**Округление только для показа.** `точное` остаётся неокруглённым; `значение` —
один знак.

## Выбор базы

Первый источник из **подтверждённого приоритета разрешённых** источников
витрины, у которого есть годное значение. По умолчанию:
`("shikimori", "kp", "imdb", "mal")`; витрина передаёт свой список.

Не максимум: выбор «где больше» брал бы каждый раз другой источник и давал
величину, происхождение которой не назвать. Оценка самой витрины (`amd`) базой
быть не может — иначе мнение наших зрителей вошло бы в формулу дважды.

Шкала приводится к десятке; исходные значения источников сохраняются как есть
(`raw_value`, `raw_scale`) и **не изменяются**.

## Что хранится раздельно

```json
"<content_id>": {
  "votes": {"<голосующий>": 8},
  "base": {
    "value": 8.0, "source": "shikimori",
    "raw_value": 8.0, "raw_scale": 10.0,
    "fixed_at": "…", "fixed_by": "first-vote", "weight": 5,
    "method": "main-score/1.0"
  }
}
```

Внешние текущие значения приходят от витрины при каждом расчёте и в хранилище
не пишутся. Результат не кэшируется в данных — он вычисляется.

## База закрепляется первым голосом

До первого голоса база **предварительная**: показывается, но не пишется
(`база_предварительная: true`). При первом голосе закрепляется и больше не
меняется.

Обновление источника **не меняет закреплённую базу скрытно**: расхождение
возвращается как `база_разошлась` и `внешняя_сейчас`, и витрина показывает его
отдельной строкой.

## Миграция существующих голосов

`зафиксировать_базу(тема, внешние, приоритет)` — явная и идемпотентная.
Повторный вызов возвращает `already` и ничего не меняет. Темы без голосов
пропускаются: база фиксируется голосом, а не запуском миграции.
`темы_без_базы()` перечисляет, что подлежит миграции.

Голоса миграция не трогает — проверено тестом.

## Единый результат

`главный_рейтинг(...)` — одна функция на главную карточку, обсуждение и
карточки каталога. Три независимых вычисления одного и того же неизбежно
разойдутся. Личная оценка посетителя показывается **отдельно** и в формулу
как отдельная величина не подставляется.

## Производительность

`_прочитать` кэширует разобранный файл по `(mtime_ns, размер)`: страница
каталога рисует шесть десятков карточек, и каждой нужен рейтинг. Кэш не
переживает чужую запись — проверено тестом.

## Проверки

1113 модульных тестов. Отдельно: четыре состояния формулы, выбор базы по
приоритету (и что не максимум), приведение шкалы, закрепление базы первым
голосом, неизменность при обновлении источника, идемпотентность миграции,
сохранность голосов, гонка десяти первых голосов, изоляция витрин, отсутствие
фиктивных голосов, округление только показа, корректность кэша.

Теневая приёмка по настоящему HTTP: `SHADOW_PUBLIC_VERDICT=PASS` —
карточка, обсуждение и каталог показывают одно число.

## Контракт подключения

```python
хранилище = community.открыть(ПУТЬ, витрина="<site_id>")

# при голосовании — передать внешние, чтобы база закрепилась
хранилище.добавить_голос(content_id, значение, ключ_посетителя,
                         slug=slug, account_id="",
                         внешние={"shikimori": 8.0, "kp": 6.0},
                         приоритет=("shikimori", "kp", "imdb", "mal"))

# везде, где показывается оценка
r = хранилище.главный_рейтинг(content_id, внешние, приоритет, slug=slug)
r["значение"]      # для показа, один знак
r["состояние"]     # base+votes | base-only | votes-only | empty
r["голосов"]       # только живые
r["база_разошлась"], r["внешняя_сейчас"]   # показать отдельно
```
