# Источники фактов по типу произведения — предложение на решение владельца

Владелец 2026-10-09: ID Shikimori не должен быть обязательным условием для
фильмов и обычных сериалов; если внешнего идентификатора нет — проверка
идентичности и поиск источника, а не постоянное исключение карточки.

## Что есть сейчас (D199)

Одобрены Shikimori API (по ID из каталога, сверка русского названия) и одна
страница официального сайта по ссылке Shikimori с проверкой robots.txt. Для
фильмов и сериалов одобренного источника нет. Список хостов
(`inventory/network-allowlist.yaml`) расширяет только владелец — без решения
SEO-сессия новые сайты не открывает.

Трафик этих сайтов почти целиком идёт на карточки, где описание уже есть
(5 из 6, 11 из 13, 4 из 5 посещаемых тайтлов).

## Что уже сделано без новых источников

* Карточки без ID одобренного источника больше не выпадают молча: суточный
  прогон пишет их в `var/seo-regular/editor-candidates.json → needs_source` с
  данными для проверки идентичности (тип, год, страны, IMDb, Кинопоиск, TMDb,
  MyDramaList) и планом источника по типу (`regular.SOURCE_PLAN`).
* Аниме по-прежнему идёт через Shikimori; запуск без источника заканчивается
  исходом SOURCES_MISSING с перечнем проверенного, а не текстом из полей.

## Предложение (нужен выбор владельца)

| вариант | идентичность | факты | условия | оценка |
| --- | --- | --- | --- | --- |
| **A. Wikidata + русская Википедия** (рекомендую) | Wikidata API по IMDb (P345) или Кинопоиску (P2603) → один элемент, сверка названия и года | год, страна, режиссёр, жанр — Wikidata (CC0); завязка — раздел статьи ru.wikipedia через API (CC BY-SA: пересказ, без копирования) | хосты `www.wikidata.org`, `ru.wikipedia.org` в allowlist; проверка robots.txt для ClaudeBot/anthropic-ai до первого запроса; запись D200 через /research-freeze | ключ не нужен; покрывает большую часть фильмов и сериалов с IMDb |
| B. TMDb API | по TMDb/IMDb ID | синопсис, год, жанры | нужен API-ключ (secret_ref) и атрибуция TMDb; ключа нет → BLOCKED_SECRET | покрытие хорошее, но ключ и условия |
| C. Кинопоиск | по ID каталога | синопсис | официального открытого API нет; неофициальные — с ключом и неясными условиями | не рекомендую |

Для аниме без ID в каталоге: поиск Shikimori `GET /api/animes?search=` по
русскому названию с обязательным совпадением названия, года и вида; при любом
расхождении — IDENTITY_UNCLEAR, текст не пишется. Это отступление от D199 («ID
из каталога, не из поиска») и тоже требует записи решения.

До решения владельца ни одного нового хоста SEO-сессия не открывает.
