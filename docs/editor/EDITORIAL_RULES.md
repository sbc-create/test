# Правила редакционного текста сети

Обязательны и для сессии, и для фонового редактора. Основание каждого
правила — замечания владельца 2026-10-08 и отказы ворот качества.

## Источник

* Разрешены (решение владельца 2026-10-08, D199; `config/editorial-sources.json`,
  `inventory/network-allowlist.yaml`): каталог сети (`editorial_facts`), Shikimori
  через API (`automation/local/source_fetch.py shikimori <id>`), официальный сайт
  произведения — только по ссылке `official_site` из Shikimori того же ID и только
  если robots.txt разрешает ИИ-агентам (`source_fetch.py official <id>`).
* MyAnimeList не используется: robots.txt запрещает ИИ-агентам весь сайт, API
  требует client id. Jikan с этого хоста недоступен (таймаут соединения).
* Идентичность: ID берётся из каталога, не из поиска; название в ответе Shikimori
  обязано совпасть с названием карточки.
* Текст источника не копируется и не переводится дословно: факты завязки — своими
  словами, без рекламных оборотов.
* Нет завязки ни в одном источнике — текст не пишется (SOURCES_MISSING).

## Язык

* Только язык посетителя. Запрещены внутренние слова: «витрина», «каталог
  витрины», «карточка», «жанровая рамка», «снимок», «заявлено».
* Название — ровно как в каталоге, оригинальное — в скобках.
* Без обещаний доступа: «доступны», «можно посмотреть», «открыты все серии».

## Числа и статусы

* Статус выхода («завершён», «продолжает выходить») — только по внешнему
  источнику (Shikimori `status`). Сама редактируемая страница статус НЕ
  подтверждает: 2026-10-08 карточки «Пожиратель звёзд» и «Хитклифф» показывали
  «Онгоинг» у давно завершённых сериалов.
* Первоисточник, автор, журнал, студия — только из `source_fetch.py credits <id>`
  (`adapted_from`, `original_creators`, `studios`). Время глагола о манге — по
  `adapted_from[].status`: «печатается/публикуется» только при `ongoing`, при
  `released` — «выходила». Издательства, которого нет в ответе, не называть.
  2026-10-09 «Серая Золушка» на icu и «Серая Золушка. Часть 2» на space
  называли завершённую мангу выходящей — исправлено.
* Рейтингов (IMDb, Shikimori) и текущих счётчиков серий в тексте нет: они не
  описывают произведение и устаревают. Число серий — только у завершённого
  сериала и только если оно нужно для понимания (например, «короткий сериал из
  двенадцати серий»), при совпадении страницы и внешнего источника.
* «Полностью», «целиком», «все серии» — не писать.
* Каталог и внешний источник расходятся в завязке — пишется подтверждённое
  внешним источником; неподтверждённое опускается.

## Уникальность

* Одно своё описание произведения на сеть (с 2026-10-09). Пересказ уже
  написанного описания для другого домена по тому же источнику — синонимайз,
  он запрещён владельцем; за ночь 08→09.10 таких пар icu/space было 9.
  Проверенные факты можно использовать снова, но в ДРУГОМ материале: подборка,
  порядок просмотра, новость о подтверждённом событии. Кандидаты строятся по
  этому правилу (`regular.editor_candidates`).
* Дубль синопсиса каталога между animedia.icu и animedia.space меняется только
  на space; icu остаётся контрольной страницей пилота (MOD-25), пока пилот не
  оценён на +14 дней.
* Хороший существующий текст без конкретного основания не переписывается.

## Публикация

* Только через мост: prepare_material → publish_material → editorial_queue_result.
* Повторная публикация — с `expect_generation`; чужую последнюю запись
  хранилища не перезаписывать.
* После публикации — проверка страницы: 200, текст виден, meta обновлена.
* Каждое изменение — строка в журнале изменений (проблема, доказательство,
  гипотеза, откат).
