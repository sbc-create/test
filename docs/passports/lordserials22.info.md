Так разрешён ремонт MOD-81 на контроле `1lordserials1.online` («чинить РАЗРЕШЕНО: это возврат к нормальному поведению»). Разрешает владелец опыта в записи, а не исполнитель по своему усмотрению; без такой записи контроль не трогается.

Роль определяет сама запись опыта, а не поиск по тексту: упоминание здесь — повод прочитать запись.
