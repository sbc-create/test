## Порядок выката (согласован с Архитектором по сути; разрешение — пользователь)

   к коммиту — по согласованию с владельцем текущей ветки этой копии.

   (blue-green, автооткат).

5. `python3 automation/local/publisher-id-check.py <домен>` — publisher в

   zonafilm.space 10252, zonafilm12.site 10261, lordserials22.info 10238).
