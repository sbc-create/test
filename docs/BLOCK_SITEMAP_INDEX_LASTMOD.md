# Блок доставки — дата части в индексе карты (MOD-111)

**Что исправлено:** индекс карты не нёс `<lastmod>` ни у одной части, и
обходчику было нечем решать, перезапрашивать ли файл на 45 000–67 000 адресов.
Правка ставит дату части из **максимума дат внутри неё**.

**Где:** `automation/host/seo_layer.py`, функция `построить_sitemap`.

**Кого касается:** 12 витрин — Lords (4), Zona (3), Animedia (2), Animego (3).
Витрины Yummy сюда НЕ входят: у четырёх из пяти дата индекса уже верна, у
`yummyani.site` она есть и устарела, и это закрывается отдельным блоком
(`docs/OWNER_BLOCK_YUMMY_SITE_IMAGE.md`).

## Почему заменять файл целиком нельзя

Измерено 20.10:

| что | размер | дата |
| --- | --- | --- |
| `automation/host/seo_layer.py` в этой ветке | **39 884 байта** | сегодня |
| `/srv/lords/.frontend/seo_layer.py` (установлено) | **17 637 байт** | **15 сентября** |
| `/srv/animedia-icu/app/src/seo_layer.py` | 17 637 байт | — |

Установленная копия отстаёт от ветки на 22 КБ. Полная замена принесла бы на
витрины двадцать два килобайта изменений, которых никто не заказывал и не мерил,
— и это ровно та ошибка, на которой я уже сбился сегодня дважды: наличие правки
в ветке не означает, что ветка и есть установленное.

**Но правка применима точно**, и это проверено чтением установленного файла:
блок построения индекса в нём совпадает с правленым дословно —
`/srv/lords/.frontend/seo_layer.py`, строки 287–292:

```python
    индекс = ET.Element("sitemapindex", xmlns=SM_NS)
    for имя, _ in файлы:
        s = ET.SubElement(индекс, "sitemap")
        ET.SubElement(s, "loc").text = f"https://{хост}/{имя}"
```

Поэтому доставлять надо **точечный патч этого блока**, а не файл.

## Что именно меняется

Внутри цикла по частям добавляется сбор даты, а в индекс — её вывод:

```python
    даты_частей: list[str] = []
    for н, часть in enumerate(части, start=1):
        ...
        даты_частей.append(max((lm for _, lm in часть if lm), default=""))
        ...
    индекс = ET.Element("sitemapindex", xmlns=SM_NS)
    for (имя, _), дата in zip(файлы, даты_частей, strict=True):
        s = ET.SubElement(индекс, "sitemap")
        ET.SubElement(s, "loc").text = f"https://{хост}/{имя}"
        if дата:
            ET.SubElement(s, "lastmod").text = дата
```

Точный текст с пояснениями — в `automation/host/seo_layer.py` этой ветки.

## Чего правка намеренно НЕ делает

**Не подставляет время сборки.** Это было бы хуже отсутствия даты: обходчик
поверил бы, что часть обновилась, и перечитал бы 45 000 адресов, в которых ничего
не изменилось. Дата берётся из записей внутри части.

**Не освежает старые части.** У Lords и Zona свежайшая запись во второй части —
июнь 2025 при первой от 2026-10-20, потому что адреса делятся по порядку и во
вторую попадают работы постарше. Их дата законно старая и обязана остаться
старой.

**Не ставит `lastmod`, если внутри части нет ни одной даты.** Пустая дата и
выдуманная «сегодня» обе врут; отсутствие честно.

Все три запрета закреплены проверками: `tests/unit/test_sitemap_index_lastmod.py`,
8 проверок. Подстановка обеих худших правок даёт падения — при снятом `lastmod`
падают 5 целевых проверок, при подстановке времени сборки — 4 других.
