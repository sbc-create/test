# Оценки — Zona (w140.zona.plus)

Выводятся все источники, пришедшие через контракт, и ничего сверх.

Оценка без источника не выводится: число без имени источника неинтерпретируемо. Шкала, число голосов и время наблюдения показываются, только если пришли, и никогда не достраиваются.

Отсутствие оценок убирает область целиком, не оставляя пустой рамки.
