# Состояния — Animedia (amd.online)

| Состояние | Что обязано быть |
|---|---|
| normal | содержимое из источника |
| empty | явное объяснение пустоты |
| degraded | честное сообщение вместо выдуманных данных |
| not_found | код 404, заголовок, выход |

Недопустим единственный исход — молчащая пустота.
