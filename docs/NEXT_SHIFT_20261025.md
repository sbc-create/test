## Ловушка, которую стоит поискать ещё раз

Класс 41: проверка `test_editor_throughput.py` падала потому, что фикстура
строила отметку времени из ЖЁСТКО записанной даты (`2026-10-24`), а инструмент
берёт окно от настоящего `now` — проверка жила ровно сутки. Поправлено, но
стоит поискать то же в других фикстурах: признак — абсолютная дата в строке
`at`/`published_at` рядом с вызовом, который считает «последние N часов».
Быстрый поиск: `grep -rn "202[0-9]-[01][0-9]-[0-3][0-9]T" tests/ | grep -v
_недавно`. Семь файлов с наибольшим числом таких отметок проверены 25.10
16:3xZ — **190 passed**, то есть сейчас больше ни одна такая проверка не падает;
опасны только те, где код под проверкой сам смотрит на `now()`.
