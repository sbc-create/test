```
$ python3 -m factory analytics rotate-check
ротация требуется: False
причина: состояние токена не проверено: файл секрета недоступен этой учётной записи
```

Снято 20.10 в 11:40Z. Отсюда следует всё остальное в этой записи:

* **живые визиты** и **страницы со входами из поиска** живут в кабинете
  Яндекс.Метрики и Вебмастера. Доступ к ним идёт через `secret_ref`, и файл
  секрета этой учётной записи не отдан. Это `BLOCKED_ANALYTICS_ACCESS` —
  нерепитабельный статус, при котором конвейер по правилу не продолжает с
  выдуманными данными;
* **обход** и **индексация** (сколько адресов обойдено, сколько в индексе) тоже
  данные кабинета Вебмастера. Их нельзя получить из публичной страницы;
* брать их из поисковой выдачи запрещено отдельно: скрапинг поисковиков
  закрыт режимом CLOSED_WORLD, и это не обходится.

Поэтому ниже стоят «неизвестно» — не как заполнитель, а как измеренный исход.
