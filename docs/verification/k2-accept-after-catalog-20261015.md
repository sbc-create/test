## Чего этот прогон НЕ проверяет

**Внешнее имя и сертификат** — записи DNS всё ещё ведут на прежний сервер
(45.131.182.225), поэтому проверка идёт запросами к nginx узла с нужным
`Host`. Что отдаётся по публичному имени, измерено отдельно: **404 по http и
отсутствие страницы по https** — работающей копии на этих именах нет вовсе
(см. раздел «Что публичные имена отдают СЕЙЧАС» в
[`K2_PUBLIC_RELEASE_20261015.md`](../K2_PUBLIC_RELEASE_20261015.md)). Путать
«витрина принята на узле» и «витрина доступна по имени» нельзя: сейчас верно
первое и неверно второе.

**Воспроизведение браузером** — в этом сценарии браузера нет. Оно подтверждено
на локальных стендах у всех восьми (`automation/local/stand-player-check.py`) и
будет повторено по публичным адресам после перевода DNS
(`publisher-id-check.py`).

**Допуск к индексации** — закрыт намеренно и измерен отдельно:
[`k2-indexing-mode-20261015.md`](k2-indexing-mode-20261015.md). Доступность
посетителям и допуск к обходу — разные вещи.
