## 2. Кодированные идентификаторы — отдельным блоком

Проверено на РЕАЛЬНЫХ идентификаторах из ответов каталога:
тайтл `01a128be-d2b6-7e7d-a418-00de4d99eb2d`, сезон
`01a128be-d2b6-7e7d-a418-00de4d99eb2d:s1`, серия `…:s1:e1`.

| проверка | результат |
| --- | --- |
| серии сезона: «:» и `%3A` | коды 200 и 200, **тела совпадают** |
| серии сезона: «:» и `%3a` | коды 200 и 200, тела совпадают |
| источники серии: «:» и `%3A` | коды 200 и 200, тела совпадают |
| источники серии: «:» и `%3a` | коды 200 и 200, тела совпадают |
| несуществующий сезон `…:s99`, «:» | 404, `code: not_found` |
| несуществующий сезон `…:s99`, `%3A` | 404, `code: not_found` |
| закодированный разделитель `%2F` | 400, `code: bad_request` — сегмент не делится |

Сравниваются не только коды, но и сами данные: равные коды при разных телах
были бы тем же дефектом, только незаметным.

До исправления (измерено 2026-10-11 на этом же адресе) закодированная форма
отдавала **404**: `серии, двоеточие как %3A → 404`, `как %3a → 404`,
`источники серии как %3A → 404`. После повторного запуска установщика все три
отвечают 200.

`NO_SOURCE_CONTRACT_RELEASED`. Это постоянное ограничение контракта, а не
состояние службы — перечень недостающих возможностей провайдера в
`docs/APP_READ_API.md` §5.1. Число серий в ответах доказательством наличия
работающего видео не является.
