# Измеренный результат по сети — неделя к неделе, 2026-10-17

Источник — суточные снимки Метрики, которые собирает служба:
`artifacts/analytics/analytics-YYYY-MM-DD.json`, окно каждого снимка
`7daysAgo…yesterday`. Токен Метрики читает служба, а не сессия
(`BLOCKED_SECRET`), поэтому прямых запросов к API не делалось и поток
повторов не создавался: взяты уже собранные выгрузки.

* «сейчас» — снимок **2026-10-17**, собран 05:09 UTC, окно 10.10–16.10;
* «раньше» — снимок **2026-10-10**, собран 11:09 UTC, окно 03.10–09.10;
* часовой пояс счётчиков — **Europe/Moscow** (паспорт счётчика);
* неполные текущие сутки в сравнение не входят.

Инструмент: `automation/local/traffic-week-over-week.py`, выгрузка —
`var/seo/traffic-wow.json`.

## Выводы по направлениям

**Подтверждённое улучшение.** Yummy: `yummyani.site` прошёл целевой уровень —
10 157 визитов людей в сутки против 2 448 неделей раньше; поисковых визитов за
неделю 12 226, из них 12 213 из Яндекса. Растут и остальные четыре Yummy.
Anime/Zona тоже выросли: `animedia.icu` ×5.6, `zonafilm12.site` ×4.7,
`zonafilm.cc` ×2.5, `lordserials22.info` ×2.9.

**Подтверждённое ухудшение.** Четыре домена просели к прошлой неделе:
`lordfilm47.space` (−46), `animeg0.site` (−49), `animedia.space` (−36),
`an1mego.site` (−26). Причины НЕ установлены этой выгрузкой — у всех четырёх
поисковых визитов мало или нет вовсе, то есть просело не поисковое, а прочее.

**Данных недостаточно.** Позиции и показы по запросам не измеряются: доступ к
Вебмастеру закрыт (B023), а в снимке поля `pages_in_search`, `excluded_pages`,
`popular_queries` помечены «не измерено». Без них нельзя сказать, какие
запросы выросли и где есть показы без переходов. Исходная точка для позиций в
проекте отсутствует — её нужно создавать отдельно.

## Два домена без единого поискового визита

`1lordserials1.online` и `animedia.space` за неделю не получили ни одного
поискового визита при открытой индексации, живом sitemap и `canonical` на
себя (проверено сегодняшним прогоном `indexability-sweep.py`: находок 0).
Значит препятствие не в доступности страниц, и следующий шаг для них —
данные Вебмастера, а не правки вёрстки. У `animedia.space` дополнительно
`вебмастер=VERIFICATION_FAILED` в `factory analytics status` — это
самостоятельный, устранимый блокер: без подтверждённых прав поисковые данные
по домену не получить вовсе.

## Что из этого следует для работы

1. Рост Yummy и Animedia/Zona идёт из Яндекса и Google; у этой группы цель
   достижима наращиванием того же, что уже работает.
2. Для четырёх просевших доменов сначала нужен Вебмастер, а не вёрстка.
3. Для восьми K2 вопрос трафика сейчас не стоит: они закрыты от индексации и
   исключены из продвижения решением владельца.
