## Две ошибки инструмента, найденные по дороге

Обе могли бы попасть в отчёт как дефекты сети, поэтому записаны:

1. **24 ложных «не измерено».** `items` у черновиков комментариев — СЛОВАРЬ по
   slug, а у накладки описаний — список. Инструмент ждал список в обоих и не
   находил тела комментариев. Исправлено, закреплено тестом.
2. **24 ложных «отказа».** После первого исправления инструмент искал текст
   комментария в HTML — а блок комментариев витрины рисуется на стороне
   клиента (измерено 09.10: текст был в базе и отдавался API, а в HTML его не
   было вовсе). Теперь по HTML комментарий не проверяется вовсе: без браузера
   это «не измерено» с причиной, с `--comments-browser` проверка передаётся
   `comment-visible-check.py`. Закреплено тестом, который падает, если
   инструмент запросит страницу для комментария.

Первый вариант этой же проверки дал бы «24 отказа» на пустом месте — ровно та
ошибка, которую стоит ловить до отчёта, а не после.
