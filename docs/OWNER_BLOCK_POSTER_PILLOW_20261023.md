## Шаг 1. Поставить библиотеку в СИСТЕМНЫЙ интерпретатор

```bash
sudo apt-get install -y python3-pil
```

**Проверка — не «пакет установлен», а «его видит интерпретатор службы»:**

```bash
python3 -s -c 'import PIL; print(PIL.__version__, PIL.__file__)'
# ожидается путь в /usr/lib/python3/dist-packages/PIL/, НЕ в ~/.local
```

Если путь указывает в `~/.local` — остановиться: пакет поставлен не туда, и
служба его по-прежнему не увидит. `pip install --user` этот шаг не выполняет.

**Проверка от имени самой службы** (у неё своя учётная запись, и её окружение —
единственное, которое имеет значение):

```bash
sudo -u animedia-icu python3 -s -c 'import PIL; print(PIL.__file__)'
```

## Шаг 3. Приёмка — по публично загружаемым изображениям, а не по пакету

Установленный пакет и зелёные тесты результатом уменьшения **не считаются**.
Засчитывается только изменение того, что получает браузер:

```bash

python3 automation/local/poster-delivery-audit.py --domain animedia.icu \
        --domain animedia.space --per-page 8 \
        --csv artifacts/evidence/posters/poster-delivery-after-t330.csv
```

Что обязано измениться и что обязано НЕ измениться:

| проверка | ожидание |
| --- | --- |
| тяжёлая обложка на канарейке | ширина не больше 480, вес меньше 160 990 Б |
| та же обложка на контрольном домене `animedia.space` | без изменений: 160 990 Б, 1086×1448, `sha256 d4502599c27c` |
| обложка, уже уместившаяся в окно (`01a15a56…webp`, 259×450, 18 730 Б) | байт в байт как у источника — перекодирования быть не должно |
| любая обложка | вес НЕ вырос ни у одной |
| время ответа канарейки | `public-speed-probe.py` по четырём маршрутам: превышений ноль, как 23.10 11:3xZ (главная 0,37 с, каталог 0,28 с) |

Сравнение «до/после» делается против снимка
`artifacts/evidence/posters/t330-baseline-before-release-20261023.txt` и против
контрольного домена, а не против памяти.
