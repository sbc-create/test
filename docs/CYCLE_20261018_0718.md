## Шесть ошибок собственных признаков, найденных за цикл

Все — один род: признак отвечал не на тот вопрос, о котором делался вывод.

1. `карточек 0` на `yummyani.site` — на главной 97 карточек формы `/anime/`;
2. `код 308, карточек 0` на работающей листалке — проба не проходила
   перенаправление на канонический адрес;
3. `фильтр жанра не сужает` — брался первый жанр из ссылок, а у аниме-витрины
   это `anime`, равный всему каталогу;
4. `доля 53.7 % — подстановка даты` — дата была у 54 адресов из 50 000;
5. `release_id не от выпуска` — условие отвергло бы каждую исправную выкладку;
6. `УСТАРЕЛО` на восьми свежих витринах — инструмент читал вчерашний отчёт из
   рабочей копии, не заглядывая в постоянный каталог доставки.

Каждая исправлена так, чтобы не вернуться молча, и к каждой стоит
отрицательный контроль в тестах.

## Две поправки к собственным выводам

* **«Приедет вашим обычным выпуском»** — неверно для витрин, чьё ядро
  закреплено на ветке от прежнего пина. Ошибка была не в измерении, а в
  предположении о доставке; записана в R-10 как первый измеренный вред
  расхождения пинов;
* **«Остаток касается части записей»** — неверно: самый крупный жанр несут
  41 404 записи из 64 508, то есть 64 % страниц. Оценку делала по размеру
  жанра, а не по числу записей, которые его несут. Правка, отложенная по этой
  оценке, сделана через полчаса.
