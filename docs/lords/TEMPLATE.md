# Шаблон `blueprints/lords`: как он устроен и как его открыть

Документ описывает работающее приложение, а не намерение его написать. Всё, что
здесь названо, проверяется тестами `tests/unit/test_lords_template.py` и
браузерным прогоном `playwright.lords.config.js`.

## Два слоя и почему их два

| Слой | Модуль | Отвечает на вопрос |
| --- | --- | --- |
| План | `factory/lords/plan.py` | какие поверхности существуют и кто их индексирует |
| Рендерер | `factory/lords/render.py` | как эти поверхности выглядят |
| Рантайм | `factory/lords/serve.py` | что происходит с адресом, которого нет, и с адресом, записанным иначе |

План не заменяет сайт: его нельзя открыть в браузере и нельзя посмотреть
глазами. Рендерер не заменяет план: по готовому HTML не видно, какой из четырёх
сайтов владеет разделом. Слои разделены, потому что отвечают на разные вопросы,
и оба нужны.

## Команды

```bash
python3 -m factory lords-preview --site lords-01              # собрать стенд
python3 -m factory lords-preview --site lords-01 --serve --port 8080
python3 -m factory lords-preview                              # все четыре пакета
python3 -m factory lords-bundle  --site lords-01              # переносимый пакет
python3 -m factory lords-plan    --assume-source fixture      # только план
.venv/bin/python tests/tools/lords_stand.py                   # четыре сайта разом
npx playwright test --config=playwright.lords.config.js       # браузерная приёмка
```

Локальные адреса стенда: `lords-01` — <http://127.0.0.1:8801/>, `lords-02` —
<http://127.0.0.1:8802/>, `lords-03` — <http://127.0.0.1:8803/>, `lords-04` —
<http://127.0.0.1:8804/>.

`python3 -m factory build --site lords-0N` сейчас **останавливается** — и это
правильный результат, а не недоделка: права на контент CDNVideoHub не
подтверждены, цель выката не передана. Стенд собирается отдельной командой
именно затем, чтобы это различие не размылось.

## Маршруты

| Адрес | Что это | Появляется, если |
| --- | --- | --- |
| `/` | главная | всегда |
| `/catalog/`, `/catalog/page/{n}/` | каталог с фильтрами | активен хотя бы один тип |
| `/movies/`, `/series/`, `/animation/`, `/anime/`, `/dorama/` | разделы по типам | соответствующий тип в состоянии `enabled` |
| `/collections/`, `/collections/{slug}/` | подборки | тип `collections` включён |
| `/new/` | новое | активен хотя бы один тип |
| `/schedule/` | что продолжается | активен тип `series` |
| `/genres/`, `/genres/{slug}/` | жанровые посадочные | активен хотя бы один тип |
| `/years/`, `/years/{year}/` | годы выпуска | то же |
| `/countries/`, `/countries/{slug}/` | страны производства | то же |
| `/title/{slug}/` | страница произведения | запись есть в каталоге |
| `/search/` | поиск | всегда; в индекс не отдаётся никогда |
| `/robots.txt`, `/sitemap.xml` | служебные документы | всегда |
| `/healthz`, `/readyz` | пробы рантайма | всегда |

Выключенный тип не создаёт ни маршрута, ни пункта меню, ни ссылки, ни URL в
sitemap. Обращение к его адресу даёт **404**, а не пустую двухсотку: пустой
раздел, отдающий 200, — это soft 404 и обещание, которое нечем выполнить.

Нормализация адреса отвечает **308**: верхний регистр, двойные слэши и
отсутствующий завершающий слэш исправляются один раз и без потери метода.

## Четыре профиля — одна кодовая база

Второй копии приложения нет. Различие задают `theme.tokens` и `layout` профиля:

| Профиль | Тема | Плотность | Герой | Колонки (моб/планшет/десктоп) | Фасеты |
| --- | --- | --- | --- | --- | --- |
| `lords-general` | тёмная, акцент `#6f9dff` | comfortable | каталог | 2 / 4 / 6 | сбоку |
| `lords-new` | тёмная, акцент `#ff9f45` | dense | лента | 1 / 3 / 4 | сверху |
| `lords-curated` | светлая, акцент `#9c4221` | airy | редакционный | 1 / 2 / 3 | нет |
| `lords-genre` | светлая, акцент `#1f6f5c` | compact | фасеты | 2 / 5 / 8 | в шапке раздела |

Тест `test_configuration_of_one_profile_does_not_leak_into_another` падает, если
настройка одного профиля попадает в разметку другого.

## Данные стенда

Каталог порождает `factory/lords/fixtures.py`: 62 записи, четыре подборки,
десять жанров, шесть стран, десять лет выпуска. Каждая запись помечена
`source: fixture/test`, названия и студии выдуманы, постеры — локально
сгенерированные SVG-заглушки с подписью `FIXTURE`.

Чего в записях нет **как полей**, а не как пустых значений: оценок, отзывов,
дат премьер, правообладателей. Их нельзя выдумать даже для витрины, поэтому
модель данных их не предусматривает.

## SEO без домена

* `canonical` не выдумывается: вместо ссылки страница несёт
  `<meta name="lords-canonical-state" content="absent_no_domain">`;
* каждая страница несёт `noindex, nofollow` в разметке;
* каждый ответ рантайма несёт заголовок `X-Robots-Tag: noindex, nofollow` —
  включая 404, 308 и статику;
* `robots.txt` закрывает сайт целиком (`Disallow: /`), `Sitemap:` в нём нет;
* `sitemap.xml` синтаксически корректен и не содержит ни одного адреса, с
  комментарием, объясняющим почему;
* выдача поиска и страницы пагинации от второй и дальше не индексируются никогда.

Индексируемую версию раздела отдаёт ровно один сайт из четырёх. Главная —
исключение по устройству: она принадлежит каждому сайту, тексты у неё разные, и
ворота уникальности это подтверждают.

## Плеер

Настоящий плеер CDNVideoHub не подключён. На его месте — заглушка со статусом
`BLOCKED_INPUT_CDNVIDEOHUB_CREDENTIALS`. Заглушка **не является** пройденной
проверкой контракта плеера: `player.contract_check()` возвращает `passed: false`
и объясняет, что проверка не запускалась.

Точка подключения серверная (`factory/lords/player.py`). Место в разметке,
размеры и подпись уже заняты, поэтому включение настоящего плеера меняет
содержимое кадра, а не раскладку страницы. Publisher ID подставляется на сервере
в момент ответа. Публичная переменная с Publisher ID запрещена: префикс
`NEXT_PUBLIC_` встроил бы значение в клиентский бандл, поэтому любая такая
переменная в окружении обрывает сборку исключением.

## Переносимый пакет

`lords-bundle` кладёт в архив документы сайта, рантайм на стандартной библиотеке,
`Dockerfile`, `bundle-manifest.json` и `rollback.json`. Свойства:

* архив детерминирован — повторная сборка даёт тот же sha256;
* рантайм ничего не устанавливает ни при сборке образа, ни при старте;
* `/healthz` и `/readyz` отвечают;
* `deployable: false` в манифесте: домена и цели нет, выкатывать нечего и некуда;
* артефакт отката лежит рядом с релизом, а не пишется в момент аварии.

## Что сейчас закрыто

| Код | Что закрывает |
| --- | --- |
| `BLOCKED_INPUT_DOMAIN` | canonical, sitemap, индексацию, TLS, Метрику, Вебмастер |
| `BLOCKED_INPUT_TARGET` | выкат и откат |
| `BLOCKED_INPUT_CDNVIDEOHUB_CREDENTIALS` | плеер, проверку его контракта, подтверждение типов контента источником |

Шесть операций невозможны механически, а не по договорённости:
`factory/lords/gates.py`, тесты — `TestProductionGates`.
