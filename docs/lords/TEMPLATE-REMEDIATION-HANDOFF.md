## Диагноз связности CTA (измерено, не предположение)

Полки и страницы назначения идут двумя разными путями в одном файле:

* полки — `выбрать(ключ, сколько, условие, пул)` с фильтрами и дедупликацией
  через множество `занято`;
* назначения — метод `список(...)`, простая сортировка без этих фильтров.

Отсюда 0/4 совпадений. Фактическое состояние главной Animedia:

| полка | CTA | чем набирается | проблема |
| --- | --- | --- | --- |
| `ongoing` «Онгоинги» | `/catalog/` | `выбрать(свежесть, условие=есть_серии)` | общий каталог; признака выхода в данных нет |
| `new-eps` «Новые эпизоды» | `/new/` | то же, что `ongoing` | номер и дата серии источником не передаются |
| `today` «Сегодня выйдет» | — | пусто | честное пустое состояние, менять не нужно |
| `new-anime` «Новые аниме» | `/new/` | `выбрать(свежесть)` | тот же URL, что у `new-eps`, другой набор |
| `top` «Топ по оценкам» | `/catalog/` | `выбрать(оценка, пул=400)` | общий каталог вместо среза по оценке |
| `collections` «Подборки» | — | пусто | честное пустое состояние, менять не нужно |

`/catalog/`, `/new/` и `/collections/` отдают идентичные 48 записей в одинаковом
порядке — различаются только `<h1>` и `<title>`.

## Что делать после разблокировки

1. Перевести `ленты` и метод `список` на единый `CollectionSpec` из
   `factory/lords/collection_contract.py`: один ключ коллекции — один резолвер
   для состава, порядка, количества, CTA, страницы и пагинации.
2. `ongoing` и `today` не показывать: подтверждённого признака выхода и даты в
   снимке нет (§4.4). Оставить честное пустое состояние, как у `today` сейчас.
3. `new-eps` и `new-anime` не могут вести на один URL. Либо у каждой свой
   доказанный предикат и свой маршрут, либо CTA скрывается.
4. Развести семантику маршрутов: `/catalog/` — весь каталог, `/new/` — только
   доказанное правило свежести, `/collections/` — перечень реальных коллекций.
   Для Zona дополнительно: `/new/` сейчас совпадает с `/catalog/`.
5. Визуальная часть требует переписать `оболочка` — согласовать с #76, иначе
   работа будет сделана дважды.
