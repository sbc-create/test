# Проверка комментариев владельцем — animedia.icu, Stage 1

Сначала одна root-команда (она в финальном отчёте), потом четыре шага ниже.
До команды ничего из описанного не появится, и это нормально.

## Что именно вы проверяете

Что комментарии работают для вас и **не существуют** для обычного посетителя.
Второе не менее важно: страница для постороннего должна выглядеть ровно так
же, как до пилота — без блока, без пустого места, без формы ввода.

## Шаг 1. Получить доступ

```bash
sudo -u lords /home/claude/wt-community-comments-platform-01/bin/comments-owner-cookie animedia.icu
```

Команда печатает строку для консоли браузера. Токен показывается один раз и
никуда не записывается. Он работает только на `animedia.icu`: имя витрины
лежит внутри подписи, поэтому на `animedia.space` бесполезен.

## Шаг 2. Открыть страницу и увидеть блок

Откройте **https://animedia.icu/title/master-lda-i-plameni-2/**, консоль
браузера, вставьте строку из шага 1, обновите страницу.

Внизу, после блока «Смотрите также», появится «Комментарии»: счётчик, три
кнопки сортировки и поле ввода над списком.

Если блока нет — cookie не установилась или истекла. Если блок есть, но
пишет, что комментарии недоступны, — не запущен шлюз, это видно в
`systemctl status comments-gateway`.

## Шаг 3. Написать комментарий

Впишите в поле:

```
Тест комментариев Animedia — владелец — <любой текст>
```

Нажмите «Отправить» **один раз**. Появится статус «Комментарий отправлен и
ждёт проверки модератора» — так и задумано, на пилоте включена премодерация,
и модератор здесь вы же. Двойной клик второго комментария не создаст.

Обновите страницу: комментарий на месте. Это и есть проверка, что он
сохранён, а не показан на секунду.

## Шаг 4. Ответ, правка, удаление

* **Ответить** — кнопка под комментарием; ответ появится со сдвигом и будет
  привязан к исходному. Вложенность ограничена тремя уровнями.
* **Изменить** — появится отметка о правке и вырастет номер ревизии. Прежний
  текст сохраняется в истории; правка возвращает комментарий в очередь
  модерации, иначе «написать безобидное, дождаться одобрения, переписать»
  было бы открытой дверью.
* **Удалить** — комментарий пропадёт из общего вида, но вы увидите его с
  пометкой «удалён». Так честнее, чем стереть молча: текст остаётся в базе,
  решение обратимо.

Проверить, что действия записаны:

```bash
sudo -u lords sqlite3 /srv/site-factory/var/comments/comments.sqlite \
  "SELECT occurred_at, action, object_id FROM cp_audit_events ORDER BY occurred_at;"
```

Текста комментария там нет и не будет — аудит хранит длину и усечённый
sha256, а не содержимое.

## Самое важное: проверьте постороннего

Откройте ту же страницу в приватном окне, без вашей cookie:

**https://animedia.icu/title/master-lda-i-plameni-2/**

Должно быть так: страница как раньше, блока комментариев **нет вообще**, поля
ввода нет, пустого места нет, ошибок в консоли нет.

И напрямую через API, из терминала:

```bash
curl -sS -o /dev/null -w '%{http_code}\n' \
  'https://animedia.icu/api/comments/v1/threads?resource_type=title&canonical_content_id=01a0b507-3280-7b2a-8af4-674dd73cff72'
```

Ожидается `503`. Не 200 с пустым списком: посторонний не должен узнать даже
того, что здесь есть что читать.

## Если что-то не так

Немедленная остановка, страница сайта не страдает:

```bash
sudo /home/claude/wt-community-comments-platform-01/automation/host/animedia-comments-stage1-rollback.sh
```

Без аргументов — два самых дешёвых уровня: kill switch и снятие блока со
страницы. С `--full` возвращает прежний релиз, манифест, vhost и убирает
шлюз. База комментариев не удаляется ни на одном уровне.

## Чего пилот не делает

Не меняет дизайн, контент, плеер, поиск, карточки, оценки, маршруты,
рейтинги, robots, canonical, sitemap, DNS и TLS. Не трогает `animedia.space`
и остальные витрины. `noindex, nofollow` остаётся на всех маршрутах, и скрипт
выкладки отказывается работать, если это не так.

## После проверки

Очистите тестовую cookie:

```js
document.cookie = "cp_cohort=; path=/; max-age=0";
```

И скажите, что дальше: расширять на второй домен, открывать публичный доступ
или откатывать. Само ничего не произойдёт.
