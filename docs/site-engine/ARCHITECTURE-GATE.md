# ARCHITECTURE_GATE

Гейт — исполняемая проверка, а не декларация. Код: `factory/site_engine/gate.py`,
тесты: `tests/unit/test_site_engine_gate.py`. Запуск:

```python
from factory.site_engine import gate
ok, results, neutrality = gate.run(".")
```

## Что проверяется

| № | Правило | Почему |
| --- | --- | --- |
| 1 | Профиль валиден по `schemas/site-engine/site-profile.schema.json` | без схемы профиль превращается в свалку полей |
| 2 | `site_id` совпадает с именем файла | иначе профиль правит не тот сайт, что ожидали |
| 3 | Домены не пересекаются между профилями | один домен — один владелец |
| 4 | В профиле нет секретов, только `*_ref` на Secret Hub | профили лежат в Git |
| 5 | `cache_policy` валиден по схеме кэша | кэш без контракта — источник тихих подмен |
| 6 | Заявленные адаптеры существуют в репозитории | профиль не может ссылаться на несуществующий код |
| 7 | При включённом SEO есть источник нормализованного контента | SEO не должен добывать содержимое сам |
| 8 | Ядро не содержит имён конкретных сайтов | различия живут в профилях, а не в `if site == ...` |

## Правило 7 подробно

SEO включён → требуется способность `normalized-content`. Удовлетворить её можно
тремя способами, любой достаточен:

1. **локальный `content-ingestion`** — сайт загружает каталог сам;
2. **общий Site Engine API** — `normalized_content_source: {"kind": "site-engine-api", "ref": "..."}`;
3. **другой зарегистрированный адаптер** — `{"kind": "adapter", "ref": "<имя адаптера>"}`.

Отказ выдаётся, когда нет ни одного из трёх, когда вид источника не из списка
разрешённых, и когда источник объявлен без `ref` — объявить источник и не
назвать его равносильно тому, чтобы не объявлять.

Требование идёт от SEO. Витрина без SEO под него не подпадает.

## Известное исключение

Проверка нейтральности ядра (правило 8) пропускает сам `gate.py`: список
запрещённых слов физически лежит в нём. Исключение узкое и намеренное — любой
другой файл ядра проверяется.

## Статус на 2026-08-30

Шесть профилей проходят гейт; нарушений нейтральности ядра нет. Все шесть сайтов
имеют локальный `content-ingestion`, поэтому расширение правила 7 не изменило ни
одного профиля — оно сняло запрет на схему, которой у нас пока нет, но которая
законна.
