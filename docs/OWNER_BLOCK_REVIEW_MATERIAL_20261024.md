# Владельцу: обязательная рецензия материалов — одно решение и один блок

Код готов и проверен (коммит `1a77697`, 26 проверок). Ставить его **нельзя**,
пока не названо одно: **кто проверяющий в штатном цикле**. Причина измерена,
а не предположена.

## Почему нельзя поставить как есть

Фоновый редактор — единственный исполнитель: `editor/claude-auto/run-*` и
готовит материал, и публикует его. Правило «автор не одобряет собственную
работу» сравнивает пару роль/автоматизация, поэтому другой ПРОГОН той же
автоматизации проверяющим не считается.

Проверено подстановкой:

| автор → проверяющий | исход |
| --- | --- |
| `editor/claude-auto` → `editor/claude-auto` (тот же прогон) | отказ |
| `editor/claude-auto` → `editor/claude-auto` (другой прогон) | отказ |
| `editor/claude-auto` → `editor/claude-review` | **проход** |
| `editor/claude-auto` → `architect/claude-session` | **проход** |

Цена установки без второго исполнителя: **51 публикация за сутки 24.10
превратится в 0**. Сверка соседней линии по этим 51: замечаний по страницам 0,
по качеству 0. То есть установка заменила бы «нет следа прочтения» на «нет
публикаций» — это хуже, и так ставить нельзя.

## Решение, которое требуется (одно)

Кто проверяющий. **Предложение, не требующее новых прав:** второй прогон того
же шлюза под именем вида `editor/claude-review/run-<метка>`.

- роль `editor` ограничений в `РАЗРЕШЕНО_РОЛИ` не имеет — новых разрешений не
  нужно;
- канал тот же, токен тот же — `FACTORY_ACTOR_ALLOW` не нужен;
- автоматизация другая, поэтому застава «автор не одобряет свою работу»
  проходит, а независимость сохраняется.

Если такой порядок подходит — дальше нужен только блок ниже.

## Блок (после решения о проверяющем)

`systemctl` закрыт хуком у **обеих** линий: у меня проверено 24.10
(`команда 'systemctl' не входит в профиль UNATTENDED_SAFE`), у соседней —
23.10. Поэтому установка и перезапуск — операция владельца.

```bash
cd /home/claude/wt-portable-site-cell-01 && \
  git fetch /home/claude/wt-nova-publish-memory-02 claude/nova-publish-memory-02 && \
  git merge --no-edit FETCH_HEAD -- factory/qwen
systemctl restart site-factory-mcp.service
curl -sS http://127.0.0.1:9000/healthz
```

| конвейер НЕ встал | за сутки после установки публикаций не меньше, чем 51 от 24.10 |

## Что уже сделано и не требует решений

- операция `review-material` в правах роли; роли `qwen` не разрешена;
- обязательные четыре проверки (соответствие произведению, подтверждение
  фактов источниками, отсутствие посторонних вставок, качество текста) и
  записанные источники при допускающем вердикте;
- допуск **внутри** `публиковать()`: без принятой рецензии выпуск запрещён,
  изменение одобренного текста требует повторной проверки — отзыв привязан к
  отпечатку, и правка сама делает его устаревшим;
- инструмент `review_material` (пишущий) и `editorial_queue_assigned`
  (читающий; закрывает передачу задания — до него готовящая сторона не могла
  узнать, что ей поручено);
- 26 проверок, из них 14 на отказы допуска; четыре прежние проверки приведены
  к новому договору, ни одна не ослаблена и не выключена.
