## 2. Наблюдатель серий для `yummyani7.info` и `yummyani7.site` (D2/MOD-121)

**Что решить:** как завести журнал наблюдений для двух контуров `7.*`. Сейчас
их каталоги пусты (`total 0`), а писатель пишет только в каталог проекта
`yummyani-staging`.

**Рекомендую вариант (а):** отдельные экземпляры наблюдателя под свои каталоги

**Подготовлено:** причина установлена по конфигурации и монтированиям, приёмка
названа линией ячейки (появляются `events.jsonl`/`watcher.json`, затем меняются
даты частей, затем сокращаются 126/131 пропуска).

**Завершает работу:** решение между (а) и (б) плюс установка unit-ов в
`/etc/systemd` (вне моего профиля).
