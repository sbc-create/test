файла**, и удаляет лишь при совпадении обеих сумм с записанной в описи:

## Откат

Удаление необратимо, но у КАЖДОГО удалённого файла в описи названа сохранённая
копия с тем же sha256 — поэтому восстановление это копирование, а не поиск:

```bash
cd /home/claude/wt-nova-publish-memory-02
python3 - <<'PY'
import csv, os, shutil
п = 'artifacts/evidence/posters/screenshot-cleanup-manifest-20261023.csv'
восстановлено = 0
for с in csv.DictReader(open(п, encoding='utf-8')):
    if с['исход'] != 'удалён' or os.path.exists(с['удалить']):
        continue
    os.makedirs(os.path.dirname(с['удалить']), exist_ok=True)
    shutil.copy2(с['сохранить'], с['удалить'])
    восстановлено += 1
print('восстановлено файлов:', восстановлено)
PY
```
