# Путь зрителя на живых витринах: замер исходного состояния

Только чтение. Ни одна страница, настройка, запись Registry или файл релиза
не менялись. Это baseline, с которым сравнивается кандидат, а не результат
работы над production.

Обход: `automation/host/live-title-journey.py`, 772 запроса, 728 ссылок на
произведения со всех видимых карточек одиннадцати разделов каждой витрины.
Список витрин взят из канонического Registry (версия 32), а не из перечня в
задании.

## Zona: все карточки ведут в 404

Сто девяносто проверенных ссылок из ста девяноста отдают 404. Это ровно тот
дефект, который закрыт в кандидате `claude/zone-tpl-001-r2`: витрина
ссылается на страницы, которых не собирала. **Кандидат в production не
выложен** — на живой витрине работает сборка `1.0.2 /
20260910T124530Z-a1691c56-nova`.

## Lords: один сломанный маршрут того же класса

`/title/albatros-2/` отдаёт 404 на всех трёх витринах, и приходит эта ссылка
с `/catalog/`. Слаг с позиционным суффиксом `-2` — это тот самый класс
дефекта, который разобран и закрыт в Zone R2: суффикс, назначенный по позиции
во входе, не совпал с адресом собранной страницы.

Отдельно: у `lords-03` раздел `/animation/` отдаёт 404, хотя ссылка на него
есть в навигации.

## Lords: просмотр недоступен на 178 страницах

На 178 из 535 открывшихся страниц область плеера объявлена, источника видео
нет, и страница честно сообщает «Видео для этого тайтла временно недоступно».
Состояние правдиво — обещания просмотра без источника нет, — но просмотр
недоступен.

Ни `<iframe>`, ни `<video>`, ни `<video-player>`, ни ссылки на поток на этих
страницах не появляется. Templates отдаёт оболочку и честное состояние;
источник приходит извне. Владелец — Player / Content / Provider,
`docs/handoff/LORDS-PLAYER-CONTENT-HANDOFF.md`.

## Lords: сезоны и серии не привязаны на части витрин

Из 72 проверенных страниц сериалов **25** показывают ноль сезонов и ноль
серий.

| Витрина | Страниц сериалов | Без серий |
| --- | ---: | ---: |
| lords-01 | 24 | 13 |
| lords-02 | 24 | 9 |
| lords-03 | 24 | 3 |

Причина видна из сопоставления одного и того же произведения на разных
витринах:

| Произведение | lords-01 | lords-02 | lords-03 |
| --- | ---: | ---: | ---: |
| `re-zero-pereryv-s-nulya-4` | 0 | 11 | 11 |
| `txt-kurs-molodogo-otca` | 0 | 12 | 12 |
| `800-metrov` | 0 | 0 | 20 |

Данные есть — они просто не попали в релиз конкретной витрины. Это
устаревшая выкладка, а не отсутствие содержимого и не дефект шаблона.
Проверено на кандидате: **все 13** произведений, пустых на живых витринах,
имеют серии в кандидате (от 1 до 20 на произведение).

## Версия шаблона на живых витринах

Разделы (`/catalog/`, `/series/`, страница 404) объявляют
`data-template-version="1.0.2"`, `data-build-id="20260910T124530Z-a1691c56-nova"`.
Страницы произведений отметки версии **не несут** — 186 из 187 на каждой
витрине Lords. То есть страницы произведений и страницы разделов собраны
разными поколениями шаблона.

## Домены вне канонического Registry

В Registry девять витрин; трёх доменов из перечня задания там нет.

| Домен | Наблюдение |
| --- | --- |
| `lordfilm1.online` | имя не разрешается: `Name or service not known`. Наблюдавшийся 502 отсюда не воспроизводится |
| `lorserial66.lol` | HTTP 200, старый шаблон DLE, признаков нового шаблона нет, 148 упоминаний CDNVideoHub |
| `newlordfilm.lol` | HTTP 200, тот же старый шаблон DLE |

Классификация — `BLOCKED_OTHER_OWNER`: этими доменами Templates не управляет,
в каноническом Registry их нет, и выкладывать туда что-либо в рамках этого
задания нельзя.

## Что из этого принадлежит Templates

| Наблюдение | Владелец | Где закрывается |
| --- | --- | --- |
| Zona: 190 карточек в 404 | Templates (исправлено в кандидате) | выкладка кандидата Zone R2 |
| `albatros-2` → 404 | Templates (исправлено в кандидате) | там же |
| `/animation/` 404 на lords-03 | Templates / Release Ops | требует выкладки текущего кандидата |
| Сезоны и серии пусты | Release Ops (устаревший релиз) | выкладка текущего кандидата |
| Источник видео отсутствует | Player / Content / Provider | отдельный handoff |
| Старый шаблон на `.lol` | другой владелец | вне периметра |
| `lordfilm1.online` не разрешается | владелец домена | отдельный handoff |

Ни один из этих дефектов не исправляется правкой живого сайта из Templates, и
ни один live-сайт этой работой не объявляется исправленным.
