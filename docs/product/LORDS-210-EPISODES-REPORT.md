# Сериал с 210 сериями: что проверено и что невыполнимо

## Фикстура

В боевом каталоге сезона ровно с 210 сериями нет. Есть 32 сезона с двумя
сотнями и больше; крупнейший — «Детектив Конан», 1212 серий в одном сезоне.
Поэтому фикстура синтетическая: `tests/lords/test_golden_210_episodes.py`
строит запись с ровно 210 сериями и собирает по ней страницу настоящим
отрисовщиком.

## Что проверено и сходится

| Требование | Итог |
| --- | --- |
| Все 210 серий существуют в данных | да |
| Отрисованы все 210 | да |
| Список не обрывается на 100 | да, 100 и 101 на месте |
| Серии 1, 2, 99, 100, 101, 209, 210 | все на месте |
| Номера идут подряд без повторов | да, ряд 1…210 |
| Номер не подменяется позицией кнопки | да, 101-я позиция несёт номер 101 |
| Объявленное число совпадает с отрисованным | да |
| Серии в упорядоченном списке `<ol>` | да |
| Список не задаёт непереносимую ширину | да |

На боевых данных то же проверено на «Детективе Конане»: 1212 серий
отрисованы целиком, граничные номера на месте, порядок не нарушен
(`tests/lords/test_series_episode_binding.py`).

## Чего шаблон сделать не может: адресация серий

`EPISODE_ADDRESSING=NOT_IMPLEMENTED`.

У серий **нет собственных адресов**: они перечислены списком на странице
произведения, ссылок на них нет. Поэтому невыполнимы и не объявляются
выполненными:

- прямой URL серии 210;
- `<title>`, описание, breadcrumbs и canonical с номером серии;
- переходы «предыдущая / следующая» и их поведение на границах;
- выделение активной серии;
- сохранение выбранной серии при перезагрузке.

Это не упущение вёрстки. Чтобы серия имела адрес, нужна отдельная страница на
каждую серию. В каталоге 8855 записей с сериями; при нынешней средней
наполненности это порядка сотни тысяч дополнительных страниц к нынешним 52 841.
Полная сборка сейчас занимает девятнадцать минут — рост будет кратным, вместе
с размером артефакта и поисковой поверхностью.

Решение о том, выпускать ли страницы серий, принимает владелец: это вопрос
размера витрины, времени сборки и SEO, а не оформления. Ниже — то, что для
этого понадобится от других владельцев:

1. **Content**: устойчивый идентификатор серии, пригодный для адреса.
2. **Player / Provider**: источник, привязанный к конкретной серии, — иначе
   отдельная страница серии будет отличаться от страницы произведения только
   заголовком.
3. **SEO**: решение о canonical и индексации ста тысяч страниц.

Пока этого нет, честное состояние — список серий на странице произведения, и
он полон: ни одна серия не теряется.
