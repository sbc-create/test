# Запрос на съёмку референса Lords

Это перечень недостающего, а не жалоба на блокировку. Всё, что можно было
закрыть без эталона, закрыто; остаток перечислен ниже поимённо.

## Почему съёмка невозможна без владельца

Разрешённые для измерения источники перечислены в
`inventory/reference-sources.yaml`. Файл содержит два источника:
`amd.online` и `w140.zona.plus`. Хостов `lordfilm-hit.org` и
`lordserials.fan` в нём нет — проверено во всех рабочих деревьях репозитория.

В самом файле записано: «Список не расширяется по инициативе агента: каждая
запись приходит из задания владельца проекта». Поэтому блокировка не
техническая, а правило. Проверено обращением, а не по прошлой записи:

```
curl https://lordfilm-hit.org/  → отказ профиля: «хост не входит в переданные контракты»
curl https://lordserials.fan/   → отказ профиля: тот же
```

Снять блокировку может только владелец — добавив записи в разрешённый список
вместе с основанием, по образцу существующих записей.

## Чего не хватает

### Страницы (архетипы)

Из одиннадцати обязательных архетипов числовым замером покрыты два с
половиной: главная (две витрины) и карточка (одна витрина, она же
единственная с измеренным плеером).

| Архетип | Есть | Нужно |
| --- | --- | --- |
| главная | числа | снимки, кропы, цвета |
| страница фильма | числа | снимки, кропы, цвета |
| страница сериала | — | адрес, снимки, DOM |
| сезон | — | адрес, снимки, DOM |
| эпизод со страницей плеера | числа по одной карточке | снимки, поведение плеера |
| жанровый каталог | — | адрес, снимки, число колонок |
| каталог по стране | — | адрес, снимки |
| подборка | — | адрес, снимки |
| результаты поиска | — | адрес, снимки, вид карточки в выдаче |
| пустая выдача | — | как выглядит «ничего не найдено» |
| мобильная навигация | — | открытое меню на узкой ширине |

### Ширины

Замер сделан на 390, 768, 1024, 1440 и 1920. Не покрыты **360** и **1366** —
две из семи требуемых.

### Данные на каждый кадр

1. полностраничный снимок PNG без сжатия с потерями;
2. кропы: шапка, меню, форма поиска, карусель, сетка каталога, карточка,
   подвал;
3. `getComputedStyle` для ролей body, h1–h3, a, p, button, card, badge;
4. цвета фона, текста, акцента и границ в sRGB;
5. `grid-template-columns` и фактическое число колонок сетки;
6. семейство и начертание шрифтов;
7. порядок секций верхнего уровня;
8. sha256 каждого файла и общий sha256 манифеста;
9. время съёмки, ширина и высота окна, полностраничный снимок или видимая
   область.

### Два вопроса, без которых числа не сопоставимы

**Что измерялось в `cardAspectRatios`.** В замере доминирует 0.69, но не
сказано, обёртка карточки это или сам постер. Наш постер 0.67, обёртка 0.42.
Объявить совпадение или расхождение одинаково нельзя. Нужен кроп карточки с
обозначенными границами измеряемого элемента.

**Как референс показывает кадр внутри области плеера.** Измерена только
рамка: 1100×460 на десктопе. Вписывает он кадр или заполняет с обрезкой —
неизвестно, а от этого зависит, появятся ли у него самого чёрные поля.
Без этого вариант B в `LORDS-PLAYER-SHELL-AB.md` совпадает с референсом по
числам, но не доказано, что совпадёт по виду.

## Условия

Только чтение. Логотипы, брендинг, тексты, каталог и идентификаторы не
копируются и не сохраняются: нужна структурная и геометрическая мера, а не
чужие материалы. Это прямо записано в разрешённом списке источников и здесь
не ослабляется.
