# Запрос на снятие референса Lords (LORDS-VISUAL-PARITY-001)

## Почему запрос, а не снимок

Егресс к референсным хостам закрыт профилем разрешений. Проверено прямым
обращением, а не по старой записи:

```
curl https://lordfilm-hit.org/  → отказ: «хост "lordfilm-hit.org" не входит в переданные контракты»
```

Тот же блокер зафиксирован ранее как `REF-EGRESS-01` для `w140.zona.plus`.

## Что уже есть

`docs/product/LORDS-REFERENCE-MEASUREMENTS.md`
sha256 `9bae6162996ef857f11e8bbef12f10381bc6796993c910afd6122710e974809d`,
замеры от 2026-08-27, три страницы:

- `https://lordfilm-hit.org/` — главная;
- `https://lordfilm-hit.org/3629-bunker-2023.html` — карточка;
- `https://lordserials.fan/` — главная сериалов.

Вьюпорты 390, 768, 1024, 1440, 1920. Есть: ширина контента, gutter, высота
шапки, типографика по ролям, пропорции карточек, число секций и ссылок,
высоты секций верхнего уровня, геометрия плеера на карточке.

## Чего нет и что из-за этого недоказуемо

| Отсутствует | Какие ворота становятся недоказуемыми |
| --- | --- |
| Полностраничные снимки | masked SSIM, overlay, «reference \| before \| after» |
| Кропы компонентов | покомпонентная матрица сходства |
| Цвета | median и p95 ΔE |
| Семейство и начертание шрифтов | font-family/weight parity |
| `grids` (не измерено, `[]`) | совпадение числа колонок по breakpoint |
| Вьюпорты 360 и 1366 | две из семи требуемых ширин |
| Архетипы: поиск, пустая выдача, 404, отсутствующий постер, loading/error | пять из одиннадцати требуемых архетипов |

## Что нужно снять

Для каждого из трёх URL и каждой ширины 360, 390, 768, 1024, 1366, 1440, 1920:

1. полностраничный снимок PNG;
2. кропы: шапка, меню, поиск, карусель, сетка каталога, карточка, футер;
3. `getComputedStyle` для ролей body, h1–h3, a, p, button, card, badge;
4. цвета фона, текста, акцента и границ в sRGB;
5. `grid-template-columns` и фактическое число колонок сетки;
6. семейство и начертание шрифтов;
7. DOM-порядок секций верхнего уровня;
8. sha256 каждого файла и общий manifest sha256.

Дополнительно архетипы, которых нет в текущем наборе: жанр/подборка, поиск с
результатами, пустая выдача, 404, карточка без постера.

## Условия

Только чтение. Логотипы, брендинг и тексты референса не копируются: нужна
структурная и геометрическая мера, а не чужие материалы.

## Дополнено после работы LORDS-VISUAL-PARITY-001

нужны снимки и кропы.
