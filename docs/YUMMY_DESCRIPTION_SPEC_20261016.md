
# Описания Yummy: что менять в приложении, с точными местами и ограничениями

Запись от 2026-10-16, 14:00 UTC. Это задание на правку для линии приложения и
предложение пяти профилей для SEO. Основание — измерения: пять витрин отдают
одинаковые `<title>` (10 из 10) и одинаковые описания (8 из 10), длина
описания 154–477 знаков при цели 120–160, и описание открывается названием.

## 1. Где это собирается

`src/seo-core/descriptions.ts`, `buildFactualDescription` (строка 73). Сейчас:

```ts
const fragments: string[] = [`Смотреть «${titleRu}» онлайн.`];
// далее по одному предложению: Оригинальное название, Год выхода, Формат,
// Статус, Жанры (ВСЕ через запятую), сезон/серия, Дата выхода, озвучки …
```

Вызов со страницы произведения — `titlePageDescription` в
`src/lib/seo/title.ts`; редакционная накладка (`overlayForSlug`) перебивает
результат и остаётся выше любой сборки.

## 2. Четыре правки, не зависящие ни от чьего решения

Каждая следует из уже принятого правила SEO и из измерения:

1. **Описание не открывается названием.** Фрагмент
   `Смотреть «${titleRu}» онлайн.` убрать: в выдаче он дублирует `<title>`
   первым словом (правило §3.5). Название остаётся доступно профилю как
   фрагмент, но не как обязательное начало.
2. **Длина 120–160 знаков**, обрезка по границе ФРАГМЕНТА, никогда посередине
   слова и без многоточия в конце (правило §3.4). Сейчас предела нет:
   измерено 154–477, в среднем 291.
3. **Жанров не более двух** (правило §3.6). Сейчас выводятся все: «Жанры:
   Аниме, Боевик, Драма, Мультфильм, Фантастика» — это перечисление ключевых
   слов, а не описание.
4. **Число серий в описание НЕ выносится** — пока не устранён MOD-49. Один и
   тот же адрес `/anime/<slug>` на разных витринах отдаёт разные произведения
   (18 слагов из 8 437), и число серий у них разное: публикуя его, мы
   превращаем расхождение маршрутов в публичное утверждение. Ветки
   `seasonNumber`/`episodeNumber` на страницах сезона и серии не затрагиваются
   — там номер приходит из адреса.

Пятое, попутное: ветка `Статус — …` мертва (`statusLabel` равен `null` у
100 % записей, поле статуса отсутствует в ответе поставщика). Её можно убрать
или оставить; на результат это не влияет.

## 4. Предложение пяти профилей (ждёт подтверждения SEO)

Различие — отбором, порядком и упаковкой одних и тех же фактов, как в правиле
для Lords. Ни один домен не получает факта, которого нет у других.

| домен | ведущий фрагмент | порядок остальных | сторона |
| --- | --- | --- | --- |
| `yummyani7.info` (канарейка) | `тип + год` | жанры, озвучки, страны, оригинальное название | спереди |
| `yummyani7.site` | жанры | тип + год, озвучки, оригинальное название, страны | спереди |
| `yummyani.org` | оригинальное название | жанры, тип + год, озвучки, страны | спереди |
| `yummyani.biz` | `страна + год` | тип + жанры, озвучки, оригинальное название | сзади |
| `yummyani.site` | `год + жанры` | тип, озвучки, страны, оригинальное название | спереди |

Порядок выпуска — по просьбе SEO обратный трафику: `yummyani7.info`, затем
`yummyani7.site`, затем `.org` и `.biz`, последним `yummyani.site`.

Профиль берётся из `SITE_PROFILE` (`site|org|biz` плюс два контура
`yummyani7`, которые тоже поднимаются с `SITE_PROFILE=site`): **поэтому
ключом должен быть не `SITE_PROFILE`, а `SITE_URL`/`APP_URL`** — у двух
контуров `yummyani7` профиль тот же, что у `yummyani.site`, и по профилю они
неразличимы. Это измеренное ограничение, а не предпочтение: `SITE_PROFILE`
принимает только три значения, и точка входа образа отказывает на четвёртом.

## 5. Как проверять результат

1. `description` одной и той же страницы на пяти доменах различается после
   нормализации пробелов — и ни одно не начинается с названия;
2. длина каждого — от 120 до 160 знаков;
3. жанров не более двух; числа серий нет;
4. каждое слово описания выводится из поля записи или из закрытого списка
   связок — перенос `automation/local/description-fact-trace.py` на поля
   приложения делаю я;
5. редакционная накладка по-прежнему перебивает сборку: на
   `/anime/1999-otdel-protivodeystviya-okkultizmu` (одна из трёх накладок с
   текстом) описание остаётся редакторским.

Эффект по трафику на `yummyani.site` по визитам проверять нельзя: 74 % его
визитов — внешний обходчик. Проверка эффекта — поисковые входы и показы, то
есть после B023.
