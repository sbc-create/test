## Что сейчас происходит

`factory/qwen/проверить_материал` (файл `factory/qwen/editorial.py`, строки
589–610) делает две вещи подряд:

```python
год = ф.get("year")
if год and str(год) not in т:
    беды.append(f"в тексте нет года {год} — он есть в снимке и его стоит назвать")
...
лишние = годы - {int(год)} - из_названия if год else set()
if лишние:
    беды.append(f"в тексте годы {sorted(годы)}, а в снимке только {год} …")
```

То есть: год СНИМКА обязателен в тексте, а любой другой год объявляется лишней
датой. Пока снимок и источник согласны — это верно и полезно.

## Когда это делает материал невыпускаемым

Измерено 25.10 на `an1meg0.site/rukovodstvo-soten-demonov-4`: снимок
`animego-04` объявляет `year=2020, type=tv`, а записанный источник Shikimori
57995 отвечает `ona, aired_on 2024-02-23`. Тогда:

* текст с 2024 ворота не пустят — «лишняя дата»;
* текст с 2020 редактор писать отказывается — год не подтверждён источником, и
  он прав: это наше же правило о фактах.

Материал непубликуем в обе стороны. Охват измерен двумя линиями независимо: не
меньше **пяти** пар витрина-произведение за 10 суток плюс два случая той же
ловушки с другой причиной; это нижняя граница (искали по формулировкам в
журнале). Одна работа при этом крутится на трёх витринах, то есть цена одной
неверной записи года умножается на число витрин.

## Предлагаемая правка (две строки смысла)

Год снимка перестаёт быть обязательным, когда записанный источник называет
ДРУГОЙ год; год источника при этом не считается лишней датой.

```python
год = ф.get("year")
год_источника = ф.get("source_year")          # ← новое: год из записанного источника
расходятся = bool(год and год_источника and str(год) != str(год_источника))
if год and not расходятся and str(год) not in т:
    беды.append(f"в тексте нет года {год} — он есть в снимке и его стоит назвать")
if расходятся and str(год) in т and str(год_источника) not in т:
    беды.append(
        f"в тексте год снимка {год}, а источник называет {год_источника}:"
        " при расхождении берётся год ИСТОЧНИКА")
...
допустимые = {int(год)} | ({int(год_источника)} if год_источника else set())
лишние = годы - допустимые - из_названия if год else set()
```

Откуда брать `source_year`: его уже отдаёт `source_fetch shikimori <id>` в поле
`aired_on`/`released_on`, и редактор его читает при подготовке — надо лишь
положить его в факты рядом с годом снимка.
