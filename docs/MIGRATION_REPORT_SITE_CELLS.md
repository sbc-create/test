## Главный блокер: активация требует root

Воспроизведено один раз, с выводом:

    $ bash deploy/activate.sh --dry-run --artifact /dev/null
    == проверка предусловий
    нужен root

`sudo` и `systemctl` закрыты профилем UNATTENDED_SAFE
(`seo_operator/unattended.py`, применяется `.claude/hooks/guard_bash.py`).
Повторные одинаковые попытки не предпринимались.

## Что найдено при подготовке и исправлено

**Рантайм перестроен соседним терминалом.** `/srv/lords/.frontend/lords-frontend.py`
теперь загрузчик на 6.8 КБ: он определяет витрину по порту и передаёт управление
неизменяемому релизу `sites/<site>/current`. Первое сравнение показало
«расхождение» у пяти ячеек — сравнивалось не с тем источником. Сверка с
назначенным релизом: **совпадает побайтово у всех пяти**. Устаревшего снимка нет.

**Yummy поднялся бы молча деградированным.** Точка входа загружает пять соседних
модулей через `_рядом()`, которого в ячейках не было, а при отсутствии файла он
возвращает `None` — не отказ. Витрина ответила бы 200 без read-model, новых
серий, внешних рейтингов и карточек. Модули добавлены, происхождение записано
честно (`verified_against: «ничего»` — в монорепозитории их больше нет).

**Отрендеренные страницы терялись при переключении.** Ячейка ждала их в своём
хранилище, а таймер хоста пересобирает их в `/srv/lords/<site>/current/site`:
2854 файла у zonafilm.space, 2977 у animedia.icu. Ячейки переведены на путь
производителя.

**Контент перестал бы доставляться.** Активация копирует снимок каталога один
раз. Добавлена `factory cell deliver`: перечень берётся из конфигурации самой
ячейки, запись атомарна и рядом с назначением, каталоги честно помечаются
`not_covered`. Подключена к обновлению контента.

**Команда активации была небезопасна по умолчанию.** Модуль делал сухой прогон,
CLI — настоящую активацию. Теперь нужен явный `--confirm-activation`.

**Две мины в переданной команде.** Из другого рабочего каталога `python -m factory`
подхватывает другую копию пакета без команды `cell`; git под root отказал бы на
чужом по владельцу репозитории. Первое закрыто обязательным `cd` в инструкции,
второе — передачей `safe.directory` обеим git-операциям.

## Блокеры, которые остаются

**Yummy: общий readmodel с пользовательскими голосами.** Все три витрины читают
один `/srv/lords/.frontend/yummy-readmodel.sqlite3` (6.7 МБ), где лежит таблица
`user_rating`. Конфигурация ячейки ждёт свой файл в хранилище. Переключить одну
витрину значит либо потерять голоса, либо расщепить хранилище на три. Требуется
решение владельца о судьбе общих голосов — выдумывать его нельзя.

**animedia.icu занят.** Ветка `claude/community-comments-platform-01` выпускала
релизы в пределах часа. Активация отложена до освобождения.

**yummyani.site занят.** Семь эфемерных контейнеров, свежайший — за 11 минут до
проверки.

## Индексация: состояние зафиксировано, не изменено

Закрыты (`Disallow: /` и `X-Robots-Tag: noindex, nofollow`): zonafilm.space,
lordfilm47.space, lordserial33.biz, 1lordserials1.online, yummyani.biz.
**Открыты**: yummyani.org и yummyani.site (`Allow: /`, заголовка noindex нет).
Это состояние задано владельцем и этой задачей не менялось. Активация его не
затрагивает: заголовки выдаёт nginx, а его конфигурация не трогается.
