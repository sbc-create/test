# VK_CONTENT_AND_ADS_CONTRACT — контент и реклама VK

Статус: **contract не передан**. Ни лицензионного каталога/выгрузки VK, ни rights manifest,
ни документации белого плеера, ни рекламного contract VK/Adman/AdTech в сессию не поступало
(F1.2). Публичные неофициальные пересказы contract не заменяют (§12), поэтому ниже
зафиксировано только то, что известно достоверно, и интерфейс, который фабрика реализует.

## 1. Правила, действующие независимо от contract

1. Факт публичной доступности ролика на VK **не является** доказательством права
   использовать его в фабрике. Каждый site package обязан ссылаться на разрешённый
   каталог/выгрузку и rights manifest.
2. Общий поиск по VK и добавление случайных публичных роликов запрещены. Используются
   только переданные `content_id` / `video_id`.
3. Скачивание и перезалив видео, preview и метаданных запрещены, если это явно не
   разрешено договором и документацией. Воспроизведение — только утверждённым
   белым плеером.
4. Слой контента и рекламный слой разделены. Реклама подключается только через
   переданный contract с указанными placement/product/video/timestamp mappings и
   разрешёнными событиями. Выдумывать SDK-методы, targeting-поля, пиксели, бюджеты
   и fallback-рекламу запрещено.
5. Секретные токены VK и рекламного API остаются server-side. Публичные идентификаторы
   считаются публичными только при явном подтверждении contract.
6. Ошибка, отсутствие прав, удаление или недоступность VK-видео дают контролируемое
   состояние страницы (`content_unavailable`) и техническое событие. Подстановка другого
   ролика запрещена.

## 2. Реализованный интерфейс (adapter contract)

`factory/vk.py` определяет `VideoPlayerAdapter` со строго ограниченной поверхностью:

| Метод | Назначение | Поведение без contract |
|-------|------------|------------------------|
| `resolve(video_ref) -> VideoDescriptor` | получить разрешённые поля ролика из переданного каталога | читает только локальную выгрузку; сети не делает |
| `embed_html(descriptor, mode) -> str` | разметка белого плеера | `mock`-адаптер отдаёт нейтральный контейнер-заглушку **только для staging** |
| `availability(descriptor) -> Availability` | доступность ролика | без contract возвращает `unknown` → страница рендерится в состоянии `content_unavailable` |

`factory/ads.py` определяет `AdsAdapter` с методами `slots(page_type)`,
`render_slot(slot_id)`, `allowed_events()`. Без contract адаптер `disabled` — рекламные
слоты не рендерятся вовсе; резервирование размеров при этом выполняется по правилам
верстки, чтобы не было CLS при последующем включении.

**Технический гейт:** `mock`-адаптеры запрещены при `environment: production` на уровне
валидатора и покрыты тестом `tests/unit/test_vk_ads_gating.py`. Это выполняет требование
§8.11 «mock/test интеграции должны быть технически невозможны в production».

## 3. Что обязано прийти от пользователя

| Поле | Формат | Что блокирует |
|------|--------|---------------|
| каталог/выгрузка VK + версия + SHA-256 | файл в `sites/<site_id>/content/` | `BLOCKED_RIGHTS` для всего пакета |
| rights manifest (кто правообладатель, срок, территория, разрешённые способы использования) | YAML/JSON | `BLOCKED_RIGHTS` |
| перечень разрешённых полей метаданных | список | рендер карточки и JSON-LD |
| contract белого плеера (embed-схема, параметры, режимы воспроизведения) | документ + ref | `embed_html` реального адаптера |
| VK API contract (если требуется server-side обращение) | документ + `secret_ref` | `network_allowlist` для VK endpoint |
| рекламный contract VK/Adman/AdTech: placement IDs, product IDs, разрешённые события, policy refs, `secret_ref` | документ | рекламный слой целиком |

## 4. Неизвестное, зафиксированное явно

- Точная схема embed белого плеера и допустимые режимы воспроизведения.
- Разрешено ли проксирование/кеширование preview-изображений.
- Разрешённый перечень полей для `VideoObject` (`uploadDate`, `duration`, `contentUrl`,
  `embedUrl`, `thumbnailUrl`) — до подтверждения ни одно из них в разметку не попадает.
- Требования к раскрытию рекламной природы блоков и к возрастным ограничениям.
