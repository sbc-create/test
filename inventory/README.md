# inventory/

Реестр разрешённых целей. **Секретов здесь нет и быть не может** — только ссылки
`secret_ref` на имена переменных окружения или пути в secret-хранилище.

| Файл | Назначение |
|------|------------|
| `ssh-hosts.yaml` | разрешённые SSH-цели, deploy-пользователь, отпечаток host key |
| `dns-zones.yaml` | разрешённые DNS-зоны и scoped-токены |
| `dle-licenses.yaml` | реестр лицензий DLE и покрываемых доменов второго уровня |
| `dle-distributions.yaml` | лицензионные дистрибутивы и их SHA-256 (архивы в git не попадают) |
| `targets.yaml` | целевые окружения: связка host + web server + БД + adapter |

`factory` резолвит `*_ref` из site package **только** по этим файлам. Значение, которого
нет в inventory, даёт `BLOCKED_ACCESS`, а не попытку угадать адрес.
